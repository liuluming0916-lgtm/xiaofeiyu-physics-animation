# 共点力静态平衡：矢量三角形、相似三角形与正弦定理

## 适用判据
物体**静止或匀速**（合力为零）且要解**力的大小/方向**。按"未知量个数"与"角度是否已知"选方法：
- 未知量 ≤ 2 且角度已知 ⇒ **正交分解**或**矢量三角形**；
- 未知量 ≤ 2 且**用正弦定理更快**（三力与三个角一一对应）；
- 未知量 > 2 且角度全未知，但图中存在与力三角形**相似的几何三角形**（顶点不变）⇒ **相似三角形法**。
反判据：合力不为零（有加速度）时先转牛顿第二定律；只问"变大变小"的趋势题用"动态平衡分析"词条。

## 建模步骤
1. **确认三力共点**：三力平衡必共点；非质点问题（棒、链、杆）先用**三力汇交原理**定出某力的方向。
2. **画矢量三角形**：首尾相接画三力，闭合成三角形（顺序无所谓，方向首尾相接）。作法要点：先画重力，再判断三角形画在**重力哪一侧** —— 判据是"**以重力为界，与题图相反**"。
3. **优先试相似三角形**：在题图里找一个几何三角形，其三个顶点固定、三边与力三角形三边分别平行/对应。
   - 若能找到（并且把质点沿接触面挪一点，新的几何三角形仍与力三角形相似、顶点不变）⇒ 用相似比 `F_1 / 边_1 = F_2 / 边_2 = F_3 / 边_3`。
   - 找不到 ⇒ 转正弦定理。
4. **正弦定理**：`F_1 / sin(对角) = F_2 / sin(对角) = F_3 / sin(对角)`（三连等 = 两个独立方程，正好解两个未知量）。
5. **正交分解**（等价路线）：选让最多力落在轴上的方向，写两个方向的和为零；注意**已相互垂直的力不再分解**。
6. **等效重力**：给物体加一个**竖直方向**的恒力 `F` 时，把它并入重力 ⇒ 等效重力 `G_eff = mg + F`（向下）或 `mg - F`；此后再按原来的模型算（原型题 5 的"自锁"就是这么来的：等效重力变大但方向不变，斜面仍然自锁）。
7. **非质点问题**：把连续体**等效成一个质点**（放重心）或**用整体法**把两部分合成一个研究对象（原型题 20 把铁链与小球看成一个质点）。
8. 解方程时**统一用符号**，最后再代数值；至少检查一次量纲与极限。

## 参考公式
- 平衡条件：`sum F_x = 0`，`sum F_y = 0`（三力共点时这两个方程即够）
- 正弦定理形式：`F_1 / sin(theta_1) = F_2 / sin(theta_2) = F_3 / sin(theta_3)`
- 相似三角形：`mg / (对应几何边) = F_T / (对应几何边) = F_N / (对应几何边)`
- 水平面上斜拉匀速：`F = mu mg / (cos(theta) + mu sin(theta))`
- 斜面上沿面斜拉匀速：`F = (mg sin(alpha) + mu mg cos(alpha)) / (cos(theta) + mu sin(theta))`
- 等效重力：`G_eff = mg + F`（`F` 竖直），自锁时摩擦力/支持力按 `G_eff` 重新算
- 三力汇交：三个不平行力平衡 ⇒ 其作用线**交于一点**（用来定未知力的方向）

## 验算
- **三个角必须能凑成 180°**：矢量三角形的三个内角与三力一一对应，画完检查一次；凑不上就是某个力的方向取反了。
- 相似比必须与几何边**一一对应**：写下三个比值后，检查分子分母是同一对（写错一对，答案会差一个因子）。
- 极限：`theta -> 0`（斜拉变水平）时 `F -> mu mg`；`mu -> 0` 时 `F -> 0`（光滑面无需牵引）。
- 等效重力检查：加上竖直恒力后，若题面说"仍然静止"，则等效重力方向不变 ⇒ 摩擦与支持力按同一比例放大（原型题 5 的答案正是 `(F+mg)sin(theta)` 与 `(F+mg)cos(theta)`）。
- 非质点：整体法的方程必须与该部分各物体方程之和一致（两种算法互检）。

## 常见错误
- **矢量三角形画在重力同侧**（应画在**相反**一侧），导致相似关系对不上。
- 未知量已经超过两个仍硬用矢量三角形（解不出来还以为是自己算错）。
- **用相似三角形却不检查"顶点不变"**：拉动过程中几何三角形的顶点若跟着变，相似比就不再是常数（应改用正弦定理）。
- 加了竖直恒力后只把重力改一半，或只改摩擦力不改支持力。
- 正弦定理里把"力"与"角"配错对（`F/sin(对角)` 的角必须是**该力对面**的那个角）。
- 非质点问题里直接对"一小段"列平衡（应先用整体/微元把它等效成质点）。
