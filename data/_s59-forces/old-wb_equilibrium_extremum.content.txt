# 共点力极值问题与自锁（摩擦角、全反力）

## 适用判据
- 求某个力的**最小值**（"求 `F` 的最小值"“至少多大的力”）；
- "**无论**外力多大都不能使物体运动" ⇒ **自锁**；
- 求"临界角"（外力方向改变到某个角度后失效）。
反判据：只求某个力在给定方向下的大小、不涉及最值的题用"共点力平衡"词条。

## 建模步骤
1. **求最小值的三条捷径，按优先级试**：
   - 若某力大小与方向都确定、只求另一个力的最小值 ⇒ **两力垂直时取最小**（原型题 17、18：`F_min = G sin(theta)`）；
   - 若是"斜拉使物体匀速"且拉力方向可变 ⇒ 用**辅助角公式**：`F = A / (cos(theta) + mu sin(theta)) = A / (sqrt(1+mu^2) sin(theta + phi))`，最小值 `A / sqrt(1+mu^2)`，其中 `A` 是**不加这个力时物体受到的合力**（沿运动方向），`tan(phi) = 1/mu`；
   - 若是"拉力方向固定、求另一个力最小" ⇒ 矢量三角形里当该力与已知方向的力垂直时取最小。
2. **自锁判据**：把摩擦力与支持力合成为**全反力** `F_R`，它与支持力的夹角 `phi_m` 满足 `tan(phi_m) = mu`（**摩擦角**）。外力与支持力的夹角 `<= phi_m` 时，物体**无论受多大外力都不会滑动**。
3. 自锁题的快捷解法：**令 `m = 0`**（自锁与质量无关）再列临界方程，可省掉重力项；临界时摩擦力取滑动摩擦 `mu F_N`。
4. 斜面自锁：由 `mu = tan(theta_0)` 反解临界倾角；若外力方向与支持力夹角为 `(90° - theta)`，则判据是 `90° - theta <= phi_m`。
5. 极值题最后**核对取极值的条件是否在允许范围内**（角度是否落在 `[0, pi/2]`）。

## 参考公式
- 全反力与摩擦角：`tan(phi_m) = mu`，`F_R = sqrt(F_N^2 + f_max^2)`，`F_R` 与 `F_N` 的夹角为 `phi_m`
- 滑动时全反力方向不变（因为 `f = mu F_N` 使 `f` 与 `F_N` **等比例**变化）
- 自锁条件：外力与支持力的夹角 `<= phi_m`；等价写法 `tan(theta_0) = mu`（水平面压物）、`tan(theta_0) = 1/mu`（水平推斜面体的形式）
- 斜拉匀速最小值：`F_min = mu mg / sqrt(1 + mu^2)`（水平面）；`F_min = (mg sin(alpha) + mu mg cos(alpha)) / sqrt(1+mu^2)`（斜面）
- 匀加速时同理：把分子换成 `mg(sin(alpha) + mu cos(alpha)) + m a`（用"惯性力"或直接列牛二）
- 已知方向的力给定时求另一力最小：`F_min = F_已知 sin(夹角)`
- 四个力的极值（原型题 19）：分母仍是 `sqrt(1+mu^2)`，分子是"忽略待求力时的合力"

## 验算
- **量纲**：`mu` 无量纲，`F_min` 与 `mu mg` 同量纲；`sqrt(1+mu^2)` 必须出现在分母。
- 极限：`mu -> 0` 时 `F_min -> 0`（光滑面不用拉）；`mu -> ∞` 时 `theta_0 -> 0`（任何角度都自锁）。
- 自锁与质量无关这条要**显式验证**：把 `m` 换成 `2m` 后临界角必须不变（可在自检里算两遍）。
- 极值处的角度必须满足题设范围；若解出的 `theta` 超出范围，最值出现在**端点**（不是内部驻点）。
- 用两条独立路线互检：辅助角公式给的最小值，与"矢量三角形里两力垂直"给的最小值必须一致。

## 常见错误
- **忘了 `sqrt(1+mu^2)` 这个分母的形式**，把最小值写成 `mu mg`（那是 `theta = 0` 时的值，通常不是最小）。
- 认为"力越大越容易推动"（自锁时**无论多大都推不动**）。
- 自锁题里去讨论质量、重力（自锁与质量无关，徒增未知量）。
- 取极值的地方判错：`F` 有最小值而 `F cos(theta)`（即功率）是**单调**的，两者不能混为一谈。
- 四个力的题直接套三力结论（要先定"忽略待求力时的合力"）。
- 把摩擦角写成 `tan(phi) = 1/mu`（定义是 `tan(phi_m) = mu`；`1/mu` 只出现在"推斜面"的等价形式里）。
