# 弹簧弹力与弹力方向判据

## 适用判据
- **弹簧类**：出现"劲度系数 `k`""原长""压缩量/伸长量"，或要算"某点移动的高度"（`dF = k dx` 变式）、多根弹簧的等效劲度系数、弹簧被剪断/分段。
- **弹力方向类**：被约束物是**轻质**的（轻环、轻杆、绳的结点、定滑轮），要判"弹力沿哪个方向""两段绳张力是否相等"；或要判**活结 / 死结**、**活杆 / 死杆**。
反判据：题面明说"超出弹性限度"时胡克定律失效；有质量的杆、粗糙环、绳被固定在点上都不属于弹力方向类。

## 建模步骤
1. **弹簧先定两个状态**（初始平衡 + 末态平衡），**分别写出形变量**，再判每个状态的形变方向（压缩/拉伸）——方向必须**逐状态**判断。
2. **用变式而非原式**：`dF = k dx` 只需**变化量**，不必求原长，也不受参考点影响。
3. **串联**（弹力变化量相同、形变量相加）`1/k_eq = 1/k_1 + 1/k_2`；**并联**（形变量相同、弹力相加）`k_eq = k_1 + k_2`；**剪断/分段**：`k` 与长度成反比，`n` 等分后每份 `k' = n k`。
4. **求"某点移动的距离"要分别累加**：该点上方弹簧形变量的变化 + 它下方连接弹簧的变化（`m_1` 走 `dx_1 + dx_2`，`m_2` 只走 `dx_2`）。
5. **弹力方向的总判据只有一句：轻物必平衡**（不计质量 ⇒ 它自己的重力为 0 ⇒ 受力必须平衡）。下面全部结论都由它推出：
   - **轻环**受两个力（杆的弹力 + 绳/外力）⇒ 二力平衡 ⇒ **`F` 必垂直于杆**（曲杆垂直于切线）；
   - **活结**（同一根绳穿过光滑环/滑轮）⇒ 绳中张力**处处相等**，两段绳的合力沿**角平分线**（可直接套正 Y 模型）；
   - **死结**（结点处是几根不同的绳）⇒ 各绳张力**不一定相等**，必须把结点当研究对象，逐根设未知张力；
   - **活杆**（可绕一端无摩擦转动）⇒ 杆的力**一定沿杆**；
   - **死杆**（固定支架、折杆）⇒ 方向由状态定：平衡时与其余力的合力等大反向；有加速度时 `F = sqrt((m a)^2 + (m g)^2)`、`tan(alpha) = a/g`。
6. **受力图只画一个研究对象**：轻环/结点自己一张图，它连接的物体另一张图。

## 参考公式
- 胡克定律 `F = k x`（`x` 是**形变量**，不是弹簧长度）；变式 `dF = k dx`
- 串联 `1/k_eq = 1/k_1 + 1/k_2`；并联 `k_eq = k_1 + k_2`；分段 `k' = n k`
- 两弹簧串联的移动量 `dx = dF (1/k_1 + 1/k_2)`
- 质量相同、初末两端弹力相等时弹簧净做功为零（详见功能侧词条，量级自检用它）
- 活结：`2 F_T cos(theta/2) = mg` ⇒ `F_T = mg / (2 cos(theta/2))`（`theta` 为两段绳夹角）；`theta = 60°` ⇒ 第三力 `= sqrt(3) F_T`，`theta = 120°` ⇒ `= F_T`
- 死结（两绳互成 `theta`）：`F_1 = mg tan(theta)`、`F_2 = mg / cos(theta)`（`theta` 为斜绳与**竖直**方向的夹角）
- 轻环平衡：`N = F` 且方向垂直于杆；**死杆力沿杆的条件：`a = g tan(theta)`**（`theta` 为杆与竖直方向的夹角）
- **弹簧的瞬时性**：剪断/撤去瞬间弹簧弹力**不可突变**（用原弹力进方程），而绳、杆的弹力**可以突变**

## 验算
- **多解检查**：题给"弹力大小为 `2mg/3`"这类**不指明方向**的条件 ⇒ 压缩与拉伸各一个解，**两解都要报**。
- 串联的前提要逐状态核：两根弹簧的"弹力变化量相同"是否真的成立（不成立就不能用 `1/k_eq`）。
- 量纲：`dF / k` 得米；`1/k` 的量纲是 `m/N`，可以直接相加。
- 能量一致性：同一形变下 `E_p = k x^2 / 2`，串联前后总势能不能凭空变化。
- 轻物必平衡：对轻环/轻杆列方程若算出合力不为 0，一定是漏力或方向错。
- 张力自检：活结处两段张力**必须相等**；解出不相等就说明它其实是死结。
- 极限：`k -> ∞` 时 `dx -> 0`（刚性连接）；`theta -> 0`（两段绳平行）时活结 `F_T -> mg/2`，`theta -> 180°` 时 `F_T -> ∞`（所以夹角不可能真的到 180°）；死杆 `a -> 0` 时 `F -> mg` 且竖直向上。

## 常见错误
- **把弹簧长度当形变量**代进 `F = k x`（少减一个原长，最高频错误）。
- 串并联用反（串联写成 `k_1 + k_2` ⇒ 会得出"串联变硬"的荒谬结论）。
- 只算一根弹簧的形变，**漏掉另一根对位移的贡献**。
- 剪断后仍用原劲度系数（剪短使弹簧**变硬**：`k' = n k`）。
- **把死结当活结**（直接令两段张力相等是死结题第一大错），或把活结当死结（多设一个未知量解不出来）。
- 对轻环/轻杆**画上重力**（它们不计质量，重力为 0）；或认定"杆的力一定沿杆"（那是**活杆**才有的结论）。
- 认为"同一根弹簧两端弹力可以不相等"（轻弹簧两端弹力必相等）。

## 生成后自检（必须逐条在代码中体现）
- [ ] 每根弹簧都有 `k`、`x0`（初始形变量）、`x1`（末态形变量）三个量，且 `dx = x1 - x0` 单独算出来（**不许**把长度当形变量）。
- [ ] 用 `dF = k * dx` 的变式路径，或明确写两端点位置差 —— 两条路径要能互相验证。
- [ ] 存在压缩/拉伸两个可能方向时，代码里是**两个分支**（两个解都在 `readouts` 里出现），不是写死一个。
- [ ] 活结与死结在代码里是**两种结构**：活结一个张力变量，死结两个张力变量（一眼能从变量个数看出判据）。
- [ ] 轻环/轻杆**没有重力项**，且轻环的力用向量与杆方向点乘断言为 0（垂直判据写进自检）。
