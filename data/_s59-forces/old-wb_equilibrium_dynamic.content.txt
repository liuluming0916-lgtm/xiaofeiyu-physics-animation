# 三力动态平衡分析：矢量三角形、相似三角形与动态圆

## 适用判据
题面有"**缓慢**移动/转动/拉起/下滑"且物体**始终平衡**，问某个力"如何变化"。四把工具按"变的是谁"选：
- 只有一个力的**方向**变（另两力方向都不变）⇒ **矢量三角形动态图**；
- 两个力的大小与方向都变，但图中能找到**顶点不变**的相似几何三角形 ⇒ **相似三角形**（相似比为常数，按边长的增减判力）；
- 两个力的方向都变且**它们之间的夹角不变** ⇒ **动态圆**（等弦对等圆周角）；
- 两个力方向都变、又找不到顶点不变的相似三角形、角度还已知 ⇒ **正弦定理**。
反判据：合力不为零的动态过程（如加速运动）不属本条。

## 建模步骤
1. **先锁定"不变的那个力"**：几乎总是**重力**（大小方向都不变）。任何动态平衡题的支点都是它。
2. **判"变的是几个力的方向"**（见上表），据此选工具。选错工具是本题型唯一但致命的错误。
3. **矢量三角形法**：画一个闭合三角形，固定重力那一侧为定边，让变化力的方向按题意转动，读出另两边的长度变化。常见结论：`F` 先减小后增大（当方向转到与某力垂直时取极小）。
4. **相似三角形法**：写出相似比（如 `mg / MO = F_N / AO = F_T / AM`）；因为 `mg`、`MO`、`AO` 是定值 ⇒ 相似比是**常数** ⇒ 哪个几何边变短，对应的力就变小。这是本类题最快的一条路。
5. **动态圆法**：两个变力夹角不变 ⇒ 它们的矢量三角形的外接圆半径不变 ⇒ 在圆上读弦长变化。
6. **正弦定理法**：写出 `F_1 / sin(a) = F_2 / sin(b) = mg / sin(gamma)`，把角度随位置的变化写成函数，再判单调性。
7. **三个力以上的动态平衡**：先用**正交分解 + 辅助角公式**把合力写成 `A sin(theta + phi)` 的形式（`F = mu mg / sqrt(1+mu^2) / sin(theta+phi)`），或者**等效成三力**问题再套上面的工具。
8. 结论必须能回答"为什么"（是哪个边/哪个角在变），不能只给"变大"两个字。

## 参考公式
- 矢量三角形：三力闭合 ⇒ 三边首尾相接；一个方向变时，读另两边的长度变化
- 相似三角形（原型题 10）：`mg / MO = F_N / AO = F_T / AM`，`MO`、`AO` 定 ⇒ `F_N` 不变、`F_T` 随 `AM` 减小而减小
- 相似三角形（原型题 11 杆绳模型）：`G / AB = F' / BC = F_a / AC` ⇒ `AC` 变长则 `F_a` 增大、`BC` 不变则杆力不变
- 辅助角形式（水平斜拉匀速）：`F = mu mg / (cos(theta) + mu sin(theta))`，且 `cos(theta) + mu sin(theta) = sqrt(1+mu^2) sin(theta + phi)`，`tan(phi) = 1/mu`
  - `F` 先减小后增大，最小值 `mu mg / sqrt(1+mu^2)`
  - `F` 的功率 `P = F v cos(theta) = mu mg v / (1 + mu tan(theta))` 随 `theta` 增大而**单调减小**
- 动态圆：两力夹角 `(pi - alpha)` 不变 ⇒ 它们在同一个外接圆上，弦长即力的大小
- 等效斜面（弧面问题）：把圆弧上某点的切线当"斜面"，滑动过程中相当于斜面倾角逐渐增大

## 验算
- **单调性至少核两个端点**：`theta -> 0` 与 `theta -> pi/2` 各算一次，与"先减后增"的结论对照（有极值的必须能指出极值点）。
- 相似比是常数这一条要显式检查：把两个位置的几何边长代入，比值必须相同（若变了，说明"顶点不变"不成立，方法用错）。
- 量纲与量级：辅助角形式里分母 `sqrt(1+mu^2) sin(...)` 无量纲，`F` 与 `mu mg` 同量纲。
- 极限：`mu -> 1` 时最小值 `mu mg/sqrt(1+mu^2) = mg/sqrt(2)`；`mu -> 0` 时 `F -> 0`。
- 功率的单调性单独核一次（`F` 先减后增而 `F cos(theta)` 单调减，这两个结论不矛盾，必须都能说明）。

## 常见错误
- **选错工具**：两个力方向都变却只用动态矢量三角形（读不出结论就乱猜）。
- 相似三角形题**不检查顶点是否变**（拉动过程中顶点变了，相似比就不再是常数）。
- 把"力的方向变"与"力的大小变"混在一起描述，结论含糊（题目要的是明确的"增大/减小/先增后减"）。
- 忘了重力是**唯一**不变的力，去拿一个变力当参考。
- 三力以上的题硬套三力方法，没先做正交分解/等效化。
- 把"`F` 有最小值"当成"`F` 一直减小"（有极值的结论必须写清在何处取极值）。

## 生成后自检（必须逐条在代码中体现）
- [ ] `setup()` 里把"变化的那个量"做成**显式参数**（角度或位移），所有力都由它算出（这样"变化趋势"是算出来的，不是写死的结论）。
- [ ] 若用相似三角形，代码里存的是**几何边长**与相似比，力由边长推出（改几何量时力必须跟着变）。
- [ ] 有一处**数值扫描**：在 `setup()` 里对参数取若干值算出力，检查单调区间与极值位置（这是"自检变化趋势"的唯一可执行办法）。
- [ ] `readouts` 至少给出该变力的值，并且在全时段（或全参数段）**键与单位不变**（C8）；所有值为有限数（C3）。
- [ ] 画面上画出**矢量三角形**或**外接圆**本身（用 `Draw.polygon` / `Draw.arc` + `Draw.ghosts` 画几个关键时刻的三角形），让"变化"这件事可见。
