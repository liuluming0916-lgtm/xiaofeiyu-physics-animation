# 弹簧：胡克定律变式与串并联等效

## 适用判据
只要题中出现"劲度系数 `k`""原长""压缩量/伸长量""弹簧"，或要算"某点移动的高度""两弹簧形变量关系"，就用本条。分三种情形：
- **变形式**：已知形变量的**变化量**求弹力的变化量（`dF = k dx`），最常见；
- **串并联**：多根弹簧的等效劲度系数（串联变软、并联变硬）；
- **弹簧被剪断/分段**：逐段看成串联的小弹簧。
反判据：超出弹性限度（题面明说"已超出"）时胡克定律失效；弹簧有质量（重弹簧）时不能用"弹力处处相等"。

## 建模步骤
1. **先定两个状态**（初始平衡 + 末态平衡），**分别写两个状态下的形变量**——本题型的通用骨架。
2. **判形变方向**：压缩还是拉伸？同一个端点在同一道题里可能先压缩后拉伸，**方向必须逐状态判断**（这是多解的来源）。
3. **用变式而非原式**：`dF = k dx` 只涉及**变化量**，不必求原长，也不受参考点选择的影响。
4. **多根弹簧串联时**（弹力变化量相同、形变量相加）：`1/k_eq = 1/k_1 + 1/k_2 + ...`；等效形变量 `dx = dF / k_eq`。
5. **多根弹簧并联时**（形变量相同、弹力相加）：`k_eq = k_1 + k_2 + ...`。
6. **剪断/分段**：整根弹簧的劲度系数与长度成反比 —— 剪成 `n` 等份后每份 `k' = n k`（原型题 10 的 4 段各为 `k`、整根为 `k/4`）。
7. **求"某点移动的距离"时把两件事分开**：该点自己的位移 = 它上方弹簧形变量的变化 + 它下方（连接）弹簧形变量的变化；不同物体的位移**不同**（原型题 9 中 `m_1` 位移 `= dx_1 + dx_2`，`m_2` 位移 `= dx_2`）。
8. 用平衡条件（或牛顿第二定律）把"弹力变化量"与"力/重力变化量"关联起来。

## 参考公式
- 胡克定律：`F = k x`（`x` 为**形变量**，不是弹簧长度）
- 变式：`dF = k dx`（这是解"缓慢移动"类问题的核心式子）
- 串联：`1/k_eq = 1/k_1 + 1/k_2 + ...`（弹力处处相同、形变量相加）
- 并联：`k_eq = k_1 + k_2 + ...`（形变量相同、弹力相加）
- 弹簧分段：`k` 与长度成反比，`n` 等分后每段 `k' = n k`
- 竖直弹簧上的物体平衡：`k x = m g`（可能还有其它力，逐状态列）
- 两弹簧串联的移动量：`dx = dF (1/k_1 + 1/k_2)`

## 验算
- **逐状态核对形变量**：把每个状态的 `x` 写出来，检查"相同弹力变化量"这一条件在两根弹簧上是否真的成立（串联的前提就是它）。
- 多解检查："弹力大小为 `2mg/3`"这类条件**不指明方向** ⇒ 压缩与拉伸各给一个解，两解都要报（原型题 8 的两个答案就是这么来的）。
- 极限：`k -> ∞`（刚性连接）时 `dx -> 0`；`k_1 -> ∞` 时串联等效劲度系数趋于 `k_2`。
- 量纲：`dF / k_eq` 得 `m`（力 / (N/m) = m）；`1/k` 的量纲是 `m/N`，可以直接相加。
- 能量一致性（若题问弹性势能）：同一形变下 `E_p = k x^2 / 2`，串联前后的总势能不能凭空变化。

## 常见错误
- **把弹簧长度当形变量**代进 `F = k x`（少减一个原长，是全章最高频的错误）。
- 只算"弹力变化量对应的一根弹簧"，**漏掉另一根弹簧的形变对物体位移的贡献**。
- 串并联用反：串联写成 `k_1 + k_2`（那会得到"串联变硬"的荒谬结论）。
- 剪断后仍用原劲度系数（剪短使弹簧**变硬**：`k' = n k`）。
- 忽略"多解"：把压缩解与拉伸解只写一个。
- 认为"同一根弹簧两端弹力大小可以不相等"（轻弹簧两端弹力必相等）。

## 生成后自检（必须逐条在代码中体现）
- [ ] `setup()` 里每根弹簧都有 `k`、`x0`（初始形变量）、`x1`（末态形变量）三个量，且 `dx = x1 - x0` 单独算出来（不许把长度当形变量）。
- [ ] 用 `dF = k * dx` 的**变式**路径，或明确写出两端点的位置差（两条路径要能互相验证）。
- [ ] 若存在两个可能的形变方向（压缩/拉伸），代码里对两个分支**都算出结果**（或用数组给出多个解），不许只留一个。
- [ ] 串联/并联的等效劲度系数写成显式表达式，且数值上与"逐根相加"的结果核对一致。
- [ ] 画面上弹簧用 `Draw.spring(a, b, { coils })` 画，**圈数要与实际长度成比例地变化**，使"形变量"在画面里可见；两个物体的移动距离用 `Draw.dimension` 标注。
- [ ] `readouts` 给出每根弹簧的弹力与形变量；`value` 保持全精度（C7 按容差比对），显示时才用 `Phys.format`。
