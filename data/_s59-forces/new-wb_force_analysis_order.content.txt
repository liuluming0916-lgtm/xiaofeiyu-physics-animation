# 摩擦力：方向判据、大小与临界

## 适用判据
只要问"摩擦力**有没有 / 朝哪 / 多大**"，或问"两物体能否**一起运动**"，就用本条。三条件缺一不可：**接触面粗糙 + 有弹力 `N` + 有相对运动（或趋势）**，无弹力必无摩擦。
- **方向题**：物块在运动的木板/传送带上、驱动轮与从动轮（走路、自行车、皮带）、"假设接触面光滑"能反推趋势的题。
- **大小题**：已知 `mu` 与压力求滑动摩擦；静摩擦由外力"需要多少"反解；"恰好不滑"取 `f = mu N`。
- **临界题**：比较实际加速度 `a` 与临界加速度 `a_c` 定摩擦方向；求"一起运动"的最大加速度；多接触面取**最严**的一个。
反判据：只问某个力的大小而接触面光滑，或题面已给"光滑"，则本条只用"无摩擦"这一条判据。

## 建模步骤
1. **先定"相对谁"**：摩擦方向永远相对**接触面**，与地面、与观察者都无关。
2. **三条件过筛**（顺序不许跳）：接触面粗糙？有弹力？有相对运动或趋势？任何一条不成立就是 `f = 0`，不要再讨论。
3. **比速度定方向**：`v_物 < v_面` ⇒ 摩擦力与带面运动**同向**；`v_物 > v_面` ⇒ 反向。
4. **共速之后改判静摩擦**：把两者都当静止，再问"若光滑它会往哪滑"。倾斜带趋势恒为沿带面向下 ⇒ 静摩擦恒为**沿带面向上**；**水平带趋势为零 ⇒ 无摩擦**。
5. **求大小先分静动**：有相对滑动 ⇒ `f = mu N`；没有 ⇒ 静摩擦大小**待定**，随外力的需要在 `0 ~ mu N` 内取值。
6. **算 `N` 要看真实受力**：斜面是 `mg cos(theta)`、被水平力压墙是 `F`、有竖直加速度时 `N` 会变，**不能一律写 `mg`**。
7. **临界题先算 `a_c` 再比较**：设"刚好达到最大静摩擦"解出 `a_c`（斜面一体 `a_c = g tan(theta)`、水平面被带动 `a_c = mu g`），再由 `a` 与 `a_c` 的大小关系判方向；问外力就要再乘总质量（`F = (m+M) a_c`，这一步最常被漏）。
8. **多接触面逐面写 `mu_i N_i >= f_需要,i`，取最严的**（砖块夹持题：由外向内逐层 `mg`、`2mg`… 到对称面为 `0`）。
9. **方向不确定就别硬给结论**：若某力初方向未知（题面没说），其变化趋势**无法唯一判断**，答案应如实写"无法判断"或分情形讨论 —— 这就是正确选项。

## 参考公式
- 滑动摩擦 `f = mu N`；最大静摩擦 `f_max = mu N`；静摩擦范围 `0 <= f <= mu N`
- 静止/匀速下滑与倾角的关系：**`mu >= tan(theta)`**（与质量无关；等号 = 恰好静止或匀速下滑）
- 斜面上静止时斜面对物块的合力竖直向上、大小 `mg` ⇒ 物块对斜面的力竖直向下 ⇒ **地面对斜面不受摩擦**
- 倾斜带共速后静摩擦 `= mg sin(theta)`（沿带面向上）；水平带共速后 `= 0`
- 两方向都靠摩擦时（二维）：`f = sqrt(f_1^2 + f_2^2)`，临界取 `= mu N`
- 倾斜面叠加体一起下滑的临界：`a_c = g(sin(theta) + mu cos(theta))`（上表面带动）；光滑斜面 `a_c = g sin(theta)`
- 特殊情形判据：`a = g tan(theta)` ⇒ 斜面上无摩擦；水平面整体无水平外力 ⇒ 地面摩擦为零；自由落体 `a = g` ⇒ 层间无弹力无摩擦

## 验算
- **量纲**：`mu` 无量纲、`tan(theta)` 无量纲 —— 要比较的是 `mu` 与 `tan(theta)`，**不能拿力去比较**。
- 解出静摩擦后核对是否 `|f| <= mu N`：超出说明它其实已经在滑动，假设错了。
- 临界两侧各代一次：`a = a_c` 时隔离体方程里的摩擦力必须为 0（或恰好等于 `mu N`），两种口径都要自洽。
- 逐层核对砖块题：最外侧 `(n/2) mg`、中间对称面为 `0`，**首尾都要对**。
- 变化规律题核对"逐时刻的 `f`、`v`、`a` 三件套"：`a` 与 `v` 同号加速、异号减速；速度过零那一刻摩擦由滑动**突变为静摩擦**，大小允许跳变。
- 极限：`mu -> 0` 时 `f -> 0`；`theta -> 90°` 时 `N -> 0` 故 `f -> 0`。

## 常见错误
- 用**地面**当参考判相对运动方向（应当用**带面/板面**）。
- 把"摩擦方向"答成"与运动方向相反"：驱动轮、被带动的物块都与运动方向相同。
- 水平带共速后仍判"有摩擦力"（水平带才是 0；倾斜带是 `mg sin(theta)`）。
- 把 `N` 一律写成 `mg`，与本题型的临界式 `f_max = mu N`（斜面 `N = mg cos(theta)`）直接打架。
- 静摩擦方向未知却硬给"一定增大/一定减小"，而不给"无法判断"或分情形。
- 算出 `a_c` 就停手，忘了题目问的是外力（还差 `F = (m+M) a_c`）。
- 把 `f = mu N` 用在**静摩擦**上（静摩擦是被动力，不到临界就取不到这个值）。
