# 斜面模型、正 Y 模型与 g·tanθ 模型

## 适用判据
三力（或可化为三力）平衡题的三种**固定受力结构**，先认结构再套结论：
- **斜面模型**：物体在斜面上（静止、匀速下滑或恰好将滑）。判据：`mu` 与 `tan(theta)` 的大小关系决定"静止 / 匀速下滑 / 加速下滑"。
- **正 Y 模型**：质点受**两个等大的力**（通常是同一根绳的两段）加一个重力而平衡 —— 两段绳夹角被绳长与两端水平间距**锁死**。
- **g·tanθ 模型**：三个力**两两垂直或互成特殊角**（竖直力 `mg`、水平力、倾斜力）而平衡。判据：水平力 `= mg tan(theta)`、倾斜力 `= mg / cos(theta)`。
反判据：物体在加速（合外力不为零）时，上述"结论式"不能直接套，只能借它们的**结构**（力的方向关系），方程仍要走牛顿第二定律。

## 建模步骤
1. **先认结构**：画出三力的方向关系，看是不是上述三种之一（很多题换个外壳就是同一个结构——原型题 4 的"斜面上的小球"与"水平绳+斜绳的结点"受力图**完全相同**）。
2. **斜面模型**：把重力沿斜面/垂直斜面分解 ⇒ 垂直方向 `F_N = mg cos(theta)`、沿面方向比较 `mg sin(theta)` 与 `mu mg cos(theta)`；判据是 **`mu` 与 `tan(theta)` 比大小**（与质量无关）。
3. **正 Y 模型**：水平方向 `F_T cos(alpha) = F_T cos(beta)` ⇒ **两段绳与水平方向夹角相等**；竖直方向 `2 F_T sin(alpha) = mg`。再由几何 `d = l cos(alpha)`（`d` 是两端水平间距、`l` 是绳长）得到 **`cos(alpha) = d / l` 是常数**。
4. **正 Y 的动态结论**（核心，原型题 2、3 全靠它）：绳端上下移动 ⇒ `d`、`l` 不变 ⇒ `alpha` 不变 ⇒ `F_T` 不变；只把一端水平拉开 ⇒ `d` 变大 ⇒ `alpha` 变小 ⇒ `F_T = mg/(2 sin(alpha))` 变大。
5. **g·tanθ 模型**：直接写结论 `F_水平 = mg tan(theta)`、`F_斜 = mg / cos(theta)`；注意 `theta` 是**倾斜力与竖直方向的夹角**（找错角是本题型唯一难点）。
6. **变式（原型题 5）**：若实际力与"无摩擦临界值"不等，则摩擦力方向由**偏差方向**定：外部力偏大 ⇒ 物体有向上（沿面向上）趋势 ⇒ 摩擦力向下（沿面向下）；偏小反之。
7. 需要时把整体法/隔离法嵌进来（弹簧连接的两个小球、穿在杆上的 `B`）。

## 参考公式
- 斜面模型：`F_N = mg cos(theta)`、下滑力 `mg sin(theta)`、最大静摩擦 `mu mg cos(theta)`；**静止/匀速条件 `mu >= tan(theta)`**，等号时两者皆可（可静止也可匀速下滑）
- 斜面上静止时：斜面对物块的**合力竖直向上、大小 `mg`**；由牛顿第三定律，物块对斜面的力竖直向下 ⇒ 斜面**不受地面摩擦力**（这条对判断地面对斜面的摩擦方向极有用）
- 正 Y 模型：`F = 2 F_T cos(theta/2)`（`theta` 为两绳夹角，`F` 为反向的第三个力）
  - 特殊角：`theta = 60°` ⇒ `F = sqrt(3) F_T`；`theta = 120°` ⇒ `F = F_T`
  - 晾衣绳式：`cos(alpha) = d / l`、`F_T = mg / (2 sin(alpha))`（两段绳张力相等且夹角相等）
  - 动态：`F` 不变时 `theta` 越大 `F_T` 越大（"四两拨千斤"）
- g·tanθ 模型：`F_水平 = mg tan(theta)`、`F_斜 = mg / cos(theta)`；三力中任意两个不变 ⇒ 第三个不变（"放大镜"性质：重力按比例增大时三力等比例放大，夹角不变）

## 验算
- 斜面：先算 `mu` 与 `tan(theta)` 的**数值比较**（不带单位），再下结论；`mu > tan(theta)` 不会匀速下滑，`mu = tan(theta)` 才可能匀速。
- 正 Y：代回几何式 `d = l cos(alpha)` 核对角度；`sin(alpha) = 0`（绳绷直竖直）会给出无穷大张力，说明该几何情形**物理上不可能**，要报出来。
- 正 Y 动态：判断 `F_T` 变化时只看 `alpha`（角度）的变化方向，`F_T = mg/(2 sin(alpha))` 中 `mg` 不变、`alpha` 减小 ⇒ `sin` 减小 ⇒ `F_T` 变大。
- g·tanθ：用两组特殊角验证 —— `theta = 45°` 时水平力与重力相等；`theta -> 0` 时水平力趋于 0 而斜向力趋于 `mg`。
- 极限：`theta -> 90°`（斜面近竖直）时 `mu >= tan(theta)` 要求 `mu -> ∞`，物块必然下滑 —— 与直觉一致。
- 三力平衡的通用检验：三力必**共点**（或其延长线共点），否则不能平衡（题目给出不共点时要用转动条件，高中范围内通常不会）。

## 常见错误
- **把 `mu` 与 `sin/cos` 混着比**：静止判据是 `mu >= tan(theta)`，不是 `mu >= sin(theta)` 也不是 `mu cos(theta) >= 1`。
- 正 Y 模型里把"绳端上下移动"当成"角度变化"（其实 `d`、`l` 不变 ⇒ 角度不变 ⇒ 张力不变，这是本模型最反直觉的一条）。
- 把同一根绳两段的张力画成不相等（光滑挂钩、光滑滑轮时**必须相等**）。
- g·tanθ 模型里把 `theta` 取成与水平的夹角（结论会变成 `mg cot(theta)`）。
- 判摩擦力方向时只凭"运动趋势"的空想，而不去比较外部力与临界值 `mg tan(theta)`（或 `mg / sin(theta)`）。
- 物体其实在加速（斜面不够粗糙）却仍用"平衡态"的结论式。

## 生成后自检（必须逐条在代码中体现）
- [ ] 斜面题：代码里显式比较 `mu` 与 `Math.tan(theta)` 并由此分支（静止 / 匀速 / 加速），**不是**把状态写死。
- [ ] 正 Y 题：`alpha` 由 `Math.acos(d / l)` 算出（不是手填角度），且 `F_T = mg / (2 * Math.sin(alpha))` 由它推出；改 `d` 或 `l` 时 `F_T` 必须自动跟着变（这是自检动态结论的唯一办法）。
- [ ] g·tanθ 题：`theta` 的取角对象在代码注释里写明（"倾斜力与竖直方向"），且 `tan(theta)` 与 `cos(theta)` 用的是同一个 `theta`。
