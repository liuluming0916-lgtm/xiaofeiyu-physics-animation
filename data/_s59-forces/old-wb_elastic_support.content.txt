# 轻环、活结/死结、活杆/死杆的弹力方向判据

## 适用判据
被约束物是**轻质**（不计质量）的，判断"弹力沿哪个方向、两段绳张力是否相等"：
- **轻环**套在（光滑）杆上，被绳/外力牵引而平衡；
- 绳的一端被**光滑环**穿过 / 结点处是否同一根绳 ⇒ **活结 vs 死结**；
- 杆是**可绕铰链转动**（活杆）还是**固定不动**（死杆）。
反判据：有质量的杆、粗糙环、绳打结固定在某点上时都不是本题型。

## 建模步骤
1. **先判"轻"**：不计质量 ⇒ 它自己的重力为 0 ⇒ 它受力必须**平衡**（否则加速度无穷大）。这条是全部结论的来源。
2. **轻环**：设环受**两个**力（杆的弹力 `N` + 绳/外力的拉力 `F`）。二力平衡 ⇒ 两力等大反向共线 ⇒ **`F` 必垂直于杆**（曲杆时垂直于切线）。
3. **活结**（同一根绳穿过光滑环/滑轮，或绳套挂在光滑环上）：绳中张力**处处相等**，且两段绳的张力对结点的合力方向沿角平分线 ⇒ 可直接套**正 Y 模型**（`F = 2 F_T cos(theta/2)`）。
4. **死结**（结点处是几根**不同**的绳，或绳被固定在点上）：各绳张力**不一定相等**，必须把结点当研究对象，分别给每根绳设一个未知张力。
5. **活杆**（可绕一端无摩擦转动）：杆的力**一定沿杆**（只能拉或压）。
6. **死杆**（固定支架/折杆）：杆的力方向**不确定**，由物体状态决定：
   - 物体平衡 ⇒ 杆的力与其余力的合力等大反向；
   - 物体有加速度 ⇒ 杆的力由牛顿第二定律给出（常见结果 `F = sqrt((ma)^2 + (mg)^2)`，方向与竖直方向夹角 `tan(alpha) = a/g`）；
   - 特别地，只有当**加速度恰好等于 `g tan(theta)`**（`theta` 为杆与竖直方向的夹角）时，杆的力才沿杆。
7. **受力图只画一个研究对象**：轻环/结点自己是一张图，它连接的物体是另一张图。

## 参考公式
- 轻环平衡：`N = F`，且 `F` 垂直于杆的方向
- 活结（正 Y）：`2 F_T cos(theta/2) = mg` ⇒ `F_T = mg / (2 cos(theta/2))`（`theta` 为两段绳的夹角）
  - 特殊角：`theta = 60°` ⇒ 第三力 `= sqrt(3) F_T`；`theta = 120°` ⇒ 第三力 `= F_T`
- 死结（两绳互成 `theta`）：水平绳 `F_1 = mg tan(theta)`，斜绳 `F_2 = mg / cos(theta)`（`theta` 是斜绳与**竖直**方向的夹角）
- 死杆带加速度：`F = sqrt((m a)^2 + (m g)^2)`，`tan(alpha) = a / g`（`alpha` 为 `F` 与竖直方向的夹角）
- 死杆上力沿杆的条件：`a = g tan(theta)`（`theta` 为杆与竖直方向的夹角）
- 光滑滑轮上轻绳的方向：合力方向在**两段绳夹角的角平分线**上（原型题 1 求 `OP` 与天花板夹角就用它：`alpha = (pi/2 + theta)/2`）

## 验算
- **轻物必平衡**：若对轻环/轻杆列方程时算出合力不为 0，一定是漏了力或把方向搞错了。
- 张力比较：活结处**两段张力必须相等**；若方程解出不相等，说明结点其实是死结（两段是不同绳）。
- 方向自检：轻环受力的垂杆性 —— 用几何算出 `F` 与杆的夹角应为 90°（可数值核对）。
- 极限：`theta -> 0`（两段绳几乎平行）时活结 `F_T -> mg/2`；`theta -> 180°` 时 `F_T -> ∞`（这就是"四两拨千斤"，也说明夹角不可能真的到 180°）。
- 死杆：`a -> 0` 时 `F -> mg` 且竖直向上（退回静止情形）；`theta -> 0`（杆竖直）时"沿杆条件"要求 `a -> 0`，即竖直杆上只有静止（或竖直方向运动）时杆力才沿杆。
- 单位与量纲：`mg`、`ma` 同量纲，可作勾股合成；`theta` 只在 `tan/cos/sin` 里出现。

## 常见错误
- **把死结当活结**：直接令两段绳张力相等（死结题的第一大错）。
- **把活结当死结**：设了两个不相等的张力，反而多出未知量解不出来。
- 对轻环/轻杆**画上重力**（它们不计质量，重力为 0）。
- 认定"杆的力一定沿杆"（那只是**活杆**的性质；死杆的方向由状态决定）。
- 忘掉光滑滑轮那一条：重物的拉力方向沿绳，滑轮轴上的力方向在两绳夹角的角平分线上。
- 把 `g tan(theta)` 里的 `theta` 取成与水平方向的夹角。
