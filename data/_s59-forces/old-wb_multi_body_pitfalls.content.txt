# 连接体受力分析的高频陷阱：研究对象、内力与静摩擦的不确定性

## 适用判据
多选题或"下列说法正确的是"那一类**只问"有没有/方向如何"**的连接体题，尤其是：
- 两个以上物体叠放（`a` 在 `b` 上、`b` 在 `c` 上）或紧靠（含靠墙）；
- 斜面体上有物块（可能还有绳跨过定滑轮）；
- 问"某接触面有没有摩擦力"「某力方向如何」；
- 题面**没有给出**某个初始条件（通常是初始摩擦力的方向）⇒ 答案可能是"无法判断"或"具有不确定性"。
反判据：单一明确受力图、只求大小的题（用相应的模型词条）。

## 建模步骤
1. **先画"研究对象边界"**：把要分析的对象单独框出来。这是本题型 90% 错误的根源（不是物理错，是研究对象错）。
2. **判某个接触面有没有力，用"从最外层往里剥"的顺序**：
   - 先用**整体法**判"系统与外界"的接触面（地面/墙壁/悬绳）：若整体在该方向无外力需求 ⇒ 该处无摩擦；
   - 再用**隔离法**判"内部接触面"：挑受力最简单的那个隔离。
3. **力与反作用力的成对性检查**：`b` 对 `a` 的力与 `a` 对 `b` 的力必须等大反向共线。若某选项只给一个方向，用另一侧的受力去验。
4. **静摩擦的"不确定性"**：若某力的**初始方向未知**（题面没说它朝哪），则它的变化趋势**无法唯一判断**，此时：
   - 要么分情况讨论（给若干种可能）；
   - 要么如实回答"无法判断"「可能…也可能…"（**这就是正确答案**，不是回避）。
5. **"水平方向无外力 ⇒ 无摩擦"**：整体在水平方向若不受任何外力，则地面给系统的摩擦力必为零（原型题 12 的 C 项就是这样排除的）。
6. **"作用力方向竖直"的判据**：若某物体只受重力 + 另一物体给的作用力而平衡 ⇒ 那个作用力**必然竖直向上**、大小等于重力（原型题 12 的 D 项）。注意作用力是弹力与摩擦力的**合力**，不等于支持力。
7. **叠加体一起加速 / 一起自由落体的特例**：`a = g` 或 `a = g sin(theta)` 时层间**无弹力也无摩擦**（另见"摩擦力方向"词条）。
8. 最后逐项核对选项，并把"不确定"的项明确写成「可能/无法判断」。

## 参考公式
- 内力判据：内部接触面的力只能由**隔离**求出；整体法只能给外力
- 水平无外力 ⇒ 地面摩擦为零：`sum F_外,水平 = 0 ⇒ F_f = 0`
- 整体竖直方向：`F_N = G_总 - F_T sin(theta)`（有斜向拉力时**不等于**总重力）
- 二力平衡 ⇒ 方向共线：只受 `重力 + 某个合力` 而平衡 ⇒ 该合力竖直向上、大小 `mg`
- 恰好不滑动 / 刚好不下滑 ⇒ 该处摩擦力取最大静摩擦 `mu F_N`，且方向由"将要滑动的方向"反推
- 多接触面问题：**逐面**写 `mu_i F_Ni >= f_需要,i`，取**最严**的一个
- 静摩擦范围：`0 <= f <= mu F_N`（"方向未知"意味着它可以是零——这是"可能为 0"这类选项的依据）

## 验算
- **成对性**：任取一个接触面，把两侧的力都写出来，检查是否等大反向（不等就是研究对象混了）。
- **整体与隔离必须给同一个结果**：整体算地面的力、隔离算内部的力，两者在"系统与外界"的量上必须一致。
- 极限：`mu -> 0` 时所有"恰好不滑"的临界条件都退化为"必须有外力维持"；`m` 相同的对称系统 ⇒ 对称轴处内部力为零。
- 量纲与方向：`mu_i F_Ni` 是力，可直接与"需要的摩擦力"比较。
- 选项逐个核：每个"一定/不可能"的选项都要能举出**一个**反例或**一个**必然性论证。

## 常见错误
- **研究对象错**：把"物体受到的力"与"物体施加的力"画在同一张图上（牛顿第三定律被混用）。
- 把整体法的结论（如地面的支持力）当成某物块受到的力。
- 忘了"静摩擦方向未知 ⇒ 结论不确定"，硬给出"一定增大"（原型题 15、16 的选项就是这么设的）。
- 把"作用力"等同于"支持力"（忽略摩擦力会一起合成）。
- 水平方向明明没有外力，却仍画出地面的摩擦力。
- 多接触面题只算了一个面的临界（要取最严）。
- 把 `F_N = G_总` 用在有斜向拉绳的题上（漏了拉力的竖直分量）。

## 生成后自检（必须逐条在代码中体现）
- [ ] 代码里每个物体一个"受力清单"（数组或对象），且**同一接触面对两侧的力符号相反**（成对性可被机检）。
- [ ] 若某力方向题面未给：代码里把它做成**参数/多分支**，并输出"可能的取值范围"或"无法唯一确定"这个结论（不许写死方向）。
- [ ] "水平无外力 ⇒ 无摩擦"在代码里体现为：水平方向外力之和为 0 时，`f = 0`（作为一条显式分支）。
- [ ] `readouts` 至少给出"系统与外界的作用力"与"某个内部接触面的力"，两类都可逐时刻复现（C7），键与单位不变（C8）。
- [ ] 画面上把每个研究对象用**不同的框/颜色**圈出（研究对象边界在画面里可见），接触面的力用同一条线的两个反向箭头表示。
