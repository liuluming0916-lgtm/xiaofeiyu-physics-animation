# 摩擦力的临界判据：g·tan(theta)、mu g 与叠加体一起运动

## 适用判据
题目要求"两个物体**能否一起运动**""摩擦力的方向在一个**加速度临界值**两侧如何变化"：
- 斜面上的小球与斜面体一起水平加速（原型题 15）；
- 叠加体（物块在木板上）一起沿水平面加速，问木板的最大加速度；
- 传送带/转盘上物体刚要相对滑动；
- "恰好不滑动""保持相对静止"这类措辞。
反判据：只有单个物体受力、不存在"与谁一起动"的问题时，不需要本条。

## 建模步骤
1. **假设没有摩擦**（或假设"刚好要滑"），先算**临界加速度** `a_c`：
   - 斜面上一体运动：`a_c = g tan(theta)`；
   - 水平面上被摩擦力带动的物体：`a_c = mu g`；
   - 倾斜面上的叠加体：`a_c = g sin(theta) + mu g cos(theta)`（上表面带动）或含 `g sin(theta)` 的各种组合，一律"先假设光滑再补摩擦"。
2. **比较实际加速度 `a` 与 `a_c`**：
   - `a = a_c` ⇒ 摩擦力恰好为 0（或恰好达到最大），是**临界**；
   - `a > a_c` ⇒ 摩擦力指向"阻止相对超前"的方向（斜面上为沿面向下）；
   - `a < a_c` ⇒ 摩擦力反向（沿面向上）。
3. **求"一起运动"的最大加速度**：对需要摩擦来提供加速度的那个物体写 `f_max = mu F_N = m a_c`，解开 `a_c`。
4. 再**用整体法求所需外力**：对整个系统 `F = M_total a_c`（这一步常被漏掉，题目问的往往是外力而不是加速度）。
5. 反过来，若题给外力求"是否一起动"：先算系统共同加速度，再看该加速度是否超过 `a_c`。
6. 与叠加体**自由落体 / 光滑斜面**的两个特殊判据对照使用（`a = g` 时层间无弹力；`a = g sin(theta)` 时层间无摩擦）。

## 参考公式
- 斜面一体运动临界：`a_c = g tan(theta)`（此加速度下摩擦力为 0）
- 水平面带动：`a_c = mu g`（`mu` 为接触面动摩擦因数）
- 倾斜面上叠加体一起下滑：`a_c = g sin(theta)`（无摩擦）或 `g(sin(theta) + mu cos(theta))`（靠摩擦带动下层/上层）
- 一起运动的最大加速度：`a_c = f_max / m = mu F_N / m`
- 系统所需外力：`F = (m + M) a_c`
- 判定方向：`a` 与 `a_c` 的大小关系 ⇒ 摩擦力方向（见建模步骤 2）

## 验算
- **量纲与量级**：`g tan(theta)`、`mu g`、`g sin(theta)` 都是 `m/s^2`，可直接比较；`mu` 与 `tan(theta)` 都无量纲。
- 极限：`theta -> 0` 时 `a_c -> 0`（水平面上不靠摩擦就能一起动，临界加速度为 0，摩擦力也为 0）；`mu -> 0` 时 `a_c -> 0`（光滑面无法带动）。
- 双向核对：把 `a = a_c` 代回**隔离体**方程，算出的摩擦力必须小于 1e-9（即 0）。
- 反解检查：求出 `a_c` 后，用它回算摩擦力，必须恰好等于 `mu F_N`（临界就是"刚好达到上限"）。
- 与整体法一致：整体法给的外力与隔离法逐物体求和必须相同（两种方法互检）。

## 常见错误
- **把 `a_c` 当成"能一起运动的加速度"本身**（它是**上限**，超过就相对滑动）。
- 忘了题目问的是**外力**，算出 `a_c` 就停手（还要 `F = (M+m) a_c`）。
- 斜面模型里把 `theta` 取成与水平方向的夹角（结论会变成 `g cot(theta)`）。
- 判定摩擦力方向时不与临界比较，而是凭"看起来会往上滑"的感觉。
- 把 `f_max = mu F_N` 里的 `F_N` 写成 `mg`（斜面上应是 `mg cos(theta)`）。
- 多个接触面时只算了一个面的临界（要**取最严**的那个，见砖块问题）。

- [ ] 代码里有一个分支：`a === aCrit` ⇒ 摩擦力为 0（用容差判定）；`a > aCrit` 与 `a < aCrit` 两种情形摩擦力符号相反（都能在画面上看出）。
- [ ] 若题问外力，代码里算的是 `F = (M + m) * aCrit` 并作为 `ANSWERS` 的一项。
- [ ] `readouts` 给出摩擦力的**有符号值**（正负表示方向），而不是只给大小——方向是本词条的核心结论。
