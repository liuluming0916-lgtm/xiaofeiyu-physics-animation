# 三种受力结构与临界判据

## 适用判据
三力（或可化为三力）问题的三种**固定受力结构**，先认结构再套结论：
- **斜面模型**：物体在斜面上（静止、匀速下滑或恰好将滑）。判据是 `mu` 与 `tan(theta)` 的大小关系（**与质量无关**）。
- **正 Y 模型**：质点受**两个等大的力**（通常是同一根绳的两段）加一个重力而平衡 ⇒ **两段绳与水平方向的夹角相等**，夹角被绳长与两端水平间距**锁死**（`cos(alpha) = d / l`）。
- **g·tanθ 模型**：三个力两两垂直或互成特殊角而平衡 ⇒ `F_水平 = mg tan(theta)`、`F_斜 = mg / cos(theta)`（`theta` 是倾斜力与**竖直**方向的夹角，找错角是唯一难点）。
**临界题**（"恰好不滑""保持相对静止""能否一起运动"）也走本条：先算临界加速度 `a_c`（斜面一体 `g tan(theta)`、水平面被带动 `mu g`、倾斜面叠加体 `g(sin(theta)+mu cos(theta))`），再由 `a` 与 `a_c` 的关系定摩擦方向。
反判据：物体在**加速**（合外力不为零）时不能直接套结论式，只能借它的**结构**（力的方向关系），方程仍要走牛顿第二定律。

## 建模步骤
1. **先认结构**：画出三力的方向关系，再判它属于哪一种（换外壳不换结构："斜面上的小球"与"水平绳 + 斜绳的结点"受力图完全相同）。
2. **斜面**：重力沿面/垂直面分解 ⇒ 比较 `mg sin(theta)` 与 `mu mg cos(theta)`，判据是 `mu` 与 `tan(theta)` 比大小。
3. **正 Y**：水平方向给出**两段绳与水平方向夹角相等**，竖直方向 `2 F_T sin(alpha) = mg`，几何 `d = l cos(alpha)`。
   - **动态结论（原型题核心）**：绳端上下移动不改 `d`、`l` ⇒ `alpha` 不变 ⇒ **`F_T` 不变**；把一端**水平拉开** ⇒ `d` 变大 ⇒ `alpha` 变小 ⇒ `F_T = mg/(2 sin(alpha))` **变大**。
4. **g·tanθ**：直接写 `F_水平 = mg tan(theta)`、`F_斜 = mg / cos(theta)`；三力中任意两个不变则第三个不变（"放大镜"性质：重力按比例放大时三力等比例放大、夹角不变）。
5. **变式**：若实际外力与"无摩擦临界值"不等，摩擦方向由**偏差方向**定 —— 外力偏大 ⇒ 物体有沿斜面向上的趋势 ⇒ 摩擦力沿斜面向下；偏小则反之。
6. **临界题**：假设光滑（或假设"刚好要滑"）求出 `a_c`，再由 `a` 与 `a_c` 比较定方向（`a = a_c` ⇒ 摩擦力为 0）；问外力则再乘总质量。
7. 需要时把整体/隔离嵌进来（弹簧连接的两球、穿在杆上的 `B`）。

## 参考公式
- 斜面：`N = mg cos(theta)`、下滑力 `mg sin(theta)`、最大静摩擦 `mu mg cos(theta)`；静止或匀速下滑的判据 **`mu >= tan(theta)`**
- 斜面上静止时斜面对物块的合力竖直向上、大小 `mg` ⇒ 物块对斜面的力竖直向下 ⇒ **地面对斜面不受摩擦**
- 正 Y：`F = 2 F_T cos(theta/2)`（`theta` 为两绳夹角）；`theta = 60°` ⇒ `F = sqrt(3) F_T`；`theta = 120°` ⇒ `F = F_T`；晾衣绳式 `F_T = mg / (2 sin(alpha))`
- g·tanθ：`F_水平 = mg tan(theta)`、`F_斜 = mg / cos(theta)`
- 临界加速度：斜面一体 `a_c = g tan(theta)`；水平面被带动 `a_c = mu g`；倾斜面叠加体 `a_c = g(sin(theta) + mu cos(theta))`（光滑时 `g sin(theta)`）
- 一起运动的最大加速度 `a_c = mu N / m`；系统所需外力 `F = (m + M) a_c`
- 特殊判据：`a = g` ⇒ 层间无弹力无摩擦；`a = g sin(theta)` ⇒ 光滑斜面上的叠加体层间无摩擦

## 验算
- 斜面：先把 `mu` 与 `tan(theta)` 的**数值**比出来（两边都无量纲）再下结论。
- 正 Y：代回几何式 `d = l cos(alpha)` 核对角度；`sin(alpha) = 0`（绳绷直竖直）时张力发散，说明该极限不可达。
- 临界双向核对：`a = a_c` 代回隔离体方程算出的摩擦力必须为 0（或恰好等于 `mu N`）；整体法给的外力与隔离法逐物体求和必须一致。
- 量纲：`g tan(theta)`、`mu g`、`g sin(theta)` 都是 `m/s^2`，可直接比较。
- 极限：`theta -> 0` 时 `a_c -> 0`（水平面上不靠摩擦也能一起动）；`mu -> 0` 时 `a_c -> 0`（光滑面无法带动）。

## 常见错误
- 斜面题里把 `theta` 取成与**水平**方向的夹角（结论会误写成 `g cot(theta)`）。
- 把 `a_c` 当成"能一起运动的加速度"本身（它是**上限**，超过就相对滑动）。
- 算出 `a_c` 就停手，忘了题目问的是外力。
- 判定摩擦方向时不与临界比较，而凭"看起来会往上滑"的感觉。
- 把 `f_max = mu N` 里的 `N` 写成 `mg`（斜面上应是 `mg cos(theta)`）。
- 多接触面只算了一个面的临界（要**取最严**的那个）。
- 把 `mu > tan(theta)` 的情形判成"匀速下滑"（`mu > tan(theta)` 时根本不会匀速下滑，等号才可能）。

## 生成后自检（必须逐条在代码中体现）
- [ ] 代码里有显式的 `aCrit`，且它由物理条件算出（`g * Math.tan(theta)` 或 `mu * g`），**不是手填的数字**。
- [ ] 三种结构各有独立的分支/函数（斜面、正 Y、`g·tan(theta)`），不要混成一个万能公式。
- [ ] 正 Y 的两条动态结论（上下移动不变、水平拉开变大）在 `setup()` 里被**数值验证**（扫两个端点值并断言）。
- [ ] 临界处有**微扰自检**：`a_c ± 0.1` 必须分别落在两种情形（方向相反）。
- [ ] 自锁/静止判定用 `mu >= Math.tan(theta)` 写，不用比较两个力的数值（避免量纲混用）。
