## 解题

### 适用判据
合力为零（静止/匀速）而要求解力的大小方向，或问"**缓慢**移动/转动时某个力如何变化"，或求某个力的**最小值/临界角**。工具按"变的是谁"选，**选错工具是本题型唯一但致命的错误**：
- 未知量 ≤ 2 且角度已知 ⇒ **正交分解**或**矢量三角形**（三力与三个角一一对应，比正交分解更快）；
- 图中存在与力三角形**相似且顶点不变**的几何三角形 ⇒ **相似三角形法**（相似比为常数）；
- 只有一个力的**方向**变（另两力方向不变）⇒ **矢量三角形动态图**；
- 两个力的方向都变、但**彼此的夹角不变** ⇒ **动态圆法**（等弦对等圆周角 ⇒ 外接圆半径不变）；
- 其余情况（方向都变、找不到顶点不变的相似三角形、角度已知）⇒ **正弦定理**，三个力以上则**正交分解 + 辅助角**。
反判据：合力不为零（物体在加速）时先转牛顿第二定律；相似三角形法的"顶点不变"不成立时必须改正弦定理。

### 建模步骤
1. **先锁定"不变的那个力"**：几乎总是重力（大小方向都不变），它是全部动态题的支点。
2. **数"变的是几个力的方向"**，据此选工具（见上）。
3. **矢量三角形**：以重力为定边画闭合三角形，让变化力的方向按题意转动，读另两边的长度变化；极值出现在该力与另一个力**垂直**时（常见结论"先减小后增大"）。要注意三角形画在重力**哪一侧** —— 判据是"**以重力为界，与题图相反**"。
4. **相似三角形**：写出相似比（如 `mg / MO = F_N / AO = F_T / AM`），`mg`、`MO`、`AO` 是定值 ⇒ **相似比是常数** ⇒ 哪个几何边变短，对应的力就变小（本类题最快的路）。
5. **动态圆**：两个变力夹角不变 ⇒ 它们在同一个外接圆上，读弦长的增减。
6. **正弦定理**：`F_1 / sin(a) = F_2 / sin(b) = mg / sin(gamma)`（一个三连等 = 两个独立方程）。
7. **三力以上**：用辅助角把合力写成 `A sin(theta + phi)`；或**等效成三力**再套上面的工具。
8. **极值三条捷径**：某力大小方向已定、求另一个力最小 ⇒ **两力垂直时取最小**；斜拉匀速求最小 ⇒ `F_min = A / sqrt(1 + mu^2)`（`A` 是**不加这个力时沿运动方向的合力**，`tan(phi) = 1/mu`）；拉力方向固定求另一力最小 ⇒ 矢量三角形里垂直时取最小。
9. **自锁**：把摩擦与支持力合成**全反力**，它与支持力的夹角是**摩擦角** `phi_m`（`tan(phi_m) = mu`）；外力与支持力的夹角 `<= phi_m` 时**无论多大都不滑动**。自锁与质量无关，验算时把 `m` 换成 `2m` 临界角必须不变。
10. **非质点**（棒、链）：先用**三力汇交**定出未知力的方向；连续体等效成质点（放重心）或用整体法合成分解。

### 参考公式
- 平衡 `sum F_x = 0`、`sum F_y = 0`；三力平衡必**共点**（三力汇交原理用来定方向）
- 正弦定理 `F_1 / sin(theta_1) = F_2 / sin(theta_2) = F_3 / sin(theta_3)`
- 相似三角形 `mg / 几何边 = F_T / 几何边 = F_N / 几何边`（顶点不变 ⇒ 比值是常数）
- 动态圆：两力夹角 `(pi - alpha)` 不变 ⇒ 同一外接圆；弦长即力的大小
- 全反力 `F_R = sqrt(N^2 + f_max^2)`，`tan(phi_m) = mu`，滑动时 `F_R` 方向不变（`f` 与 `N` 等比例变化）
- 自锁判据：外力与支持力夹角 `<= phi_m`；等价写法 `tan(theta_0) = mu`（水平面压物）
- 斜拉匀速最小力 `F_min = mu mg / sqrt(1 + mu^2)`（水平面）；`F_min = (mg sin(alpha) + mu mg cos(alpha)) / sqrt(1+mu^2)`（斜面）；匀加速时分子再加 `m a`
- 辅助角：`cos(theta) + mu sin(theta) = sqrt(1+mu^2) sin(theta + phi)`，`tan(phi) = 1/mu`

### 验算
- 矢量三角形的三个内角必须能凑成 180°；凑不上就是某个力的方向取反了。
- 相似比逐项核对"分子分母是同一对"（写错一对，答案差一个因子）；并在**两个**位置各代一次几何边长，比值必须相同。
- **静态题**：`mu -> 0` 时 `F -> 0`；`theta -> 0` 时 `F -> mu mg`（斜拉退化为水平拉）。
- **动态题**：单调性至少核两个端点（`theta -> 0` 与 `theta -> pi/2`），有极值的必须指出极值点；注意"某个力有最小值"与"其功率 `F cos(theta)` 单调减小"不矛盾，两句话都要能说清。
- **自锁/极值**：`sqrt(1+mu^2)` 必须出现在分母；极值角度必须落在题设范围 `[0, pi/2]` 内，否则最值在**端点**；`mu -> 0` 时 `F_min -> 0`。
- 等效重力：物体再加一个**竖直**恒力时并入重力（`G_eff = mg + F` 或 `mg - F`），此后摩擦与支持力按同一比例放大、方向不变 ⇒ 仍自锁。

### 常见错误
- 矢量三角形画在**重力同侧**，导致相似关系对不上。
- **用相似三角形却不检查"顶点不变"**：拉动过程中几何三角形顶点若跟着变，相似比就不再是常数。
- 未知量已超过两个仍硬用矢量三角形（解不出来还以为是自己算错）。
- 加了竖直恒力后只改重力不改支持力/摩擦力（等效重力必须整体替换）。
- 忘了 `sqrt(1+mu^2)`，把最小力写成 `mu mg`（那是 `theta = 0` 的值，通常不是最小）。
- 认为"力越大越容易推动"（自锁时无论多大都推不动），自锁题里去讨论质量、重力。
- 四个力的题直接套三力结论（要先定"忽略待求力时的合力"）。

## 动画建模

### 阶段怎么切
- 平衡题**没有物理阶段**：切的是"**几何位置序列**"。把缓慢过程参数化成 `u ∈ [0, 1]`，每个关键位置（初始、极值点、题设终点）就是一个边界。
- 边界时刻从 `setup()` 里的扫描结果取（极值点、力的方向与另一力垂直的位置），不许在 `drawFrame` 里"看情况"。
- 静态题只有一帧内容，`SIM.duration` 取 1–2 s 用于平滑展示 `u` 的推进；`stateAt` 必须 O(1)。

### 每个边界怎么表达
- 每个边界对应**一组力的大小与方向**（由 `u` 算出），用 `RETURN('uStar', uStar)` 之类把边界参数导出，让画面转折与数据转折是同一个数。
- 边界处画细竖线或小圆点标记，并写明"该处 `F` 取极小"这类不超过 6 字的标注。
- 力的大小变化用箭头长度体现，**零力不画满长箭头**（画点）。

### 实体与标注怎么挂
- 三力闭合三角形用 `Draw.arrow` 逐边相接（首尾相接），起点取力的作用点；重力那条边固定不动。
- 实体（绳、斜面、接触面）与力箭头分开类别：`Draw.line` 画绳、`Draw.incline` 画斜面，力一律 `Draw.arrow(..., { category: 'force' })`，前端开关才能各自关掉。
- 角度标注用 `Draw.dimension(..., { kind: 'angle' })`，摩擦角那种"看不见的角"要显式画出来（自锁题的关键就是它）。

### 特殊渲染需求
- 动态过程的"轨迹"画在**力的矢量图上**（顶点移动的弧线），用 `Draw.trace(...)`，这样"动态圆"这件事在画面上可见。
- 极值点与自锁临界角各给一个视觉标记（虚线 + 角标），不要只靠文字说明。
- 标注全部用世界坐标与米，禁止像素坐标。

### 生成后自检（必须逐条在代码中体现）
- [ ] 力的矢量图与实体图**同一坐标系、同一比例尺**（同一组力在两个图里长度一致）。
- [ ] `u = 0` 与 `u = 1` 两个端点的力学状态都在 `readouts` 里可读，且与解析式对得上。
- [ ] 极值点/临界角的标记位置取自 `setup()` 算出的常量（不是画面上目测的位置）。
- [ ] 所有 `Draw.*` 只用世界坐标；`stateAt(t)` O(1) 且全时段有定义。
