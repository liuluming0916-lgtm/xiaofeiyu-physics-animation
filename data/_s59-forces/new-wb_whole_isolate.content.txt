## 解题

### 适用判据
**多个物体**（连接体、叠放体、斜面体+物块、绳跨滑轮）处于平衡或一起运动，要求某个力、某个夹角或某个质量比。选法只有一句话：
- 该力是系统**外力**（地面支持力/摩擦力、悬绳张力、推力、墙壁弹力）⇒ **整体法**；
- 该力是系统**内力**（两物体间的弹力/摩擦力、中间绳杆弹簧的张力）⇒ **隔离法**，且要挑**受力最简单**的那个物体隔离。
反判据：单物体题用不上；求内力却用整体法必然解不出来（内力在整体方程里成对抵消）。

### 建模步骤
1. **圈定系统**：明确"把谁和谁算作一个整体" —— 换系统就换内外力，这是本题型唯一的自由度。
2. **按"问题问的是内力还是外力"选法**，不要凭习惯。
3. **整体法只画外力**（总重力 + 外界给的力），写 `sum F = 0` 或 `= (sum m) a`；系统内部的绳/杆/弹簧力**一律不画**。
4. **隔离法**挑最简单的一个物体单独画，目的通常是**暴露连接介质里的力**（绳张力、弹簧弹力、接触面弹力/摩擦）。
5. **两法配合的固定套路**：先**整体**定与外界有关的量（地面摩擦、支持力、悬绳方向），再**隔离**定内部量，最后用"同一根绳/杆/弹簧的力大小相等"把两者接起来。
6. **求两球之间绳的方向**：外围绳是外力 ⇒ 整体法定方向；两球之间的绳是内力 ⇒ 隔离末端的球定方向。常见结论是"某球恰在悬点正下方"（两个正切值相等）。
7. **求质量比**：隔离两侧，用**同一个连接介质的力**（`F_T` 或 `k x`）在两边相等的条件建立等式。
8. **判某个接触面有没有力：从最外层往里剥** —— 先用整体法判系统与外界的接触面（该方向整体无外力需求 ⇒ 该处无摩擦），再用隔离法判内部接触面。
9. **陷阱三件套**：① 研究对象错（把"某物受到的力"与"它施加的力"画在同一张图上）；② **静摩擦方向未知 ⇒ 结论不确定**，此时应分情形讨论或如实写"无法判断"；③ 整体在水平方向无外力 ⇒ 地面摩擦必为零。
10. **两条捷径判据**：某物体只受重力 + 另一物体的**一个**作用力而平衡 ⇒ 那个作用力必**竖直向上**、大小等于重力（注意它是弹力与摩擦力的**合力**，不等于支持力）；叠加体一起自由落体或沿光滑斜面下滑 ⇒ 层间无弹力无摩擦。

### 参考公式
- 整体 `sum F_外 = 0`（平衡）或 `= (sum m) a`（一起加速）
- 整体法给地面支持力 `F_N = G_总 - F_T sin(theta)`（有斜向拉力时**不等于** `G_总`）；给地面摩擦力 `F_f = F_T cos(theta)`
- 悬绳方向（整体）`tan(alpha) = （两球水平力的合力）/（总重力）`；内部绳方向（隔离末端球）`tan(beta) = （该球受到的水平力）/（该球的重力）`
- 同一根绳（或跨光滑滑轮/挂钩）两端张力相等；正 Y 式 `2 F_T cos(theta/2) = 该结点下方总重力`
- 水平无外力 ⇒ 地面摩擦为零：`sum F_外,水平 = 0 ⇒ F_f = 0`
- 多接触面：逐面写 `mu_i N_i >= f_需要,i`，取**最严**的一个
- 静摩擦范围 `0 <= f <= mu N`（"方向未知"意味着它可以是零 ⇒ "可能为 0"这类选项的依据）

### 验算
- **两法互检**：整体方程与各隔离体方程相加必须得到同一个整体方程（差值应为 0）。
- 整体方程里逐项问"这个力是谁对谁的"；系统内部的相互作用**划掉**。
- 成对性：任取一个接触面，两侧的力必须等大反向共线（不等就是研究对象混了）。
- 对称性：轴对称系统解出"对称轴处摩擦不为 0"，一定是分层取错了。
- 极限：`F_T -> 0`（绳松弛）时内部联系消失，各部分各自竖直悬挂；`alpha -> 0` 时系统整体水平力为零（各球水平力互相抵消）。
- 角度定义统一：外围绳与内部绳的角都要与**同一方向**（如竖直方向）比较，否则"相等"会变成互补。

### 常见错误
- **在整体受力图上画了内力**（最典型：把两球之间绳的张力也画上）。
- 求内力却用整体法，然后抱怨"方程不够"；或隔离了**受力最复杂**的那个物体，把自己绕进死胡同。
- 把整体法的结论（地面的支持力）当成"某物块受到的弹力"。
- 把"同一根绳"与"两根绳"混了（只有同一根绳或跨光滑滑轮的两段张力才相等）。
- 忘了绳子还可能**松弛**（`F_T = 0` 的分支要单独判）。
- 静摩擦方向未知却硬给"一定增大/一定减小"，而不给"无法判断"或分情形。
- 水平方向明明没有外力，却仍画出地面摩擦力。
- 多接触面题只算了一个面的临界（要取最严）。
- 把 `F_N = G_总` 用在有斜向拉绳的题上（漏了拉力的竖直分量）。

### 生成后自检（必须逐条在代码中体现）
- [ ] 代码里把"系统"写成显式集合（如 `const system = ['A','B']`），整体方程只累加**含外界接触**的力项 —— 内外力在代码结构上就分开了。
- [ ] 内部接触面的力只出现在隔离体方程里；整体方程里出现该力即为错（可断言）。
- [ ] 方向未知的内部力用**符号量**表示，并在 `readouts` 里给出"范围/可能为 0"，不写死一个方向。
- [ ] 两法互检在 `setup()` 里被断言（整体方程 − 各隔离体方程之和 ≈ 0）。
- [ ] "同一根绳张力相等"与"绳可能松弛（`F_T = 0`）"两条各有显式分支。

## 动画建模

### 阶段怎么切
- 平衡/准静态连接体题**没有物理阶段**：切的是"**几何位置序列**"（拉动、缓慢转动的过程）。用归一化参数 `u ∈ [0, 1]` 推进，把题设的几个关键位置（初始、平衡判定的临界位置、终点）当作边界。
- 若题目含"恰好不滑/恰好松弛"的临界，那一刻就是**唯一的重要边界**，边界参数在 `setup()` 里由等式解出并导出（`RETURN`），不许在 `drawFrame` 里目测。
- 一起加速的问题才有真阶段：切"运动模式变化"处（共速、分离、绳绷紧）。

### 每个边界怎么表达
- 边界处必须**同一根绳的长度不变**、位置连续；绳松弛的边界之后张力取 0 且形状改为竖直下垂，这个突变要在画面上有标记。
- 每个关键位置画细竖线或小圆点，标注"绳恰绷紧"这类 ≤ 6 字的短语。
- 导出量（`tan(alpha)`、`F_T`、地面摩擦）走 `RETURN`，`stateAt` 只读不重算。

### 实体与标注怎么挂
- 每个物体一个 `stateAt` 字段（`xA`、`xB`、`xC`），箭头的起点直接取它，**不许另算一份**；整体边界用 `Draw.polygon(..., { dash: true })` 画虚线框把成员圈起来。
- 绳用 `Draw.line`，滑轮用 `Draw.pulley`，地面/墙面用 `Draw.ground`；系统**内部的绳**与外界悬绳要用不同线型或标注区分（"谁是内力"必须在画面上看得出来）。
- 力的箭头一律 `Draw.arrow(..., { category: 'force', subtype: ... })`，把 `tension` / `normal` / `friction` 分开，前端能各自开关。

### 特殊渲染需求
- 必须能在画面上区分"整体"与"隔离"两种视图口径：同一次渲染里既有整体虚线框（对外力）、又有被隔离物体的实线轮廓（对内力），并各挂一条标注。
- 成对的内力（`A` 拉 `B` 与 `B` 拉 `A`）画成两个反向箭头，直观体现"它们互相抵消"。
- 禁止像素坐标；实体一律世界坐标（米），视口交给系统自动决定。

### 生成后自检（必须逐条在代码中体现）
- [ ] 系统边界（虚线框）的顶点由成员位置算出，成员动了框跟着动 —— 不能是写死的矩形。
- [ ] 内力箭头成对出现且方向相反（`A→B` 与 `B→A` 各画一条），长度相等。
- [ ] `u = 0` 与 `u = 1` 的位置与解析式对得上，并在 `readouts` 里可读。
- [ ] 若含临界边界，其时刻/参数取自 `setup()` 的常量；`stateAt(t)` O(1)、全时段有定义。
