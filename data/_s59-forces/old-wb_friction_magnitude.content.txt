# 摩擦力大小：muF_N、被动的静摩擦与动/静突变

## 适用判据
要算摩擦力（或最大静摩擦）的大小：
- 已知 `mu` 与压力求滑动摩擦力；
- 静摩擦（大小由**外力的需要**决定，需要反解）；
- "恰好不滑""刚好滑动"这类临界，用 `f_max = mu F_N` 取等号；
- 沿斜面缓慢改变倾角、或外力随时间线性增大，问摩擦力的**变化规律**。
反判据：只问方向的题用"摩擦力方向"词条；传送带共速后的连续过程请两条合看。

## 建模步骤
1. **先判静/动**：有相对滑动 ⇒ 用 `mu F_N`；没有 ⇒ 是静摩擦，**大小待定，由平衡/牛顿第二定律反解**。
2. **算 `F_N` 时要看真实受力**：不能一律写 `mg`。斜面 `F_N = mg cos(theta)`；有水平推力压墙时 `F_N = F`；有竖直方向加速度时 `F_N` 会变（`F_N - mg = m a_y`）。
3. **求最大静摩擦临界**：令 `f = f_max = mu F_N` 并与"需要多少摩擦"联立（可能要先做**勾股合成**：两个方向都要靠摩擦时 `f = sqrt(f_1^2 + f_2^2)`）。
4. **静摩擦的反解**：先假设方向（如沿斜面向上为正），由平衡解出符号；负值说明方向相反。
5. **变化规律题要分初值讨论**：初始时刻的静摩擦**方向未知** ⇒ 至少三种初值情形（`F = mg sin(theta)`、`F > mg sin(theta)`、`F < mg sin(theta)`），分别给变化趋势。
6. **动 ↔ 静转变**（本题型最能考人）：把"摩擦力 = 重力"的时刻当作分界：
   - 之前：滑动摩擦随 `F_N` 线性变化，物体做**加速度逐渐减小**的加速运动；
   - 相等时：加速度为 0，**速度最大**；
   - 之后：滑动摩擦继续增大并超过重力 ⇒ 物体做**加速度逐渐增大**的减速运动，直到速度为零；
   - 速度为零的那一刻：摩擦力由滑动摩擦**突变为静摩擦**，大小可能**跳变**（通常由 `mu F_N > mg` 跳回 `mg`）。
7. **缓慢旋转斜面**：倾角增大过程中会**先静摩擦后滑动摩擦**（转折点是 `tan(alpha) = mu`）；题目给"两个角度的摩擦力恰好相同"，就是拿静摩擦式与滑动摩擦式相等去解 `mu`。

## 参考公式
- 滑动摩擦：`f = mu F_N`（只由 `mu` 与 `F_N` 决定；与相对速度、接触面积**无关**）
- 最大静摩擦：`f_max = mu_s F_N`（题面常给 `mu_s = mu`）
- 静摩擦的范围：`0 <= f <= f_max`（具体值由外力的需要决定）
- 斜面静止：`f = mg sin(theta)`（沿面向上，未到临界）
- 斜面临界：`mu >= tan(theta)`（等号时"恰好静止"或"匀速下滑"）
- 缓慢旋转斜面求 `mu`：静摩擦 `mg sin(alpha_1)` 与滑动摩擦 `mu mg cos(alpha_2)` 相等
- 两个方向都要靠摩擦时：`f = sqrt(F^2 + (mg sin(theta))^2)`；临界 `= mu mg cos(theta)`
- 外力与控制：若 `F_N = k t`，则滑动摩擦 `f = mu k t`（随时间线性增大），加速度 `a = g - mu k t / m`，速度最大出现在 `t = mg/(mu k)`

## 验算
- **变化的连续性**：静摩擦在自身范围内可以任意变化；滑动摩擦由 `F_N` 决定。但**静 → 动**与**动 → 静**的转折点上，摩擦力大小**允许跳变**，此时"连续性"不是判据（要改判"受力是否满足平衡/牛二"）。
- 逐时刻核对：把 `f`、`v`、`a` 三个量同时算出来，检查 `a` 与 `v` 的符号关系（同号加速、异号减速）是否与题述一致。
- `f <= f_max` 必须全程成立；若解出 `f > mu F_N`，说明它其实已经在滑动，假设错了。
- 极限：`mu -> 0` 时 `f -> 0`；`theta -> 90°` 时 `F_N -> 0` 故 `f -> 0`。
- 量纲：`mu` 无量纲，`F_N` 与 `f` 同为牛顿；讨论 `mu` 与 `tan(theta)` 时两边都无量纲。

## 常见错误
- 认为"接触面积越大摩擦力越大"或"速度越大摩擦力越大"（两者都不影响；`F_N` 不变则 `f` 不变）。
- 把 `F_N` 一律写成 `mg`（有外加压力/竖直加速度时都错）。
- 用 `mu F_N` 去算**静**摩擦（静摩擦必须反解，`mu F_N` 只是它的上限）。
- 变化规律题只给一种情形（忘了初值方向的三种可能）。
- 动→静突变处硬套连续（忽略了速度为零那一刻的跳变）。
- 缓慢旋转斜面时，对 `alpha = 45°` 仍用静摩擦式（需先判断它是否已经滑动）。
