# 受力分析总纲：按"重力→弹力→摩擦力"逐一判定

## 适用判据
只要题目涉及"分析受力""求受力个数""画出受力示意图""某个力是否存在"，或**任何**需要先列受力才能往下算的题（平衡、牛顿第二定律、功、动量），都以本条为第一步。
反例：题面已明确给出"受三个力"且要求只做计算时，可直接进入相应模型词条；但**受力图仍然要照本条画**。

## 建模步骤
1. **先定研究对象**：单个物体、结点、还是"整体"。要隔离就明确隔离谁（`A` / `B` / 结点 `O`）。
2. **按固定顺序找力，一步都不许跳**：**重力（及其它已知场力）→ 弹力 → 摩擦力**。
   - 弹力：**只有接触且有弹性形变**才有。轻绳只能拉（沿绳）、轻杆可拉可压、接触面只能压（沿法线）。
   - 摩擦力：**接触面粗糙 + 有弹力 + 有相对运动（或趋势）** 三条件齐全才有；接触面无弹力 ⇒ 一定没有摩擦力。
3. **把"有没有"逐个判死**，不要凭感觉：绳无力的典型是"二力平衡迫使它为零"；面无力/无摩擦的典型是"整体法证明它为零"（见下）。
4. **画受力图**：所有力从**质心**（或公共作用点）出发，带箭头与符号；同一个物体上的力不共点时要标出作用点。
5. **再决定怎么分解**：优先选"让尽量多的力落在坐标轴上"的方向（常取运动方向 / 接触面）；**已经相互垂直的力永不分解**——只分解落单的那个（通常是重力）。
6. **加速度不共线时分解加速度**：若三个力已两两垂直而加速度是斜的，就保留三个力、把加速度分解到两轴上，再列牛顿第二定律。
7. 需要时**力与加速度同时分解**（斜面上被水平拉动、斜面整体在加速等）。
8. 最后**用平衡或牛顿第二定律列方程**，得到的是纯代数问题。

## 参考公式
- 重力分解（沿斜面/垂直斜面）：沿面向下 `mg sin(theta)`（俗称"下滑力"），垂直面向里 `mg cos(theta)`（表现为"正压力"）
- 正交分解：`F_x = F cos(a)`，`F_y = F sin(a)`；合力 `F = sqrt(F_x^2 + F_y^2)`
- 牛顿第二定律（分方向）：`F_x合 = m a_x`，`F_y合 = m a_y`
- 弹力：轻绳张力沿绳、处处相等（同一根绳）；弹簧 `F = k x`（见"弹力"词条）
- 摩擦力：静摩擦 `0 <= f <= f_max`，方向由**相对运动趋势**定；滑动摩擦 `f = mu F_N`，方向沿接触面、与**相对运动方向相反**
- 斜面上静止的判据：`mu >= tan(theta)`（最大静摩擦不小于下滑力）

## 验算
- **力的个数对账**：画完图后数一遍，并逐个回答"它由哪个接触面/哪个场提供"；答不出来的力就是多余的。
- **牛顿第三定律**：若把 `A` 对 `B` 的力与 `B` 对 `A` 的力都画在**同一个受力图**上，一定错了（受力图必须只属于一个研究对象）。
- 极限检查：令 `theta -> 0` 时 `mg sin(theta) -> 0`、`F_N -> mg`（退回水平面）；`mu -> 0` 时静摩擦上限为零（光滑）。
- 方向检查：静摩擦力的方向可以**先假设、再由平衡条件反解符号**；解出负值就是方向假设反了，不是算错。
- 单位：`mg` 与 `mu F_N` 同量纲；`tan(theta)` 是无量纲，不能与力比较（要比较 `mu` 与 `tan(theta)`）。

## 常见错误
- **漏力或多力**：漏"接触面的静摩擦"（因为没意识到有相对运动趋势）、多画"下滑力"（它是重力的分量，**不是**额外的力）。
- **把重力的分量当成两个独立的力**画进受力图（受力图里只有**一个**重力）。
- 把"绳的张力"画成沿水平方向（轻绳的力必须沿绳）或把绳画成有质量的杆。
- 接触面无弹力却仍画摩擦力（三条件缺一，必错）。
- **该用整体法时用了隔离**（反之亦然）：判断"接触面之间的力"要用隔离+整体配合，顺序是先整体定外力、再隔离定内力。
- 分解了本已垂直的力，反而把方程搞复杂、还容易漏符号。

## 生成后自检（必须逐条在代码中体现）
- [ ] `setup()` 里每个力都是一个**具名常量/对象**（`G`、`N`、`f`、`FT`、`F`），且每个都能回答"来自哪个接触面"——多余力无处藏身。
- [ ] 每个力的箭头用 `Draw.arrow(..., { category: 'force', subtype: 'gravity'|'normal'|'tension'|'friction'|'elastic'|'electric'|'ampere'|'lorentz' })`，**从质心出发**；前端"受力"开关能按 subtype 单独关掉。
- [ ] 存在相对运动趋势的题：代码里有一个**显式判据**（如 `F > mg * Math.tan(theta)`）决定摩擦力方向，而不是把方向写死。
- [ ] `readouts` 至少给出"合力"与"各个分方向合力"；平衡态下合力必须是 0（允许 1e-9 量级残差，C3 禁止 NaN）。
- [ ] 若题中某个力被判为 0（绳无力/面无力），**画面上也要体现**：该箭头消失或长度趋近 0，不能仍画一根满长箭头。
