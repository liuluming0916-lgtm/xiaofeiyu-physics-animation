# XFY-2.0 · 小肥鱼物理动画 2.0

教师给一道高中物理题（文字或图片）→ 大模型在一次对话里自己写、自己跑、自己看、自己改 →
交付一个可离线双击播放的单文件网页。**没有多阶段流水线，没有格式枷锁。**

## 开始之前

**任何 agent 或协作者进入本仓库，先读 [AGENTS.md](AGENTS.md)。**

其中最重要的硬性规则：**禁止使用 PowerShell 写或修改文件内容**。
历史事故：用 PowerShell 落盘时中文被按 GBK / 带 BOM 写坏，只能回退版本。
所有文件内容一律用编辑工具（UTF-8 无 BOM）创建与修改。

## 快速开始

**双击根目录的 `启动.bat`** —— 它会叫起服务、等它真的就绪，再自动打开浏览器。
第一次运行时它会自己装依赖。已经在跑的话，它只打开网页，不会重复起进程。
关窗口（或 Ctrl+C）就停。

命令行方式（等价）：

```powershell
npm install --cache .npm-cache   # 只装一次
copy .env.example .env           # 填入接口密钥（也可以在界面的「设置」里填）

npm run web                      # 起界面：http://127.0.0.1:8787
npm run m0                       # 沙盒自检：快进 + 截图 + 数值对账
npm run run -- --text "题目"      # 命令行出一道文字题
npm run run -- --image 题目.png   # 出图片题（可重复 --image）
node scripts/check.ts 文件.html   # 给现成动画跑一遍质检
npm run typecheck                # 类型检查
```

`npm run m0` 输出到 `开源日志/m0/`；`npm run run` 输出到 `开源日志/<时间>-<题目标题>/`，
里面是 `animation.html`（双击可播）、`shots/`（每次回传给模型的截图）、`run.json`（完整对话记录与指标）。

> Windows 上如果提示浏览器起不来（crashpad 拒绝访问），说明当前终端处于受限沙箱，
> 需要给"完全访问"权限才能拉起无头 Chrome。打包成 exe 后没有这个限制。
> 浏览器用本机已装的 Chrome / Edge，不额外下载。

## 目录

```
apps/             教师界面（M2 起）
packages/sandbox/ 虚拟时钟、绘图探针、检查项
packages/agent/   模型客户端、工具、单轮闭环、提示词（prompts/system.md 可直接改）
packages/player/  宿主播放器与导出包装（控制条不靠模型画）
examples/         手写样例动画（回归基准）
scripts/          命令行入口（m0 自检 / 出题 / 接口探路 / 截图）
docs/             需求、方案、里程碑
开源日志/          产物与截图（git 忽略）
```

## 环境

- Node ≥ 22.18（直接运行 `.ts`，无需构建步骤）
- 本机 Chrome 或 Edge 其一
- Git 2.55 / Windows，主分支 `main`

## 桌面版（免安装）

```powershell
npm run app:portable      # 构建 + 组装，产出 release/portable/
```

产物是一个文件夹，压缩后即可分发（约 117 MB）：

```
小肥鱼物理解题动画.exe
resources\app\...
启动说明.txt
```

- **不需要**安装 Node、也不需要另装浏览器（沙盒用系统自带的 Edge/Chrome）。
- 生成的文件与配置保存在 `%APPDATA%\小肥鱼物理解题动画\`。
- 首次运行会有 Windows 的“未知发布者”提示（未买代码签名证书），点“更多信息 → 仍要运行”。

> 状态：2026-10-27 在 Windows 上实测可正常启动并生成动画。

安装包（NSIS）那条路用 `npm run app:build`，需要联网下载打包工具，网络受限时会超时。
