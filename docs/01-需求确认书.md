## 三、需要你点头的 6 条推断（我先按这个做）

**A1 数值显示位置（已按你的答复改定）。**
不做侧栏数值表，也不做曲线图（暂时取消）。数值**就地标在示意图上**：速度写在速度箭头旁，
位移挂在已滑过的路径旁（像划痕/量距），力写在力的箭头旁。
理由：你 1.0 的图例里写着“画面不写数值”，而画布上写数字正是文字重叠的最大来源；
所以数字必须“跟着图走”，不能“浮在图外”。
这条推翻了我原来的“侧栏表格”方案——后续所有提示词与检查项都按“就地标注”来写。

**A2 箭头的三种模式。**
“全程跟随 / 仅关键帧 / 关闭”，由模型按题型自选（圆周运动、ODE 类默认仅关键帧），播放时也能手动开关。
→ 对应你说的“ODE 类可以不用全程箭头解说”。

**A3 时间的处理。**
每一“幕”的播放时长默认压到 **≈4 秒**（继承你 1.0 的归一化），同时标注物理时间，例如
“物理 0.45 s ｜ 播放 4.0 s”；变速只改播放速度，不改物理换算。
→ 如果你想“物理 1 秒就是播放 1 秒，靠变速解决看不清”，请说，这是两套完全不同的实现。

**A4 3 轮修不好时怎么交付。**
动画照给，页面顶部一条红字写明“未通过：t=1.2 s 处速度读数与应得值 4.0 m/s 不符”，并给一个
“打回重做”按钮（你可以附一句“箭头画大点”）。不是静默交付。

**A5 截图验收的前提。**
它需要模型**能看图**。如果 DeepSeek-V4.1-Flash 的接口只收文字，我就把截图换成“画面摘要”——
程序把“画面上有什么元素、文字块在什么位置、曲线极值是多少”转成一段结构化文字给模型看。
两者可以同时存在：有视觉能力就发图，没有就发摘要。

**A6 沙盒用你电脑上已装的 Chrome 或 Edge。**
不额外下载第二个浏览器（省 150 MB，也避免公司网限制下载）。
代价：机器上至少得有一个 Chrome/Edge。你两台机器都满足，我已确认。

## 四、三条边界（先说清，以后少吵架）

1. **准、快、便宜，三选二。** 现在定优先级为“准 > 快 > 便宜”。
2. **全板块 ≠ 首版就全可靠。** 先把力学闭环做到能上课，再逐个板块过 40 题题库。
   这是排顺序，不是砍范围。
3. **“大模型自主”不等于“不可核查”。** 它写什么我管不了，但跑没跑过、画面长什么样、
   数字对不对，必须有日志和截图留证——这是 1.0 最大的教训。

## 五、验收标准（建议阈值，可改）

40 题跑三档，逐题记录：耗时、花费、修复轮次、失败原因。

| 指标 | 首版目标 | 打磨后目标 |
|---|---|---|
| 一次通过 | ≥ 60% | ≥ 85% |
| 三轮内通过 | ≥ 85% | ≥ 93% |
| 人工打回一次内可用 | ≥ 90% | ≥ 96% |
| 单题 P90 耗时 | ≤ 6 分钟 | ≤ 4 分钟 |
| 单题 P90 花费 | ≤ 0.6 元 | ≤ 0.4 元 |

“通过”的判定不靠感觉：由第四节的自动质检项 + 关键帧人工抽检共同决定。
