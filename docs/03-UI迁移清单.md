## 一、定稿的三条

1. **连接设置**：入口放顶栏右侧齿轮，复用现有弹窗（地址 / 模型 ID / Key / 支持看图 / 超时 / 测试连接）。
2. **时间轴**：一条**全局轴** + **幕分隔线**，允许在分隔线处切幕跳变。
3. **左栏讲解区**：保留。它的定位是“解析 ↔ 动画的联动”，不是旁白。
4. **时间轴刻度**：标**物理秒**，旁边小字标“播放 X s”。理由：讲题说的是“0.6 s 反应时间”“4 s 后共速”，不是“播到第几秒”。

## 五、质检口径的一处修正

既然允许切幕跳变，第 15 条不能写成“禁止跳变”，改为：

- 相邻采样位移/速度跳变，若**不在**幕分隔线上 → 失败；
- 若**在**幕分隔线上 → 通过，但该处必须有幕分隔标记与幕名（画面摘要里能读到），
  且分隔线前后各有至少 1 个采样点。

这样比 1.0 的“允许随便跳”严，也比“绝对禁止”合理。
