## 三、新图规格（照这个出，直接覆盖，不改代码）

| 项 | 要求 | 原因 |
|---|---|---|
| 比例 | **1:1 正方形** | 界面用 `aspect-square` + `object-cover`，非正方形会被裁 |
| 尺寸 | **≥ 880×880**（建议 1024×1024） | 显示宽 440 CSS px，2 倍屏要 880 |
| 格式 | **WebP**（质量 80–85） | 代码写死 `.webp`，换格式要改代码 |
| 体积 | 单张 **≤ 120 KB** | 现在总共 723 KB，别翻倍 |
| 背景 | 不强制透明 | 界面已有浅蓝渐变 + 白色圆角框，自带场景/背景更好看 |
| 命名 | **文件名不能改** | 代码按 `/fish/{name}.webp` 取，改名就白屏 |

> 换图是纯覆盖动作：把新图丢进 `web/public/fish/`，同名替换，**不需要改一行代码**。

## 四、还要补的：应用图标

`electron/resources/` 目前是**空的**，装出来的软件用的是 Electron 默认图标。要补：

| 文件 | 用途 | 规格 |
|---|---|---|
| `icon.ico` | Windows 安装包 + 窗口图标 | 256×256 起，含 16/32/48/256 多尺寸 |
| `icon.png` | 打包脚本兜底 | 512×512 或 1024×1024 |

注意：图标**不要**用那条鱼。DeepSeek 的鲸鱼图形是它的商标，把近似的鱼做成应用图标
是最容易被认定“搭便车”的做法（见 [TRADEMARK §四](../TRADEMARK.md)）。
用文字标（“小肥鱼”三个字做字形设计）或抽象的图形都比画鱼安全。
