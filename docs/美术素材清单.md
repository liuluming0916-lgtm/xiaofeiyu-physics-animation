## 二、以后加图照这个规格

| 项 | 要求 | 原因 |
|---|---|---|
| 比例 | **1:1 正方形** | 界面用 `aspect-square` + `object-cover`，非方形会被裁 |
| 尺寸 | **≥880×880**（建议 1024） | 显示宽 440 CSS px，2 倍屏要 880 |
| 格式 | **WebP**（质量 80–85） | 代码写死 `.webp` |
| 体积 | 单张 **≤120 KB** | 控制安装包体积 |
| 命名 | **不能改** | 代码按 `/fish/{name}.webp` 取 |

## 四、还缺：应用图标

`electron/resources/` 目前是**空的**，装出来的软件用的是 Electron 默认图标。

| 文件 | 用途 | 规格 |
|---|---|---|
| `icon.ico` | 安装包 + 窗口图标 | 256×256 起，含 16/32/48/256 多尺寸 |
| `icon.png` | 打包兜底 | 512×512 或 1024×1024 |

> ⚠ 图标**别用那只蓝色鲸鱼**。形象本身是你的，但鲸鱼图形与 DeepSeek 的标识有联想，
> 做成应用图标是最容易被指“搭便车”的位置（见 [TRADEMARK §四](../TRADEMARK.md)）。
> 用“小肥鱼”三个字做字形设计，或换一个抽象标记，都比画鱼安全。
