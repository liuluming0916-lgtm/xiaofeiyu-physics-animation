# 界面方案 v0.1（待对齐）

- 日期：2026-10-27
- 线框：`docs/wireframe.html`（截图见 `开源日志/wireframe.png`）
- 基准：1.0 的排布 + 2.0 的"单轮对话 + 宿主播放器"

---

## 1. 三个页面（各自独立，不同屏）

**解题页和动画页是两个独立页面**，顶栏切换，同一时刻只显示一个（与 1.0 相同）。
不做"左边输入、右边预览"的同屏分栏。

| 页面 | 干什么 | 进入条件 |
|---|---|---|
| 解题 | 输入题目、选填解析、等待生成 | 常驻 |
| 动画 | 看片、拖时间轴、打回重做、导出 | 有产物才可进 |
| 设置 | 填接口地址 / 模型名 / 密钥，测连通 | 常驻 |

顶栏右侧四个入口，**四页同一套、样式统一**：`输入 · 动画 · 设置 · 导出`。
没产物时"动画/导出"置灰。生成完成后不自动跳页，停在输入页显示"画好啦"，
由老师点"动画"过去——留一个确认动作。

---

## 2. 解题页

左栏（约 44%）：

1. **题面文字**（多行，支持 LaTeX）
2. **题目图片**（拖拽区 + 选择按钮，≤15 MB）
3. **参考答案 / 解析（可选）** —— 2.0 新增
4. **开始生成动画**

右栏：

1. 吉祥物 + 一句话状态（出题 → 写码 → 试跑 → 看图 → 交付，四段进度条）
2. 折叠的"过程记录"：**前端不显示日志**，日志自动存 `开源日志/<时间>-<题>/run.json` 和 `.html`

**解析注入的规则（重要）**

- 解析在**点"生成动画"之前**填好，和题目一起发给模型。填了，模型**不再自己推导**，
  只负责把这份解析正确地画出来。
- 沙盒对账仍以这份解析为标准：动画里的关键数值与解析不符，红条标注（默认允许交付，
  老师可以先看形状；要硬拦截说一声就改）。
- 没填 → 模型自己推，并自行标注近似假设（g 取 10、忽略摩擦等）。

这条同时解决两个问题：复杂题模型算错、以及"一题多解它选了你不想讲的解法"。

---

## 3. 动画页

左栏（约 38%）：

1. **题目原文**（可折叠）
2. **分幕列表**：按小问顺序，每幕一行标题 + 一句说明（`t=0→2 s，位移 4.0 m`）。
   点一行就跳到那一幕。
3. **答案解析**：如果老师填了，就显示在这里；没填则显示模型自己推的结论（标注"模型自解"）。

右栏：

1. 画布（1280×720，按容器缩放）
2. **总时间轴**：总长 = 幕数 × 4 s（3 幕 = 12 s）。进度条上按幕分段画刻度，
   拖动跨过边界就自动切到下一幕 —— 老师讲课时是一条连贯的线，不用先选幕再拖。
3. 打回重做：一个输入框 + 按钮。"接着上一轮改"，上限 3 轮。

## 4. 设置页

替换 1.0 的"知识卡"：

- 接口地址（`https://api.deepseek.com`）
- 模型名（`deepseek-flash`）
- 密钥（密码框，只存本地）
- 思考强度：low / high / max
- 「测试连接」按钮 → 显示模型真实名称、上下文长度、是否支持看图

---

## 5. 失败态（1.0 没有，2.0 必须有）

红条不做"一句失败原因"，而是四段：

```
第 2 幕 · t = 1.20 s：文字重叠（「v = 4.0」压住「30°」，重叠 66%）
建议：把 v 的标签移到箭头右上方，或把角度标注挪到弧线外侧
上一版仍可播放 →  仍要交付 | 打回重做
```

对应到我们已有的检查项，每条都能给出"哪一幕、哪一刻、哪一项、怎么改"。

## 6. 与 1.0 的对照

| 1.0 | 2.0 |
|---|---|
| 解题 / 动画 / 设置 / 导出 | 保留四个，导出并入动画页 |
| 补充信息（按阶段） | 删除 |
| 知识卡、判断依据 | 删除 |
| 第 1 步…第 5 步 + 解析 + 曲线图 | 改为分幕列表；曲线图取消 |
| 解题过程与动画联动 | 预留位置，先不做 |
| 逐次 AI 调用日志弹窗（公测留痕） | 保留思路，暂不实现；日志静默落盘 |
| 前端显示完整日志 | 取消；日志只落盘 |
