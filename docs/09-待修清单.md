# 09 · 待修清单（2.5.1 收尾时整理）

> 这份清单是 2026-10-29 对开发端做的一次全量排查结果。
> 标注「已修」的可以删掉；新问题往下加。改完任何一项，先 `npm run regress`，再重新打包。

## 一、优先修（按性价比排序）

### 1. 删掉过时的 `viewport-sizing` 质检 —— 5 分钟

- 位置：`packages/agent/src/tools.ts`（搜 `viewport-sizing`）
- 现状：禁止模型写 `100vw` / `position:fixed`，命中就打回重写
- 为什么过时：2.1 起模型页面跑在 1280×720 的 iframe 里，这两种写法已经被关在笼子里，**不再有害**
- 影响：会把本来能用的产物打回，白烧一轮模型的 token
- 改法：删掉这条检查（或降级成 warn，不判不合格）

### 2. 从分幕列表切幕时，笔迹不会被清 —— 15 分钟

- 位置：`packages/player/src/player.js:221-224`（`xfy === 'goto'` 的分支）
- 现状：直接改 `idx`，绕过了 `gotoAct`，而清空笔迹挂在 `gotoAct` 上
- 影响：老师在左侧点第二幕时，上一幕的板书还留在画面上
- 改法：`goto` 分支里改 `idx` 之后调一次 `window.__xfyClearInk?.()`

### 3. iframe 加 `sandbox` —— 30 分钟

- 位置：`packages/player/src/export.ts:144`
- 现状：`<iframe id="xfy-frame" allowfullscreen scrolling="no">`，**同源**
- 影响：模型代码仍能 `parent.document...` 碰到控制条与标注层；现在的隔离靠"模型不会这么写"，不是边界
- 改法：加 `sandbox="allow-scripts"`（`postMessage` 照常工作），然后重跑回归确认 10 题都正常

### 4. 任务对象与产物目录不回收 —— 30 分钟

- 位置：`apps/server/src/server.ts:40`（`const jobs = new Map()` 只增不减）
- 另外：`开源日志/web/<时间>-<id>` 每次运行新建，从不清理
- 影响：长期使用会慢慢涨内存/磁盘
- 改法：保留最近 N 个任务（比如 20 个），更早的从 Map 删掉；产物目录给个"清理旧文件"的按钮或启动时按天数清理

### 5. 补验证：打回接着改 + 数据目录迁移 —— 30 分钟

- **打回**：`server.ts:153` 传了 `resume: resumeMessages`，逻辑完整，但端到端没跑过。做法：拿一个超时/失败的产物点「打回」，看是否从断点续上
- **迁移**：`electron/main.cjs:31-45` 会把 `%APPDATA%\小肥鱼物理解题动画` 改名成新名。做法：留一个旧目录，装新包跑一次，确认 Key 还在

## 四、等他反馈再动

- **单次模型调用 600 秒上限**：`loop.ts:156` 取 `min(600s, 剩余预算)`，`llm.ts:113` 超时直接抛错不重试。
  总预算 1200 秒形同虚设——单次调用一超时，任务当场失败。
  候选修法：降 `max_tokens`（128k → 32k）+ 超时后允许「接着改」；单纯抬高上限只是把墙挪远。
