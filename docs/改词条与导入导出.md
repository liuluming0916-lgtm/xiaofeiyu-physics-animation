## 一、三类知识卡：改哪个有用

| 知识卡 | 进哪个槽位 | 它管什么 |
|---|---|---|
| **动画规范卡** | 动画代码（常驻） | 坐标/单位/颜色/读数、阶段表、30 个元件总览。改它影响所有动画 |
| **元件卡** | 动画代码（按元件命中） | "这个元件怎么画"。一卡一件（画布 / 传送带 / 箭头 / 标注 …） |
| **场景卡** | 动画代码（按题型命中） | 目前 0 张；留给"这类题的整体画法" |

> 提示词卡与本地规则卡也算知识卡总集，但它们不是 `knowledgecard` 条目：
> 提示词卡在设置页「提示词卡」里改，本地规则卡在「本地规则卡」里改。

**改哪里最有效**：动画不好看、动得不对 → 先看**元件卡**。
一卡一件的意思很硬：一张卡里塞两个元件，模型会混着用。

---

## 二、一张合格的卡长什么样

必须有三样东西：

1. **这是什么时候用**（触发词 + 一句场景描述）；
2. **规范怎么写**（要点式，别写散文）；
3. **生成后自检**小节 —— 让模型写完自己核一遍。

并且要给一段 **`code_examples`**：一段**能通过静态检查**的代码。
它不是装饰：门禁会把每段示例真跑一遍检查，**示例坏了会红**。
（"照抄我们的示例会被我们自己的检查打回"这种情况，比没有示例更糟。）

## 三、编辑 → 保存 → 生效

> 在软件的**设置 → 知识卡**页做；也可以直接改 `ai-rules/knowledgecard/` 下的 JSON。

1. **改 / 建**：一张卡一个 id。
   - 内置词条**只读**：一改就自动生成一条**同 id 的覆盖副本**（`origin: user`）；
   - 删掉覆盖副本就恢复内置；
   - 已保存的 id **不可再改**（改名会让文件和覆盖关系对不上）；要换 id 就新建。
2. **保存到本机**：顶部按钮。写前滚动备份 5 份（`ai-rules/.backup/`），整批校验，原子写；
   任何一条不合法就**整批不写**。
3. **体检**：保存时在 Node 侧做完整校验——
   - 元件 id 必须在官方清单里（写 `arroww` 这种表外 id 会当场报出来）；
   - 必须带「生成后自检」小节；
   - `code_examples` 必须通过静态检查（不许调用未登记的函数）。
4. **试触发**：设置页有**实时预览器**——贴一段题面，它告诉你会命中哪几张卡、进了哪个槽。
   这是调卡片最快的手段：不用真跑一遍模型。
5. **生效**：下一次生成就带上。已经生成好的动画不会自己变。

## 四、导出 / 导入（JSON）

- **导出**：把当前全部**用户卡**（含覆盖副本）导成一份 `.json`
  （格式标识 `od-knowledgecard` v1）。内置卡不会导出——它们随程序走。
- **导入**：先选文件名（默认 `imported.json`），再点「导入并保存」。
  Node 侧做完整校验与旧名归一化（`scene_spec` → `scene_code`），
  **要么全进、要么全不进**（拒绝"进了一半"的状态）；覆盖同名文件前自动备份。
- **旧包**：v1.1.9 及更早的 `od-worldbook` 包仍可导入；保存时写成 `od-knowledgecard`。
- **幂等**：导出 → 导入 → 再导出，两次结果**逐字节一致**（门禁 ㉒ 钉着这条）。

⚠ 导入别人的知识卡包之前，先看一眼 `code_examples`——那里面是可执行代码，
虽然只能在画布沙箱里跑，但**别导入来路不明的包**。

## 五、出问题怎么回退

| 症状 | 做法 |
|---|---|
| 改了卡之后效果变差 | 删掉这条覆盖副本（设置页「删除」），立刻回到内置版本 |
| 不知道哪条卡生效了 | 看解题结果的「知识卡依据」面板，或设置页的试触发预览 |
| 想全部复位 | 设置页「**恢复 1.1.10 内置**」：只撤销你对内置卡的覆盖，**不删你自己新建的卡**；恢复前自动备份 |

> 「恢复 X 内置」里的版本号就是**你装的这一版**。每个发布版本都把当版内置卡
> 编译进程序（`OD_BUILTIN_BUNDLE=1`），所以不会恢复成别的版本的内容。

## 六、写卡的三条经验（血泪）

1. **不要写"绝对不许"清单**。只写禁令的卡，模型会绕开禁令但丢掉画法。
   把"应该怎么画"写清楚，比列十条"不许"有效。
2. **数值不要靠文字描述**。画布不写数值、矢量靠**颜色与长度**表达——卡里也别写"高度约为 3 米"。
3. **一张卡一个元件**。真要组合（比如"斜面上的块"），就在**斜面卡**里写下"块要跟着转"，
   而不是新开一张组合卡——否则两张卡会同时命中、互相打架。
