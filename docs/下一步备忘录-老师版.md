| 事项 | 人话 | 影响 | 准备放哪版 |
|---|---|---|---|
| **账本 / 审计不可用** | 每次生成、失败、复现包的历史记录，现在记不下来 | 你上课不受影响；但出了问题不好回看“上次是怎么坏的” | **1.1.19** |
| **q06 / q09 还是 todo** | 另外两道真题还没按方案二重跑 | 真实基线只有 q04 一道，不够证明“换卡/换提示词没变差” | **1.1.19** |

| **动画页公式和导出页不一样** | 动画页的公式表还是演示题 q01 的；导出页是现场渲染 | 只影响公式观感；不影响动画和答案 | **1.1.19** |

## 3. v1.1.19 要干什么

**定位：上线前最后 debug，不加新功能。**

### 3.1 恢复账本 / 审计

- 现在 Electron 33 的“记账模块”版本对不上，启动时会降级；
- 1.1.19 要升级运行环境或换兼容版本，让“每次生成/失败/复现包”重新可记录；
- 恢复后删掉两个临时开关（导出探针 / 关审计），不把调试后门带进正式版。

### 3.2 真题从 1 道扩到 10 道

- q06/q09 按方案二重跑；
- q01/q05/q07/q08… 逐步补；
- 至少 **3–5 道 accepted**，才敢说“真实题稳定”；
- q04 已经 accepted，不再动。

### 3.3 提示词 / 知识卡最后审计

- 30 张卡逐张过：哪些真命中、哪些是噪声、哪些该删；
- 补“电路符号 / 卡销”这类真实题需要的卡；
- 决定水银柱卡要不要解封；
- 做 10 题的“有卡 vs 无卡、有答案 vs 无答案”A/B，确认卡不是越多越好。

### 3.4 收 3 个小尾巴

- 导出页“出处信息”补上真实指纹；
- 动画页公式表改成当前题；
- 纯图片题标题兜底。

### 3.5 打包 / 安装测试

- 出 1.1.19 绿色版 + 安装包；
- 在正常 Windows 上跑一次 `--selftest`（服务 / 首页 / 账本 / Worker）；
- 装一次、导出一次、设置页四分区点一遍。

## 4. v1.2.0 要干什么

**定位：正式版，面向别的老师发布。**

- **正式安装包 / 版本号 1.2.0 / 发布说明**；
- **LICENSE、素材版权、半开源镜像**（现在还没就绪）；
- **用户文档 / 安装说明 / 常见问题**；
- **10 道真题稳定、账本/审计可用、门禁全绿**；
- 可选功能（不绑版本）：自动上传报错、AI 帮写卡、社区仓库镜像；
- 发布前把“调试后门 / 临时探针”清干净。

> 1.2.0 不是“再加动画功能”，而是“把现在能用的东西，做成别人也能装的正式版”。
