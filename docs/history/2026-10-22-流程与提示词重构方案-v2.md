## 0. 一表看变化

| 现在 | 之后 |

## 1. 阶段与职责

```
题面 + 图
  │
  ├─ read_problem ── 元件/场景（触发卡）· 极简几何 · 示意图范围
  │
  ├─ solve ───────── 解题过程（或整理老师解析）
  │
  ├─ 答案讲解 ────── 第 1..N 步：讲给老师/学生听（UI 的「第 X 步」）
  │
  ├─ 物理分析 ────── 每元件：从几秒到几秒、x(t)/y(t) 各是什么
  │
  ├─ scene_code ──── 8 槽位代码，按真实物理时间
  │
  └─ 渲染层 ──────── 8 秒归一化（本地算 k）
```

### 1.1 read_problem — 读题（只管三件事）

**要**：判元件、判场景、给示意图范围，外加一句极简几何。
**不要**：写尺寸、角度、质量、速度这些**数值**——它们只从题面取，写进转写只会和图打架。

输出固定小标题：

```
【物体】A、B、C
【相对位置】A 在传送带上，滑轮在右端，B 悬挂在滑轮下，C 在 B 下
【姿态】水平传送带；竖直绳
【运动方向】A 向右为正
【示意图范围】0.12,0.35,0.48,0.62
【动画元件】block, belt, pulley, rope
【场景】conveyor_block
```

- 一维问题时可以不写【姿态】的第二行。
- 所有词只能从词表取 id。

> 为什么删掉“尺寸与比例 / 已知量 / 图中文字”：这三节全是**可量化的东西**，模型写错一个角度，`scene_code` 会信文字不信图。几何要的是**结构**，不是数据。

### 1.2 solve — 解题（基本不动）

保留两种模式（自解 / 整理老师解析）。只改一处：**题面没给的数不许编**；
符号题允许只给符号，不再强求“符号结论也写数值”。

### 1.3 答案讲解（原 steps）

**目的**：给老师看的、可编辑的逐步讲解；也是导出页的「第 X 步」。

输出：

```
step1_title: 建立 F–x 关系并求 0→1 m 的功
step1_time_hint: 从开始到共速
step1_tex: """……讲解正文（面向学生，含推导）……"""
```

- `time_hint` 是**模糊文字**，可以是“从开始到共速”“剪断后”，**不要求数字**；
- 不写 `t0/t1`（数字时间由物理分析给）；
- 步数 2–6；一步 = 一个可以在动画里讲清楚的阶段。

**权限**：导出前教师可编辑每一步的 `title/tex`；**重新跑一次直接覆盖**（已定）。

### 1.4 物理分析（原 answers）

**目的**：把“物体怎么动”写成机器能用的表达式。**唯一时间真相**。

输出（行式表 / JSON，二者取一，建议行式表配代码块）：

```
element: A
segment: 1
t0: 0
t1: 1.0
x: 0.5*2*t^2            ← 物理时间、SI、t 为秒
y: 0.27                 ← 常量
event_end: A 与传送带共速

element: A
segment: 2
t0: 1.0
t1: 3.0
x: 1.0 + 2.0*(t-1.0) + 0.5*(-1.5)*(t-1.0)^2
y: 0.27
event_end: A 到达 x=6 m
```

规则：

- **每个元件一段一份**（元件内可再分段，元件之间互不对齐）；
- `x(t)`、`y(t)` 必须是**关于 t 的表达式**，只允许：四则、幂、`sin/cos/tan/exp/sqrt/abs`、常量；
- 一维运动 `y` 写常量；
- 段与段在 `t1` 处**位置连续**（值必须相等，容差 1e-9）；
- 事件表单独给：`事件名 | 时刻 | 判据`（如“共速 | 1.0 | v_A = v_belt”）。

**它不占槽位**：物理分析是阶段产物，8 个槽位不变。

### 1.5 scene_code — 动画代码

输入改为：

| 顺序 | 内容 |
|---|---|
| 1 | 题面 |
| 2 | 极简几何（read_problem 的【物体/相对位置/姿态/运动方向】） |
| 3 | 示意图（裁好的 PNG） |
| 4 | 答案讲解（全文） |
| 5 | **物理分析表（每元件 x(t)/y(t)）** |
| 6 | 事件表 |

提示词要点（新增/替换）：

- **按真实物理时间写**：`SIM.duration = T_phys`（= 物理分析里最大的 `t1`），不做归一化、不写倍速；
- `stateAt(t)` 直接实现物理分析给的表达式，**不许自己改时间尺度、不许手填端点速度做样条**；
- `readouts` 返回物理值（v 就是真速度）；
- 每个运动元件在 `SIM.bodies` 里声明。

### 1.6 渲染层（本地，不调模型）

- `T_phys = max(所有分段 t1)`，由代码取；
- `k = 8 / T_phys`，**固定 8 秒**；
- 播放：`t_phys = t_disp / k`；
- **v/a 箭头必须按 `t_phys` 求导**（否则会长 k 倍）；
- 教师可另设“播放倍速”（额外乘子，不改 `k`）；
- 极端 k 允许（碰撞 0.3 s → k≈27，慢放；长过程 40 s → k=0.2，快放）。

### 1.7 校验（跟着换）

| 判据 | 新口径 |
|---|---|
| `C5` | `SIM.duration === T_phys`（±1e-6），且 `k` 可算 |
| 新 `C10` | 事件时刻自洽：`v(t_event)` / `x(t_event)` 满足事件判据 |
| 新 `C11` | 分段一致：`stateAt` 与物理分析表逐点吻合（1e-6）；段端位置连续 |
| `C7` | 改为“事件时刻读数 = 由 x(t) 推导的值”，不再拿 ANSWERS 的 `at_t` 当锚 |

## 3. 已定 / 未定

**已定**

- 转写只写结构，不写数值；
- `T_phys` 由代码从分段末端推导，模型声明只做交叉核对；
- 演示固定 8 秒，极端倍速允许，另加教师倍速控件；
- x 是矢量 ⇒ 每个元件给 `x(t)` 与 `y(t)` 两条表达式；
- 教师编辑的讲解，重跑直接覆盖；
- 自愈轮带裁好的示意图。

**未定（下一轮要定）**

1. 物理分析用行式表还是 JSON（我倾向行式表，和现有解析器一致）；
2. 事件表的判据怎么写才可机器判定（`v_A = v_belt` 里 `v_belt` 从哪来）；
3. `C11` 的容差与采样密度（逐点比还是端点比）；
4. 旧 15 题夹具怎么重建、谁来审。
