# v1.1.18 发布说明（2026-10-24）

> 本版定位：**1.1.17 完善版 + 方案二动画**。
> 绿色版 zip：`release/物理解题动画-v1.1.18-win-x64.zip`（约 130 MB）
> 解压后双击：`物理解题动画/物理解题动画.exe`

## 1. 本版最重要的事

### 方案二：物理世界坐标 + 相机自动取景

- `state.<key>` 只给 `x / y / type`（物理米、质心）；
- 没有 10×6 纸、没有 `cx/cy`、没有 `anchor`；
- `VIEW` 没有 `SIM.stage`，`bodies.at` 返回 `[x,y]`；
- 尺寸、比例、构图归画图 AI，允许“示意”；
- 相机自动取景；v/a 箭头用同一套物理坐标。

### 补充信息可以按阶段注入

解题页的“配图补充描述”改成了按钮：

> **补充信息（按阶段）**

弹窗里可以分别给：

- 读题
- 解题
- 物理分析
- 画图
- 修复

各写各的；空着 = 不注入；不会串台。

### 31 张知识卡迁到方案二

- 2 张常驻卡 + 12 张矛盾卡 + 其余示例全部迁到 `state.x/y` + 米制示意；
- 卡校验：启用卡不许再出现 `cx/cy` / 布局纸 / `anchor` / `10×6` / `纸面`；
- 水银柱卡与词表封存（暂不支持水银柱题）。

### q04 已验收

- 带参考答案重跑：`verdict=pass`，870 帧，4 步，3.622 s；
- A 末位置约 −1.7136 m，与参考答案一致；
- 第 4 段为 **answer-guided fit**（用户接受；不是独立受力推导）；
- 默认取景 A 偏小，用户端可自由缩放/拖拽。

## 3. 已知问题 / 没做

- **账本/审计仍降级**：Electron 33 是 Node-API 9，better-sqlite3 13 要 10；应用/导出正常，账本不可用；
- **P1-9 导出哈希**：导出页真实运行的 promptHash/knowledgecardHash 仍可能写“未记录”；
- **P2-6 live 公式**：动画页公式表仍是演示题 q01 的，和导出页可能不同；
- **P2-8 纯图片题标题兜底**：仍是 `parseProblemTitle`，没用 `deriveEntryLabel`；
- **q06 / q09**：`index.json` 仍是 `todo`，还没按方案二重跑；
- **老师手改代码回灌**：本版只有“只重画 / 从解题重跑”按钮；老师自己改槽位再回灌，按你的裁决留到 1.x 大版本，本版不管；
- **打包自检**：本机 DSH 沙箱拦 Electron 管道（`platform_channel ... 拒绝访问`），所以 `--selftest` 没跑完；
  `--version` 与 `app.asar` 形态检查已通过，zip 是手工从已组装目录压的。请在正常 Windows 上双击验证。

## 4. 怎么验收

1. 解压 zip；
2. 双击 `物理解题动画.exe`；
3. 确认标题栏/关于框显示 **v1.1.18**；
4. 进解题页：
   - 点“补充信息（按阶段）”，给“画图”写一句，确认只影响画图；
   - 跑一道简单题，确认动画页能播放；
5. 进设置页：
   - 知识卡 / 提示词卡 / 本地规则卡 / AI 帮写四个分区都在；
   - 知识卡能“恢复本版内置”；
6. 导出一次网页，确认文件名是中文标题 + 时间戳。
