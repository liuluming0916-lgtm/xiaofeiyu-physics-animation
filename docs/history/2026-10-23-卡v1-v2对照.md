### 3.1 物块

**v1 `wb_el_block`**（456 字）

```markdown
# 元件·物块 / 滑块（力学器材）

## 判据
题面或配图里出现「物块」「滑块」这类东西时画这一件。

## 状态与画法
- stateAt 里写：return { x: 0.6 };
- drawFrame 里写：Draw.box([state.x, 0.15], 0.4, 0.3);

## 这条元件最常错的地方
宽高写成像素；块心算到板外（穿模）

## 两条铁律（所有元件都适用）
- state.* 的键名必须就是 stateAt(t) 返回的键名（名字不一致读到 undefined，最终 NaN 被 C3 拦下）。
- 跨槽位读常量用 context.X；读别的时刻用 context.at(tt)，且只能在 drawFrame / readouts 里用。

## 生成后自检（必须逐条在代码中体现）
- [ ] stateAt 返回的键名与 drawFrame 里读的完全一致。
- [ ] 坐标是米，没有像素量与像素比例。
- [ ] 静态几何在 setup() 里算一次，不逐帧重算。
```

**v2 `wb_el_block`**（509 字）

```markdown
# 元件·物块 / 滑块

## 判据
题面或配图里出现「物块」「滑块」这类东西时画这一件。

## 状态字段
- `state.<key>.angleDeg` 由运行时按速度方向注入；没有速度时由场景卡给静态角。
- `state.<key>.x / .y` 是物理接触点；画形状用 `state.<key>.cx / .cy`（视觉中心）。
- `state.<key>.w / .h` 是视觉尺寸；不要写死宽高。
- 不要写 `stateAt` / `VIEW` / `setup` / `readouts`。

## 画法
- `Draw.box([state.e0.cx, state.e0.cy], state.e0.w, state.e0.h, { angleDeg: state.e0.angleDeg });`

## 这条元件最常错的地方
用 `x/y` 当块心（块会沉进支撑面）；写死 `+0.1` 或 `0.4×0.3`。

## 自检
- [ ] 用 `cx/cy/w/h`，没有写死半高或宽高。
- [ ] 坐标是米，没有像素；画布上不写字。
- [ ] 静止物体按读题几何摆放，没有悬空。
```

# 场景·导线 / 电路布局

## 判据
题面或配图里出现「电路」「导线」「电源」「开关」「电阻」「滑动变阻器」这类东西时画这一件；电表由 `meter` 场景画。

- `Draw.line([0, 0], [2, 0]);`

## 这条场景最常错的地方
接线柱坐标每帧重算；电流方向画成电压方向；把电表表盘也画进导线场景。

## 自检
- [ ] 电路是静态基准，不读 `state`。
- [ ] 电流方向用 `aux` 箭头，画布上不写字。
- [ ] 电表由 `meter` 场景负责，本卡不重复画。
