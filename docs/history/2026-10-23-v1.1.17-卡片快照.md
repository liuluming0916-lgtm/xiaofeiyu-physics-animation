### 2.1 元件·物块 / 滑块

- id：`wb_el_block`
- kind：`element`
- 绑定：`block`
- enabled：true
- 正文字数：509
- 词表别名：物块、滑块、木块、方块、方框、长方形、矩形、叠放体、托盘、冰壶、砖块、砖、铁块、物体A、物体B

### 元件·物块 / 滑块

#### 判据
题面或配图里出现「物块」「滑块」这类东西时画这一件。

#### 状态字段
- `state.<key>.angleDeg` 由运行时按速度方向注入；没有速度时由场景卡给静态角。
- `state.<key>.x / .y` 是物理接触点；画形状用 `state.<key>.cx / .cy`（视觉中心）。
- `state.<key>.w / .h` 是视觉尺寸；不要写死宽高。
- 不要写 `stateAt` / `VIEW` / `setup` / `readouts`。

#### 画法
- `Draw.box([state.e0.cx, state.e0.cy], state.e0.w, state.e0.h, { angleDeg: state.e0.angleDeg });`

#### 这条元件最常错的地方
用 `x/y` 当块心（块会沉进支撑面）；写死 `+0.1` 或 `0.4×0.3`。

#### 自检
- [ ] 用 `cx/cy/w/h`，没有写死半高或宽高。
- [ ] 坐标是米，没有像素；画布上不写字。
- [ ] 静止物体按读题几何摆放，没有悬空。

**代码示例**

示例 1

```js
Draw.box([state.e0.cx, state.e0.cy], state.e0.w, state.e0.h, { angleDeg: state.e0.angleDeg });
```

## 4. 常驻卡

### 4.1 动画规范·坐标/单位/颜色/读数（常驻）

- id：`wb_anim_conventions`
- kind：`anim_rule`
- 绑定：`—`
- enabled：true
- 正文字数：777

### 动画绘制规范（常驻）

#### 你只写 drawFrame
- 位置只从 `state.<key>.x / .y` 读；不要重算运动、时间、速度。
- 不要写 `stateAt / VIEW / setup / readouts / STEPS / ANSWERS`；这些由程序生成。
- 不要写 `function drawFrame` 头、槽位标记或解释文字。

#### 坐标与尺寸
- 世界坐标：x 向右、y 向上、单位米；不要写像素、相机比例或 canvas 尺寸。
- 一屏画完：主体居中、留边距；视口由系统自动决定。
- 长度用题面的米数；天文/微观用示意比例。

#### 画面
- 画布上不写任何文字：文字/公式标注、箭头 label、尺寸 text 都不显示；说明放画布外图例。
- 颜色由 `category` 决定；不要写 `color`。
- 虚线写 `{ dash: true }`；实线不写；只有自定义间距才写 `[n, m]`。
- 不要画 v/a 箭头；运行时按程序里已有的刚体声明（`SIM.bodies`）自动求导绘制。
- 只有 `force / aux` 箭头才用 `Draw.arrow`，必须给 `category` 与 `mag`（真实量级），不要给 `scale / color`。

#### 静止物体
- 地面画在 y=0；斜面/轨道必须穿过运动元件在 t=0 的位置；绳/杆连到实际锚点；不要悬空。
- 静止基准只画一次，不要逐帧换位置。

#### 自检
- [ ] 没有 `stateAt / VIEW / setup / readouts / context` / 槽位标记。
- [ ] 没有像素、没有文字、没有 v/a 箭头。
- [ ] 运动位置都来自 `state.<key>`；静止几何没有悬空。

### 4.2 动画规范·阶段表与状态组织（常驻）

- id：`wb_anim_stages`
- kind：`anim_rule`
- 绑定：`—`
- enabled：true
- 正文字数：353

### 多段运动与多物体（常驻）

#### 什么时候用
- 题目有多个运动阶段，或同时有多个会动物体。

#### 画法
- 每个会动物体在 `state` 里有一个 key（`e0 / e1 / …`）；位置只从 `state.<key>.x / .y` 读。
- 阶段边界用**固定世界坐标**的细虚线或几何标记标出（数值从 analysis 表读，写死为常量），不写文字。
- 同一元件的相邻段在边界处位置必须连续；不要让物体瞬移。
- 多个物体各自更新，不要用同一个 key 画两个物体。

#### 自检
- [ ] 每个会动物体都有自己的 state key。
- [ ] 边界标记用固定坐标，不跟着物体漂移。
- [ ] 没有 `stateAt / STEPS / SIM.bodies / setup`。
