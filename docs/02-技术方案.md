## 2. 四个关键机制（整个项目的技术地基）

### 2.1 虚拟时钟：让动画“可以被倒带和快进”

生成出来的代码会以为自己在实时跑（`requestAnimationFrame` + `performance.now()`）。
沙盒在页面脚本执行前把这三个东西换成**自己控制的时间**：

- `performance.now()` / `Date.now()` → 返回虚拟时间
- `requestAnimationFrame` / `setTimeout` / `setInterval` → 登记回调，由沙盒推动

于是“快进到 3.7 秒看一帧”变成“把虚拟时间设成 3700，然后驱动一帧”，**耗时是毫秒级**，
而不是真的等 3.7 秒。这是“10 分钟出片”和“反复重试 3 轮”的物理前提。

### 2.2 绘图探针：不需要模型配合，也能知道画面里有什么

在页面里接管 `CanvasRenderingContext2D` 的绘制方法，记下每次画的：

- `fillText` / `strokeText` → 文字内容与方框（用来算**文字重叠**、越界、字号过小）
- `fillRect` / `arc` / `lineTo` / 路径 → 图形包围盒（用来算**越界**、空白页、元素过小）

模型完全不用知道这件事，它只管正常写 Canvas 代码。**这是“不给模型戴格式枷锁”的技术保障。**

### 2.3 可选数值探针：想核对数字时才需要

如果模型愿意，多写两行：

```js
window.XFY = {
  duration: 4.0,                       // 这一幕的总时长（秒）
  sample(t) {                          // 给定时刻，返回此刻的物理量
    return { t, ball: { x: 1.2, y: 0.8, vx: 3.0, vy: -2.1 } };
  }
};
```

有这个，就能做**数值对账**（“t=1.0 s 时 v 应该是 4.0 m/s”）。
没有这个，沙盒退化为像素级检查 + 画面摘要，仍然能跑，只是精度低一档。
**不强制、不惩罚**：写了加分，没写也能过。

### 2.4 画面摘要 + 截图：给模型“看见”的能力

每个检查点做两件事，同时产出：

1. **截图**（PNG）——给能看图的模型
2. **画面摘要**（结构化文字）——给只能读文字的模型，也给你自己排查

摘要示例：

```
t=0.0s 画布 1280x720 | 文字 6 块（无重叠，最小字号 18px）
  物体: 小球 (x=120,y=300,r=16) 斜面 (x=200..900, 倾角 30°)
  箭头: 重力(2.0 单位, 向下) 支持力(1.7, 垂直斜面)
t=1.0s ... 小球仍在斜面上，未穿模
异常: 无
```

## 3. 单轮工具循环

一轮对话，模型可用的工具（数量刻意少，避免它分心）：

| 工具 | 作用 |
|---|---|
| `build_animation(code, meta)` | 提交/更新整份动画代码（含多幕与 `sample`） |
| `run_checks()` | 在沙盒里快进跑，返回检查结果 + 画面摘要 |
| `look_at(times[])` | 取指定时刻的截图（模型自己挑关键时刻） |
| `finish(report)` | 交付 |

时序：

```
题 → [build] → [run_checks] → 失败? ──是──▶ 模型读报错 → [build] 改
                                   │
                                   否
                                   ▼
                            [look_at] 看关键帧 ──不符──▶ [build] 改
                                   │
                                   符
                                   ▼
                                [finish] → 导出
```

- **每轮 = 一次失败的检查**；上限 3 轮（第 4 次仍失败就按 A4 交付并标注）。
- **总超时 10 分钟**，可按取消；超时保留最后一次能跑的版本。
- **手动打回**：保留整段对话，你点“打回”时在同一个会话追加一条你的意见（“箭头大点”），
  它接着改，不是从零重来。

## 3.5 宿主播放器（M1.5 新增）

模型**不画控制条**。它只交付一个"舞台"：给定播放时间 t，画出那一帧。

```js
window.XFY = { playback, physical, render(t), sample(t) };
```

播放/暂停、时间轴拖动、0.5×/1×/2×、重播、时间读数，由 `packages/player` 在导出时统一注入。
三个好处：

1. 每个动画的交互一模一样，老师不用重新学；
2. 画布不再被按钮占掉一块，也不会因为控件压字而误判"文字重叠"；
3. 沙盒可以直接 `render(t)` 取帧，不用按 16ms 步进——M0 的"5 帧 4.14 秒"降到 1.61 秒，
   而且取的就是 t 秒那一帧，不是最近的帧。

这条也把"提示词里写 UI 规格"整段删掉了——凡是能用代码保证的，就不写进提示词。

## 4. 检查项清单（每一项都要有“人话报错”）

| # | 检查项 | 判据 | 失败信息示例（要直接喂回模型） |
|---|---|---|---|
| 1 | 语法/加载 | 页面 `error` 事件 | `第 214 行 SyntaxError: Unexpected token '}'` |
| 2 | 运行时异常 | `console.error` / 未捕获 Promise | `TypeError: Cannot read properties of undefined (reading 'x')` |
| 3 | 空白画面 | 像素非底色占比 < 0.5% | `t=0 时画布几乎全空，可能没画出来` |
| 4 | NaN / Infinity | 探针值或坐标非有限 | `t=1.20s 小球 y = NaN` |
| 5 | 越界 | 内容包围盒超出画布 | `t=2.4s 小球中心 x=1340，超出画布 1280` |
| 6 | 位置断层 | 相邻采样位移 / 速度突变超阈值 | `t=1.20s 到 1.25s 位移跳变 180px（正常 < 8px）` |
| 7 | 穿模 | 探针包围盒与障碍物相交 | `t=0.8s 小球与斜面相交，深度 12px` |
| 8 | 文字重叠 | 探针文字方框相交面积 > 阈值 | `“最大速度 v₀”与“30°”重叠 60%` |
| 9 | 元素过小 | 箭头长度 / 字号低于阈值 px | `速度箭头 4px，投影上看不清（阈值 14px）` |
| 10 | 卡死 | 单帧 > 200ms 或总耗时 > 20s | `时间轴拖到 3s 时单帧耗时 900ms` |
| 11 | 数值对账 | 模型自报的 checkpoints 与实际采样 | `t=1.0s 自报 v=4.0，实测 3.2` |
| 12 | 画面语义 | 截图/摘要 → 模型判断“是否符合题意” | 由模型自己写，例如“物块应向右运动，实际向左” |

> 第 6、11 项是 1.0 缺的（你只说了 NaN 门禁）。断层和数值对账才是“看起来对、其实错”的主要来源。

## 5. 视觉规范（继承 1.0 的教训，写进给模型的系统提示）

- 坐标与比例自定，但**必须自洽**：同一画面里 1 m 对应的像素数一致。
- 箭头：每一类各自归一化；过长**收缩不裁切**；某时刻量极小**画成一个点**；颜色沿用
  绿=速度、蓝=加速度、红=受力、紫=辅助。
- 文字：**数值就地标注**，跟在箭头旁、挂在已走过的路径旁（划痕、量距）；
  不做侧栏数值表，不做 v-t / x-t 曲线图（已取消）。最小字号 16px（画布逻辑像素），自动避让。
- 公式：KaTeX 离线内嵌（约 1 MB，含字体子集）；中文用系统中文字体，不内嵌。
- 体积目标：单幕 < 2 MB，多幕 < 5 MB。

## 7. 技术栈与目录

- Node 22 + TypeScript；包管理用 npm（本机没装 pnpm，不额外引入）
- 沙盒：`puppeteer-core` 驱动本机 Chrome/Edge（不下载第二份浏览器）
- 界面：本地网页（Vite + React），`npm start` 后自动开浏览器；后期用 Electron 包成 exe
- 模型：OpenAI 兼容接口，默认 DeepSeek，key 存本地配置文件

```
apps/web           教师界面
apps/server        会话、工具循环、导出
packages/sandbox   虚拟时钟、绘图探针、检查项
packages/prompts   系统提示与检查器提示词
  examples/        手写样例题（做回归用）
docs/              本目录
开源日志/           产物与截图（git 忽略）
```

## 9. 已知风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| 模型接口不能看图 | 中 | 画面摘要兜底（2.4），必要时另配一个便宜的视觉模型只做“看一眼” |
| 生成代码绕开虚拟时钟（用真实 `Date`、CSS 动画、`<video>`） | 中 | 注入面做全（rAF/timer/Date/performance）；实在绕开就退回实时播放 + 事后采样，慢但可用 |
| 4 秒归一化与物理时间打架 | 中 | 元数据里分开记“播放时长 / 物理时长”，播放器同时显示（见 A3） |
| 文字重叠反复触发重做 | 高 | 探针给出重叠的具体坐标与字号，报错里直接说“把标签移到右下 40px” |
| 单文件体积超预期（KaTeX） | 低 | 常用符号子集化，实在不行公式改用 SVG 路径 |
| 全板块一次铺开导致都不精 | 高 | 按 M5 顺序推进，每板块都用题库验收，不靠感觉 |
