## 0. 先说清楚三件事

### 0.1 `__` 是什么

题面里的 `__` **全部是源网页抽取时丢失的公式/数值**（这些网站把公式渲染成图片或 OMML，抓文本时会被吞掉）。
**我没有补写、也没有推算任何题面数值**——补一个数就等于换了一道题。

带 `__` 的题，测试前请对照原卷（每题给了来源链接与预览页）把数值填进 `problem.md`。
每道题缺什么，见 §7 清单。

### 0.2 一题一个目录

```
tests/real/<编号>-<简称>/
  problem.md    题面（文本 + 图）+ 分值
  expected.md   关键事件时刻、各段位移/速度、答案、图上应出现什么
  notes.md      想考哪张卡、你的预判
```

### 0.3 先 3 题，再 10 题

按 §3.2：**不改任何卡/词表/提示词**，每题跑 1 次，失败或有争议再原样跑 1 次。
3 题基线建议用 **M1 / E1 / T2**（见 §6.1），它们分别压传送带、电磁感应、气体定律三条最重的链路。

## 1. 选题口径（六维评分）

| 维度 | 看什么 | 1 分 | 3 分 |
|---|---|---|---|
| **可动性** | 有没有连续过程、能不能切成 ≥2 个真实事件 | 静态/瞬时 | ≥3 段且状态连续 |
| **元件覆盖** | 命中的词表元件数与难度 | 1 个 | ≥3 个且含难点元件（belt / spring / plates / cylinder_piston） |
| **读数** | 答案能不能落成 `readouts` 的 key | 纯定性选项 | ≥2 个数值/符号答案 |
| **几何可判** | 长度、角度、接触关系是否明确 | 说不清 | 一义 |
| **图依赖** | 没有原图能否重建场景 | 离不开图 | 无图可做 |
| **数据完整** | 题面数值是否齐 | 缺 3 处以上 | 全齐 |

满分 18。**主集门槛 12**；热学/光学按 2-1 配额收录时可放宽到 11，并在卡片里注明。

> 门槛不是玄学：低于 12 的题，测出来的多半是"读题"或"画不出来"，而不是"卡有没有用"。

## 3. 十道主题

### M1 · 2026 福建卷第 16 题（传送带 + 滑轮连接体）

- **来源**：[21世纪教育网 · 福建省2026年高考真题物理试卷](https://zy.21cnjy.com/26756131)（2026-10-14 上传，1.65 M）｜[移动版预览](https://mip.21cnjy.com/P/26756131.html)
- **题型**：计算题（压轴），多过程 + 图像
- **题面（转录，`__` 为抽取丢失）**：

> 如图（a），物块 A 置于水平传送带上，通过跨过光滑轻质定滑轮的轻绳与右边的物块 B 相连。B 通过轻绳与物块 C 相连，连接各物块的轻绳均处于拉紧状态且不可伸长，A 与滑轮间的绳子与传送带平行。传送带始终以恒定速率 `__` 顺时针转动。用挡板 P 使 A 保持静止。
> `t = 0` 时，撤去挡板 P，同时在 A 上施加一水平外力 F，A、B、C 从静止开始运动。以 x 表示 A 离开初始位置的位移，F 与 x 成正比关系，取水平向右为 F 和 x 的正方向，变化关系如图（b）。A 第一次向右运动过程中，其速度 v 随位移 x 的变化关系如图（c）。当 `x = __` 时，A 与传送带共速。
> 已知 A、B 质量分别为 2 kg、3 kg，A 与传送带间的动摩擦因数小于 1，最大静摩擦力等于滑动摩擦力，重力加速度大小取 `__`，A 始终在传送带上，B、C 始终未与滑轮和地面相碰。
> （1）求 A 离开初始位置向右运动 1 m 的过程中，F 做的功；
> （2）求 C 的质量和 A 与传送带间的动摩擦因数；
> （3）当 A 第一次运动到 `x = __` 时，剪断 B、C 间的绳子，A 开始向左运动。求 A 第一次运动到最左端时相对初始位置的位移。

- **评分**：可动 3 · 元件 3 · 读数 3 · 几何 2 · 图依赖 1 · 数据 1 = **13**
- **为什么选它**：
  1. 三个物体 + 传送带 + 滑轮，是"卡有没有教对装配关系"的最强压力测试——正是 §4.2 里 B 组要区分的地方；
  2. 有"共速 → 剪绳 → 折返"三个真实事件，`STEPS` 边界必须对齐，直接考 §5.2 阶段表；
  3. F–x 与 v–x 两张图必须由题面关系推出，不能抄示例几何。
- **命中元件**：`belt` `block`（A、B、C）×3 `pulley` `rope` `ground` `chart`（F–x / v–x）
- **预期关键事件（expected 骨架）**：
  - t=0 撤挡板 → A 开始向右（受 F、绳张力、摩擦力）；
  - 某时刻 A 与传送带共速（此时摩擦力换向，v–x 图上出现折点）；
  - 剪绳瞬间 B、C 脱开，A 只受 F 与摩擦，减速 → 速度 0 → 向左；
  - 最左端 v=0，求相对位移。
- **预期答案**：原卷解析未抓到数值（第 16 题答案为空），**待对照原卷补**。
- **重点卡**：`wb_el_belt`（刻度相位 `v·t`）、`wb_el_pulley`（绳分两段、切点距圆心 = r）、`wb_el_rope`（松弛不能画成直线）、`wb_el_block`、`wb_el_chart`
- **A/B 提示**：A 组关掉上面 5 张 + `chart`；B 组全开。
- **风险/预判**：
  - 文字描述里"B 通过轻绳与 C 相连"有歧义（B 是否悬挂），**必须配原图**，否则读题就崩；
  - 传送带与 A 的摩擦方向在共速前后反号，是 C9（物理包络）高发点；
  - 图（b）（c）必须随题面一起给，纯文字做不了。

### M2 · 2026 福建卷第 7 题（斜面 + 弹簧双物块）

- **来源**：同上（[福建 2026](https://zy.21cnjy.com/26756131)）
- **题型**：多项选择（4 分）
- **题面（转录）**：

> 如图，一倾角为 30° 的足够长斜面固定在水平面上，斜面上放置两个由轻质弹簧连接的物块 M 和 N。M、N 的质量分别为 0.5 kg 和 1 kg，M 与斜面的接触面光滑，N 与斜面间的动摩擦因数为 `__`。初始时，弹簧处于原长状态，M、N 由静止释放。弹簧始终在弹性限度内，最大静摩擦力等于滑动摩擦力。则（　　）
> A．N 开始运动的瞬间，M 的加速度为 0
> B．N 的速度达到最大时，M 的速度为 0
> C．N 开始运动后，M、N 的总动能与弹簧弹性势能之和保持不变
> D．M、N 第一次共速时的弹簧弹性势能和第二次共速时的不同

- **评分**：可动 3 · 元件 3 · 读数 1 · 几何 3 · 图依赖 3 · 数据 2 = **15**
- **为什么选它**：
  1. 斜面 + 弹簧 + 双物块，正好是 §4.1 #6 与 #1 的交集；
  2. 过程是"先只有 M 动 → N 被弹簧拉动 → 两次共速"，天然三段，`STEPS` 边界很清楚；
  3. 无图也能做（文字已给全几何），适合先跑通链路。
- **命中元件**：`incline` `spring` `block`（M、N）×2 `ground`
- **预期关键事件**：
  - 释放瞬间：M 沿斜面下滑（弹簧原长，无弹力）；N 受静摩擦不动；
  - 弹簧伸长到弹力 = N 的最大静摩擦，N 启动；
  - 第一次共速（M 减速、N 加速）；之后 N 超过 M，弹簧反向，二次共速。
- **预期答案**：原卷参考答案 **AD**（解析未抓到，判据以原卷为准）。
- **重点卡**：`wb_el_spring`（两端锚点同源）、`wb_el_incline`（`angleDeg` 正负、顶点是最高端）、`wb_el_block`
- **A/B 提示**：A 组关 `spring` `incline` `block`；B 组开。
- **风险/预判**：
  - 静摩擦"启动瞬间"是卡最可能漏的一条（`spring` 卡现在只写"两端锚点同源"，没写"静摩擦临界"）；
  - 斜面 + 弹簧的画法容易弹簧穿模，正好验 `wb_el_spring` 的"斜穿"告警。

### M3 · 2024 全国甲卷第 11 题（救护车 + 声波）

- **来源**：[21世纪教育网 · 2024 全国甲卷（解析版）](https://zy.21cnjy.com/23357451)｜[中国教育在线原卷（图片）](https://gaokao.eol.cn/shiti/wl/202406/t20240614_2616583.shtml)
- **题型**：计算题（12 分）
- **题面（转录，数值完整）**：

> 为抢救病人，一辆救护车紧急出发，鸣着笛沿水平直路从 t = 0 时由静止开始做匀加速运动，加速度大小 a = 2 m/s²，在 t₁ = 10 s 时停止加速开始做匀速运动，之后某时刻救护车停止鸣笛，t₂ = 41 s 时在救护车出发处的人听到救护车发出的最后的鸣笛声。已知声速 v₀ = 340 m/s，求：
> （1）救护车匀速运动时的速度大小；
> （2）在停止鸣笛时救护车距出发处的距离。

- **评分**：可动 3 · 元件 2 · 读数 3 · 几何 3 · 图依赖 3 · 数据 3 = **17**
- **为什么选它**：
  1. 数据全齐、无图、答案硬（20 m/s、680 m），是整套里最干净的"读题 + 解题"探针；
  2. 两段运动 + 声波追及，`STEPS` 边界清楚（t₁ = 10 s 换段，t₀ 停笛，t₂ = 41 s 收到）；
  3. 如果这题都画不好，问题一定不在元件卡，而在读题/解题——正好当"第五类"的对照组。
- **命中元件**：`block`（车）×1 `ground`；声波没有对应元件（见下）
- **预期关键事件**：
  - 0–10 s：匀加速到 20 m/s，位移 100 m；
  - 10 s–t₀：匀速，期间某刻停笛；
  - t₀–41 s：声音以 340 m/s 回传，走完 t₀ 时刻车的距离。
- **预期答案**：**（1）20 m/s；（2）680 m**（原卷解析已给出）。
- **重点卡**：`wb_el_block`（宽高别写像素、块心别算到板外）、`wb_el_ground`
- **风险/预判**：
  - **声波不是 30 个元件之一**。模型大概率会想画"声波扩散"，然后无卡可用，退到 `raw_composite` 或干脆不画 —— 这正是"卡缺一个元件"的证据；
  - 如果它把声波画成一条水平箭头，会撞 C1（箭头契约）；
  - 建议记录：它选了哪个元件表达"声音"。

### M4 · 2024 全国甲卷第 7 题（蹦床 F–t）

- **来源**：同上（[2024 全国甲](https://zy.21cnjy.com/23357451)）
- **题型**：多项选择（6 分）
- **题面（转录，数值完整）**：

> 蹦床运动中，体重为 60 kg 的运动员在 t = 0 时刚好落到蹦床上，对蹦床作用力大小 F 与时间 t 的关系如图所示。假设运动过程中运动员身体始终保持竖直，在其不与蹦床接触时蹦床水平。忽略空气阻力，重力加速度大小取 10 m/s²。下列说法正确的是（　　）
> A．t = 0.15 s 时，运动员的重力势能最大
> B．t = 0.30 s 时，运动员的速度大小为 10 m/s
> C．t = 1.00 s 时，运动员恰好运动到最大高度处
> D．运动员每次与蹦床接触到离开过程中对蹦床的平均作用力大小为 4 600 N

- **评分**：可动 3 · 元件 2 · 读数 3 · 几何 2 · 图依赖 2 · 数据 3 = **15**
- **为什么选它**：
  1. 触网—最低点—离网—最高点—再落，四段都在 2.3 s 内，`SIM.duration` 和 `STEPS` 有明确的物理依据；
  2. F–t 图本身就是 `chart` 卡的正例（面积 = 冲量）；
  3. 变力冲量是"能不能从图里取数"的直接检验。
- **命中元件**：`ball`（人）×1 `chart`（F–t）`ground`
- **预期关键事件**：
  - t=0 触网；t=0.15 s F 最大（最低点，v=0）；
  - t=0.30 s 离网，v=10 m/s（向上）；
  - 1.30 s 最高点；2.30 s 再触网。
- **预期答案**：**BD**（原卷解析已给出；平均作用力 4 600 N）。
- **重点卡**：`wb_el_chart`（面积填充、符号题也要画）、`wb_el_ball`、`wb_el_ground`
- **A/B 提示**：A 组关 `chart` `ball`；B 组开。
- **风险/预判**：
  - **蹦床不在词表里**。模型很可能拿 `spring` 硬凑（弹簧当网）——这是"卡缺元件"还是"模型乱套"，正好记录；
  - 人用 `ball` 还是 `block`，两种都行，看它选哪个、是否解释。

### E1 · 2024 全国甲卷第 12 题（导轨 + 电容 + 电阻）

- **来源**：同上（[2024 全国甲](https://zy.21cnjy.com/23357451)）
- **题型**：计算题（20 分，压轴）
- **题面（转录，符号完整）**：

> 两根平行长直光滑金属导轨距离为 l，固定在同一水平面（纸面）内，导轨左端接有电容为 C 的电容器和阻值为 R 的电阻，开关 S 与电容器并联；导轨上有一长度略大于 l 的金属棒，如图所示。导轨所处区域有方向垂直于纸面、磁感应强度大小为 B 的匀强磁场。开关 S 闭合。金属棒在恒定的外力作用下由静止开始加速，最后将做速率为 v₀ 的匀速直线运动。金属棒始终与两导轨垂直且接触良好，导轨电阻和金属棒电阻忽略不计。
> （1）在加速过程中，当外力做功的功率等于电阻 R 热功率的 2 倍时，金属棒的速度大小是多少？
> （2）如果金属棒达到（1）中的速度时断开开关 S，改变外力使金属棒保持此速度做匀速运动。之后某时刻，外力做功的功率等于电阻 R 热功率的 2 倍，求此时电容器两极间的电压及从断开 S 开始到此刻外力做的功。

- **评分**：可动 3 · 元件 3 · 读数 2 · 几何 2 · 图依赖 2 · 数据 3 = **15**
- **为什么选它**：
  1. 单棒 + 电容 + 电阻，是 §4.1 #9 的标准形态，`rod` `circuit` `field_region` 三张卡同时命中；
  2. 两阶段（S 闭合加速 → 断 S 后匀速）边界明确，适合验 `STEPS`；
  3. 纯符号答案，正好测 SYMBOLIC 模式（C7 的 `value: null` 分支）。
- **命中元件**：`rod` `circuit`（含电容、电阻、开关）`field_region`
- **预期关键事件**：
  - S 闭合：棒加速，电容被短路，电流经 R；
  - 达到匀速 v₀；某时刻 P_F = 2P_R；
  - 断 S：电容接入，棒维持匀速；之后 P′_F = 2P′_R，求 U_C 与外力功。
