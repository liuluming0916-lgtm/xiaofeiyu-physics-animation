## C. 视觉归一化方案（2026-10-24，用户裁决，**以此为准**）

> 前面的 §0–§5 讲的是“两层尺寸（size 纸面 + physical 物理米）”。C 方案把 `size` 的数字部分**整体退役**：
> **`physical`（物理米）成为唯一尺寸来源；位置和长度用同一个 `s` 折算。**
> 以下与旧文冲突处，以本节为准。

### C.1 三条规则

1. **位置和长度都写物理米**；本地 `s = min(8.8/宽, 5.28/高)` 统一折算到 10×6 纸。
2. **`state.w/h/r` = 卡里的 `physical`（物理米）**；渲染时乘同一个 `s`。
3. **贴合/连接靠“同一把尺子”**：位置和尺寸同乘 `s`，线性变换保比例 ⇒ 物块底 = 板顶，**误差 0**，不需要 anchor / yDraw / 求解器。

### C.2 可见性与溢出

- **包络 = 轨迹采样 ∪ 元件半尺寸（physical）∪ 6% 边距**，等比例 contain，居中；相机固定拍纸。
- **像素下限 `MIN_PX = 6`（CSS px）**：闭合多边形按 bbox 中心放大到至少 6 px 见方；圆半径至少 3 px。
  只在“布局 → 像素”之后判断；极端大题里元件进入“符号模式”（可见，但接触不再承诺）。
- **不加 `maxPx`**：正常路径下包络已经保证元件不超纸；“太大”靠包络与（后续的）纸面溢出告警，不靠像素上限（像素上限会破坏真实比例和导出 WYSIWYG）。
- 老程序（无 `SIM.stage`，15 道回归题）**不折算**，行为不变。

### C.3 卡字段

| 字段 | 含义 |
|---|---|
| `physical.{w,h,r}` | **唯一尺寸来源**，物理米；7 类运动元件必填（至少 h 或 r）；`board` 只给厚度 h，长度按题面 |
| `size.shape` | 只表达形状（教学用），不再存任何数字 |
| `size.rotatable` | 是否可转（教学用） |

题面不给小物块尺寸是常态：**卡里的 `physical` 就是默认画法**；analysis 与渲染用同一个数，接触仍精确。
题面明写尺寸时，以题面为准（analysis 的 `y0` 与 drawFrame 用同一个值）。**视为质点的小物块也画成方块**（用户 2026-10-24 明确）。

## 0. 一句话

**模型只画物理世界；元件卡给两层尺寸：`size`（10×6 纸面单位）管外观、`physical`（物理米）管质心；
位置由本地折到 10×6 纸，长度/半径一律用纸面单位、不缩放。**

## 1. 五个问题的最终答案

| # | 问题 | 结论 |
|---|---|---|
| 1 | `analysis` 的 `x/y` | **质心**。所有元件统一，不保留“静止元件用接触点”的例外。 |
| 2 | 卡片尺寸单位 | **两个尺寸块**：`size` = 纸面单位（跨题一样大，**不乘 s**）；`physical` = 物理米（只给 analysis 算质心高度）。 |

## 3. 卡字段（B1 返工后的终态）

### 3.1 元件卡（`kind: "element"`）

```json
{
  "kind": "element",
  "elements": ["block"],
  "size":     { "anchor": "bottom", "shape": "box", "w": 0.4, "h": 0.3, "minPx": 36, "rotatable": true },
  "physical": { "w": 0.2, "h": 0.1 }
}
```

- `size`：**必填**（element 卡）；纸面单位；按 `shape` 必填 `w/h` 或 `r`。
- `physical`：物理米；**7 类运动元件必填**，其余可缺省；只用于 analysis 算质心。
- `board` 特例：`size.h` / `physical.h` 必填；`size.w` / `physical.w` **可缺省**（长度由模型给）。

### 3.2 场景卡（`kind: "scene"`）

- **不写 `size`，也不写 `physical`**；
- 尺寸由模型按题面/轨迹/演示需要自主调配；
- 卡只保留判据、画法、状态字段说明。

### 3.3 `physical` 值（用户确认的 7 类）

| type | physical（米） |
|---|---|
| block | w 0.2, h 0.1 |
| ball | r 0.05 |
| board | h 0.02（w 缺省） |
| conductor_rod | w 0.5, h 0.02 |
| light_rod | w 0.5, h 0.02 |
| piston | w 0.05, h 0.02 |
| mercury | h 0.1（w 缺省） |
| spring / rope / trace_path / graph_wave | 不写（不作运动刚体） |

## 4. `analysis` 契约

- `x/y` 是**质心**；`y0 = 支撑面 + physical.h/2`（球用 `r`）；单位米。
- 输入增加一段**只读 `physical` 表**（上面 7 行，带“不得写进输出”的明确禁令）；
  `size`（纸面）**不给** analysis，避免模型用错单位。
- **不输出** `w/h/r/pointR/size/physical`；解析器遇到这些字段报 `analysis.size-not-allowed`
  （不是静默忽略）。
- `t0/x0/y0/vx0/vy0/ax/ay`、连续性、锚点校验**不放宽**。
- `type` 目前是自由文本（只查长度与一致性）。`physical` 按 `type` 查表，写错会静默退化成
  “没有尺寸的点”。**用户已裁决（23:47）：A —— `type` 必须是 11 个元件 id 之一，`unknown` 不再允许；
  对不上报 `analysis.type-unknown` 硬错。** 实现放在 B2（与 parser 的 `size-not-allowed` 一起）。

## 5. `scene_code` 契约

- **位置**参数写物理米（`state.<key>.x/y`）；
- **长度/半径**参数写纸面单位（`state.<key>.w/h`、板厚、舞台范围）；
- 输入里增加：**纸面运动范围**（画地面/带/板够长）、**板的固定厚度（只读）**；
- 不画 `v/a`（`SIM.bodies` 自动）；`force` 不教；`aux` 保留；
- 板：`Draw.box([x, y], 板长, 板厚)`，板长由模型按纸面范围给；
- 静止场景（地面/带/斜面/滑轮/绳/导轨）由模型按读题几何摆，尺寸自由（场景卡不固定）。

> 单位口径要写进提示词的一句话：**“位置用物理米，长度用纸面单位；两者不要相加。”**

## 6. 最小题（block + belt）目标文本

题面：传送带 `u=2 m/s` 向右；物块（`m=1 kg`）无初速轻放，`μ=0.2`。
卡：`size` 0.4×0.3（纸面），`physical` 0.2×0.1（米）。

### 6.1 `analysis`（只给质心）

```text
element: block_A
type: block
segment: 1
t0: 0
t1: 1.0
x0: 0
y0: 0.05
vx0: 0
vy0: 0
ax: 2
ay: 0
x: x0 + vx0*(t - t0) + 0.5*ax*(t - t0)^2
y: y0
```

`y0 = 0.05` 来自 `physical.h/2`。**没有** `w/h/size/physical` 字段。

### 6.2 `stateAt`

```js
state.block_A = { x: <物理>, y: 0.05, w: 0.4, h: 0.3, type: 'block' };
```

`w/h` 来自 `size`（纸面），不乘 `s`。

### 6.3 `drawFrame`

```js
Draw.belt([x0, 0], [x1, 0], { r: 0.1 });              // 位置物理米；r 纸面单位
Draw.box([state.block_A.x, state.block_A.y], state.block_A.w, state.block_A.h);
if (state.f > 1e-9) Draw.arrow([state.block_A.x, state.block_A.y], [state.f, 0], { category: 'aux', label: 'f' });
```

### 6.4 贴面精度（必须知道）

纸面尺寸固定 + 物理质心 ⇒ 图标相对支撑面的偏差 ≈ `(s·physical.h - size.h)/2`。
只有当 `s = size.h / physical.h` 时才严丝合缝；块（0.3/0.1）在 `s≈3` 最准，球（0.08/0.05）在 `s≈1.6` 最准。
**不同元件不可能在同一 `s` 同时精确贴面**——这是本方案的固有性质，不是 bug。
处理方式：提示词按 `physical` 放质心，B4 用 1 m / 3 m / 1e6 m 三道样张验收；**不引入求解器**。
