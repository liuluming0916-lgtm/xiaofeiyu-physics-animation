# 画图流程白话版：方案二（物理世界坐标 + 相机自动取景）

> 2026-10-24：用户选定**方案二**，已落地。
> 一句话：**本地算运动，AI 算画法；画面用物理米，相机自动取景。**
> 不再有 10×6 布局纸，不再有 `cx/cy`。
> 契约：[`v1.1.18-方案二契约.md`](v1.1.18-方案二契约.md)。

---

## 0. 先看一句话

- `analysis` 给物理运动方程（米、秒、质心）；
- `state.<key>.x / .y` 是**物理米**（质心）；
- 画图 AI 直接在物理世界里画：尺寸、地面/带/斜面长度、比例、构图都由它定；
- 相机**自动取景**：AI 画到哪里，画面就框到哪里；
- 本地只留：时间归一化、v/a 箭头、C1–C9、播放器。

**允许“示意”**：物块可以画 1 m，即使题面是 0.2 m；不承诺严格贴面/接触。

---

## 1. 一张图看懂

```
题目（文字 + 图片）
   │
   ├─① 读题 AI：图里有什么、谁在左谁在右、用到哪些元件/场景
   │
   ├─② 解题 AI：解题过程
   │
   ├─③ 物理分析 AI：每个物体每一段的运动公式 x(t)、y(t)（单位：米）
   │
   ├─④ 本地程序：
   │     · 生成 state.<key> = { x, y, type }（物理米，质心）
   │     · 生成 VIEW：bodies.at = [x, y]（v/a 箭头由此求导）
   │     · 时间归一化（每小问 4 s）
   │
   ├─⑤ 画图 AI：只写 drawFrame
   │     · 位置：读 state.<key>.x / y
   │     · 尺寸、地面长度、斜面角度、弹簧长度：自己定（米，可示意）
   │     · 不写字、不画 v/a、不重算运动
   │
   ├─⑥ 本地检查 C1–C9：语法、接线、瞬移、时间……
   │
   └─⑦ 播放器：相机自动 fit 物理世界；v/a 箭头用同一套物理坐标
```

**关键分工：**

| 谁 | 负责什么 | 不负责什么 |
|---|---|---|
| 物理分析 AI | 运动公式（米、秒、质心） | 画多大、布景、取景 |
| 本地程序 | `state.x/y`、`VIEW.bodies`、readouts、时间归一、v/a 求导 | 尺寸、比例、构图 |
| 画图 AI | 尺寸、比例、构图、静态布景、`drawFrame` | 重算运动、写文字、v/a |
| 播放器 | 物理世界 → 屏幕像素（自动 fit） | 物理、布局 |

## 2. `x / y` 是什么？用一道题看

假设物块从 `x=1.2 m` 开始向右走，质心高度 `y=0.05 m`。

`analysis` 给：

```
x(t) = 1.2 + 2*t
y(t) = 0.05
```

本地生成：

```js
state.block_A = {
  x: 1.2,       // 物理米，质心
  y: 0.05,
  type: 'block',
};
```

画图 AI 可以这样写：

```js
Draw.ground(-2, 8, 0);
Draw.box([state.block_A.x, state.block_A.y], 0.6, 0.4);
```

- 物块画在物理 `(1.2, 0.05)`，尺寸 0.6×0.4 m（示意，不必等于题面）；
- 相机自动 fit 这个世界；
- v/a 箭头按 `SIM.bodies.at` 的物理坐标求导，和画图同坐标系，不会错位。

> 以前的 `cx/cy` 是“10×6 纸上的格子坐标”。
> 方案二已经把它删了：新程序没有 `SIM.stage`，也没有 `cx/cy`。

---

## 3. 为什么删掉 10×6 / `cx/cy`？

因为 v/a 箭头必须和画面用同一套坐标。

- 旧方案：本地把米折成 `cx/cy`，箭头和画图都用纸坐标 → 一致；
- 新方案：AI 自己定比例。如果本地还按固定纸算 `cx/cy` 给箭头，
  而 AI 按自己的比例画物体，箭头就会和物体错位。

所以方案二只有“物理世界 + 自动取景”这一条自洽路线。
旧导出 `铁中26-14.html` 就是这么跑的。

---

## 4. 代价（用户已接受）

| 代价 | 说明 |
|---|---|
| 接触/贴面不再保证 | `state.x/y` 只给质心；物块底是否贴带面，由 AI 摆 |
| 相机可能被静态件撑大 | AI 把地面画得很长，相机会 zoom out；提示词要求“主体别太小/别太偏” |
| 同题两个物体比例可能不一致 | AI 自己定尺寸；卡里要求“同类元件尽量同量级” |
| 大跨度题物块可能很小 | AI 应把示意物块画大；这是它的责任 |

换来的自由：AI 可以为了“好看”整体放大/缩小/挪位置，不再被固定纸绑住。
