# q04 A 的运动方程核对（2026-10-24）

> 问题：A 的运动方程到底对不对？
> 结论：**前 3 段对；第 4 段（剪断 B–C 后）不对**。
> 按题面给的力，A 第一次到最左端应是 **x = −2 m**；参考答案 **x = 1/2 − 7√10/10 ≈ −1.7136 m** 与受力不一致。

---

## 1. 题面数据

- m_A = 2 kg，m_B = 3 kg；
- 由 (2) 得 m_C = 3 kg，μ = 0.5，f = μ m_A g = 10 N；
- F = −20x（图 (b) 过原点、x=1 时 −20 N、x=6 时 −120 N）；
- g = 10 m/s²；
- 传送带顺时针，带面向右；A 与带在 x=1 时共速；
- 取向右为 x 正方向。

---

## 2. 剪断前：A、B、C 整体

### 2.1 0 ≤ x ≤ 1：A 比带慢，摩擦力向右

整体沿运动方向：

```
F + f + (m_B+m_C)g = (m_A+m_B+m_C)a
−20x + 10 + 60 = 8a
a = 8.75 − 2.5x = −2.5(x − 3.5)
```

这是以 x=3.5 为平衡位置的简谐型运动，ω = √2.5 ≈ 1.5811。

从 x=0、v=0 积分到 x=1：

```
v²(1) = 2∫₀¹ (8.75 − 2.5x) dx = 2(8.75 − 1.25) = 15
v(1) = √15 ≈ 3.873 m/s
```

所以 **传送带速度 = √15 m/s**（x=1 共速）。

### 2.2 1 ≤ x ≤ 4：A 比带快，摩擦力向左

```
−20x − 10 + 60 = 8a
a = 6.25 − 2.5x = −2.5(x − 2.5)
```

从 x=1、v²=15 积分到 x=4：

```
v²(4) = 15 + 2∫₁⁴ (6.25 − 2.5x) dx
      = 15 + 2[(25−20) − (6.25−1.25)]
      = 15 + 0 = 15
v(4) = √15
```

x=4 再次与带共速。

### 2.3 4 ≤ x ≤ 6：A 又比带慢，摩擦力向右

```
−20x + 10 + 60 = 8a
a = 8.75 − 2.5x
```

从 x=4、v²=15 积分到 x=6：

```
v²(6) = 15 + 2∫₄⁶ (8.75 − 2.5x) dx
      = 15 + 2[(52.5−45) − (35−20)]
      = 15 + 2(7.5−15)
      = 0
```

所以 **A 第一次到 x=6 时速度恰好为 0**，然后开始向左。  
**前 3 段与图 (c) 一致，A 的方程是对的。**

---

## 3. 剪断 B–C 后：A、B 系统

剪断后 C 不再参与；A、B 仍由绳连接。A 向左，B 向上。

- A 受：F = −20x（左），摩擦力向右 +10 N，绳张力 T 向右；
- B 受：重力 30 N 向下，绳张力 T 向上；
- 取向右为正，B 向下为正（A 右时 B 下），a_B = a_A：

```
A: −20x + 10 + T = 2a
B: 30 − T = 3a
```

相加：

```
−20x + 40 = 5a
a = 8 − 4x = −4(x − 2)
```

从 x=6、v=0 积分到最左端 x：

```
v²(x) = 2∫₆ˣ (8 − 4s) ds
      = 2[8s − 2s²]₆ˣ
      = −4x² + 16x + 48
```

令 v=0：

```
−4x² + 16x + 48 = 0
x² − 4x − 12 = 0
(x − 6)(x + 2) = 0
x = 6（起点）或 x = −2
```

**最左端 = −2 m。**

---

## 4. 参考答案的 −1.7136 m 为什么不对

把 x = 1/2 − 7√10/10 ≈ −1.7136 代回上面的 v²(x)：

```
v²(−1.7136) = −4(2.936) + 16(−1.7136) + 48
            ≈ −11.744 − 27.418 + 48
            ≈ 8.84 (m/s)²
v ≈ 2.97 m/s ≠ 0
```

也就是说：**A 到 −1.7136 m 时还在向左走，并没有停**；它还会继续走到 −2 m 才第一次停下。

所以 −1.7136 m **不是**“第一次运动到最左端”的位置（在题面给的力下）。

---

## 5. 程序里第 4 段是什么

`tests/reports/q04-model.program.json` 的 segment 4：

```
x = 2.143203 + (6 − 2.143203) cos(2(t − t0))
```

这是以 **x = 2.143203** 为平衡位置、振幅 3.8568 的简谐运动；从 x=6 出发，到 x=−1.7136 恰好是另一半周期。

但物理平衡位置应是 **x=2**：

```
a = 8 − 4x = −4(x − 2)
```

程序把平衡位置从 2 改成 2.143203，相当于额外加了约 **2.86 N** 的常量力（或把摩擦力从 10 N 改成约 12.86 N）。题面没有这个力。

**结论：程序第 4 段是为了凑参考答案而拟合的，不是从受力推出来的。**

---

## 6. 那到底谁对？

两种可能，需要你确认：

1. **题面漏了条件**：比如剪断后 F 撤去/改变、传送带停下或反向、B 的质量/连接方式不同、A 离开传送带等。  
   有了这些条件，−1.7136 可能成立。
2. **参考答案或题面本身有误**：按现有条件，A 的最左端应是 −2 m。

在题面不改的情况下，**A 的运动方程第 4 段应按 a = 8 − 4x**，最左端 **−2 m**。
