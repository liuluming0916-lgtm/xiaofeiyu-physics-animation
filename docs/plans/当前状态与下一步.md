## 1. 已锁定决策

- 坐标分三层：
  - 物理层 `x / y`：米，只给物理、读数、C10；
  - 场景层 `u / v`：布局单位，由 `auto_stage` 折算（10×6 纸）；
  - 元件层：**尺寸唯一来源是卡 `physical`（物理米）**；`state.w/h/r = physical`，
    渲染时与位置**同乘一个 `s`**（C 方案，2026-10-24，见 `v1.1.18-B契约.md` §C）。
- **不设 50 m 阈值**；同一类元件按**物理比例**画（尺寸 × s），不再要求跨题像素一致；
  极端题靠 `MIN_PX = 6` 像素下限兜底（符号模式）。
- 场景卡（belt/incline/ground）**不写尺寸**，由模型按题面几何画；`Draw.belt` 端点 = 带面顶。
- **版面骨架不做**（2026-10-23 用户裁决：过度工程）。只保留 `auto_stage` 这一条：
  **固定 10×6 纸 + 物理比例尺寸 + 相机拍纸**（已实现）。
- 大模型只报语义（有电路/磁场/导轨），**不写画幅、坐标、比例尺**。
- 场景卡只当布景道具；`state.layout.anchors` 搁置。
- 已硬删除：`Draw.text`、`Draw.latex`、`Phys.interp`、`Phys.roots`、`Phys.format`。
- `Phys.integrate` 保留为未来 ODE 接口；`Runtime.format` 只是图表脚注格式化。
- **知识卡：v1 弃用，`core/knowledgecard/data-v2/` 是唯一在用的库**（31 张）。
- **物理分析用“段锚点增量”写法**：`x0 + vx0*(t - t0) + 0.5*ax*(t - t0)^2`；
  `t0/x0/y0/vx0/vy0` 是本段字段，由 `core/analysis/generate.mjs` 原样代入。
- **analysis 提示词逐字用用户版本**；`yA / yB` 字段已删（玻璃管/水银柱暂不支持）。

## 4. 时长归一 / 联动（已实现）

- 边界来源：`couple` 给每个步骤标 `sub`（第几小问）；同一 `sub` 的步骤 `[min t0, max t1]` 是该问的物理区间。
- `core/timing/display-time.mjs`：`buildDisplayTiming(stepTimes)` → `timeMap` + `displayDuration`（4 × 小问数）
  + 换算到显示秒的 stepTimes；写进 `PROGRAM_DATA`。
- 播放器 `player.state.t` 仍是物理秒；时间轴 / 时间码 / 步骤跳转 / 播放推进 / 图表横轴用显示秒。
- 时间轴不显示秒，时间码是「第 k / n 步」；**图表横轴仍是真实物理秒**。
- 倍速 6 档预设 + 自定义 0.1–20×（`rate-custom`，共用 `applyRate()`）。

## 6. 已知问题

1. **账本/审计不可用**（P0 已缓解）：Electron 33 是 Node-API 9，better-sqlite3 13 要求 10；
   `require` 会在原生层 0xC0000005。现已在 `core/history/index.mjs` 加 N-API 闸门（<10 不加载），
   应用/导出正常，账本降级。要恢复账本：升级 Electron 35+ 或换 N-API 9 产物。
2. 模板“第一次注入即锁死”（`program-already-inlined`）：靠“跑完才注入”绕开；要支持自愈重画需改模板。
3. q04 是模型生成后人工修补，不能算“模型一次通过”。
4. q09 卡销位置与活塞行程对不齐（词表没有“卡销”）；汽缸比例偏细。
5. 自愈没有“确定性错误”识别：同一诊断逐字复现时仍跑满轮次。
6. couple 允许省略纯概念步，个别步骤没有时间区间（设计允许）。
7. `tests/real-exam` 被覆盖自检豁免；q04/q06/q09 不在 `verify-all` 里跑。
8. JPEG 拆图退回整图（只支持 8 位非隔行 PNG）。
