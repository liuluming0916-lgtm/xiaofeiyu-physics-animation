# 金标准候选验收单 v1

> 状态：口径（2026-10-23，第二版）
> 依据：用户裁决 —— **金标准 = 模型产出 + 人工验收通过**（手写不算）；**画面好不好由人判，不由工程量阈值判**。
> 适用：`tests/real-exam/` 三道试点题（q04 / q06 / q09）以及之后接管编号的新题。

## 0. 为什么要有这张单

q06 的 `pass`（961 帧）+ 人工打回，两件事同时成立，说明**门禁管不到画面**。
更麻烦的是打回原因当时写成“待补”，一周后没人知道该修什么 —— 这一单补的是那个洞：
**打回要留一句人能看懂的话**，不是留一个我编的分数。

## 1. 三道门，顺序不能换

| 门 | 谁判 | 判什么 | 不过怎么办 |
|---|---|---|---|
| ① 自动门禁 | `node tools/_check-real.mjs <id>` | C1–C10、`frames > 0`、无 blocking | 修代码/重跑，不进人工 |
| ② 画面 | **人**（附 `_shot` 出的图 + 单文件 HTML） | 能不能拿去讲课 | 打回，写一句话 |
| ③ 内容与物理 | 人（对教师答案） | B1–B4 | 打回，写 B 编号 |

①②③ 全过，`tests/real-exam/index.json` 的 `status` 才能从 `candidate` 改成 `accepted`。

## 2. 画面门（A）：只给人看，不设阈值

**不再有 A1–A6 这种我替人定的“占屏 / 宽高比 / 美观”判据**（2026-10-23 用户否决：
“小肥鱼不要替人类判断美观程度”）。

现在只做两件事：

1. **把画面摆到人面前**：`node tools/_shot.mjs <program.json> --n 6` → `python tools/_shot.py <dir>` → 拼版 PNG；
   同时给**单文件 HTML**（`tools/_build-page.mjs`），能播能拖时间轴。
2. **报事实，不下结论**：取证数据（内容包围盒、帧数、时长、读数极值）附在报告里，**只作参照**。

人怎么判：一句“可以 / 不行 + 哪里不行”。`index.json` 的 `rejectReason` 就写这句话，不强制编号。

已知的、**不算问题**的项（2026-10-23 逐条确认）：

| 现象 | 结论 |
|---|---|
| 内容呈扁条、上下留白多 | **现有比例可以，够演示用**；宽高比留给自动舞台，不在这里卡 |
| 金属棒细、和磁场符号同色 | 棒能清晰看见 |
| 电阻画成矩形块 | 目前没问题 |
| 磁场符号只覆盖部分区域 | 示意可行，就这样 |
| 外力箭头很小 / 缺失 | **本来就要删**，不是缺陷 |
| 画面外沿有一条孤立坐标轴 | 不影响演示 |
| 开关符号全程不变、看不到“闭合→断开” | **现版本不需要**，示意图对即可 |
| 电容与开关画在同一条支路（串联） | **属电路场景卡质量问题**（`wb_sc_wire` 没给符号库和并联拓扑规则），不算模型错 |

## 3. 内容与物理门（B）

| 编号 | 项 | 判据 |
|---|---|---|
| B1 | 答案一致 | `readouts` 的极值/事件值 == 教师答案。**符号题按比值归一化是合格的“优秀产出”，不算编数** |
| B2 | 步骤同源 | `STEPS` 的每一步结论与教师解析同源，不另起炉灶 |
| B3 | 事件对齐 | 步骤时间轴 ↔ 物理事件（共速 / 断开 / 最大速度 / 离开卡销）逐一对上 |
| B4 | 分段连续 | 阶段交界处位置连续；不出现“瞬移”“消失的物体” |

## 4. 打回记录格式

```json
{
  "status": "rejected",
  "rejectedAt": "2026-10-23",
  "rejectReason": "画面：电路挤在左边，右边导轨空着；听讲解时看不出棒在动"
}
```

规则：

1. 写**人话**，说清“哪里不对”；
2. 能指出 B 项就写 `B1`…，纯观感就不写编号；
3. 同一题连续两次打回同一处 ⇒ 停下来改卡片/提示词，不再重跑。
