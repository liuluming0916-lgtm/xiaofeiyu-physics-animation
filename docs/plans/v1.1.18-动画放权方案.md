## 0. 一句话结论

**“过度工程”的实质不是约束数量多，而是同一件事在三层说了三遍、且互相打架。**

先做 **A（统一口径 + 去重 + 压缩）**：不换契约、不牺牲接触精度，1.1.18 可做。

## 1. 现状事实

### 1.2 三层在重复什么

- `t0States` 给的 t=0 坐标，`state.*.cx/cy` 本来就有；
- `stateMap` 又把 analysis 的元件 id、anchor、位置读法抄一遍；

### 1.3 真正会害人的是“互相打架”

`core/knowledgecard/data-v2/93-elements.json` 里有 **12 张卡**（11 张启用 + `graph_wave` 封存）

- “按读题几何用**固定世界坐标**画”（`wb_sc_pulley:237`、`wb_sc_ground:169` 等）

## 2. 先别删的两样东西（删了会退步）

### 2.1 `t0States` 不是装饰

`41bed94` 的提交说明写得很清楚：**“scene_code 的 user 补 STEPS 标题 + t0/t1 + t=0 各元件布局坐标（治斜面画歪）”**。
它是为了修真实缺陷加的。直接删，斜面/滑轮大概率重新画歪。

### 2.2 `anchor` 是接触精度的来源

`state.<key>.cx/cy` 给的是**元件某一面**的坐标（bottom/top/center），模型自己定尺寸后按 anchor 偏半个尺寸，
物块底才能精确贴带面。去掉 anchor ⇒ 接触不再有保证（B 方案）。

## 3. 方案 A（推荐，1.1.18 可做）

目标：**同一件事只说一遍，同一套坐标只留一个说法**；契约不变。

### A1 统一 12 张卡的坐标口径（先做，零行为损失）

把四类句子机械替换（同一份 `93-elements.json`）：

| 原文 | 改为 |
|---|---|
| 按读题几何用固定世界坐标画 | 按读题几何用布局坐标（0–10 × 0–6）画 |
| 静止几何用固定世界坐标，不跟 `state` 漂移 | 静止几何用布局坐标（0–10 × 0–6），不跟 `state` 漂移 |
| 也可以是固定世界坐标 | 也可以是布局坐标（0–10 × 0–6） |
| 或固定世界坐标 | 或布局坐标（0–10 × 0–6） |

并加一条**负向卡校验**：启用中的 v2 卡正文不得出现「固定世界坐标 / 世界坐标 / 坐标是米」。
这条比“再写一遍提示词”有用：以后再有人写回去，门禁直接红。

### A2 `scene_code` system 压缩（1,189 → 约 650 字）

保留 5 条硬约束：

1. 只输出 `drawFrame` 函数体；
2. 画布 10×6，布局单位；
3. `state`：`cx/cy` 是位置、`anchor` 是这个点是哪一面、`x/y` 只给读数不要拿去画；
4. 尺寸 / 构图 / 场景摆法自己定（卡里有可照抄的量级）；
5. 位置只从 `state` 读、不重算运动、只调 `Draw.*`、不写字、不画 v/a。

删掉：

- “地面画在运动元件脚下 / 带面穿过 t=0 接触点 / 绳连到真实锚点 / 不要悬空”——这些是**画法**，应在卡里；
- 重复的“尺寸由你定”三段（合并成一句）；
- 与卡重复的“颜色由系统决定 / 一屏画完”两条（卡与运行时会兜）。

### A3 user 注入去重（不改 `t0States`，只删重复）

- `stateMap` 只留 `key = id（type）` 一行；**删掉 anchor 的中文解释**（`state.anchor` 已有值，system 已解释一次）；
- `steps` 压成一行一条：`1. 0–1.2 第 1 步标题`（已经是这样，保持；不删）；
- `t0States` 保留（见 §2.1）；
- `readProblem` 保留（静止件摆放依据）。

预计 q04 的 user 从 3,653 → 约 3,300 字，system 少约 540 字；**主要是去冲突，不是省 token**。

### A4 卡的自检去重（可选，收益小）

31 张卡的「自检」都在重复「位置用 `cx/cy`、尺寸自己定、不写字」。
可以只留一条全局约定，卡里只保留“这条元件最常错的地方”。
风险：卡的“可照抄写法”是实测有效的，去自检可能降低约束；建议**先不动**，等 A1–A3 跑完 q04 再评估。

### A5 验收

- `node tools/verify-all.mjs` 56 步全红→全绿（新增卡校验只加断言，不加步骤）；
- 15 道回归题 dry-run 不变；
- q04 重跑一次，与 06:23 的 835 帧版本对比（不只看 pass，要看画面截图）；
- 记录改前/改后的 system/user 字数与 `promptHash`。

## 4. 方案 B / C（不在 1.1.18）

### B（1.1.19 再议）：去掉 anchor，只给元件中心

- `state` 只给中心布局坐标；模型自己决定怎么贴；
- 自由度更大，但“物块底贴带面 / 球心离地 r”不再有结构性保证；
- 需要 q04（滑轮/斜面）+ q06（绳-滑轮）两题 A/B，才能判断是否值得。

### C（不建议）：把 `stateAt/VIEW` 也交给模型

- 本地只留 C1–C9；等于把 v6 的核心（运动由 analysis 生成）退回去；
- 成画率、物理正确性、修复分类都会重新洗牌；
- 不属于“瘦身”，是换链路。
