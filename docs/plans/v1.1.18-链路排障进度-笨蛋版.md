## 2. 方案二落地：画面怎么画

**一句话：本地算运动，AI 算画法；画面用物理米，相机自动取景。**

```
analysis：物理运动 x(t)/y(t)（米、质心）
      ↓
本地：state.<key> = { x, y, type }；VIEW.bodies.at = [x,y]
      ↓
画图 AI：直接在物理世界里画；尺寸/比例/构图自己定，允许示意
      ↓
播放器：相机自动 fit；v/a 箭头用同一套物理坐标
```

- **没有 10×6 纸**，**没有 `cx/cy`**，**没有 `anchor`**；
- `state.x/y` 是质心（米）；
- 物块可以画 1 m，即使题面是 0.2 m（示意）；
- 接触/贴面不再有结构性保证——这是你接受的取舍；
- 时间归一化、v/a 箭头、C1–C9 仍由本地做。

详细版：[`画图流程-白话版.md`](画图流程-白话版.md)。
