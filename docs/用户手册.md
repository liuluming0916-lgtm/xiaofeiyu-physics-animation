## 一、这是什么

把一道物理题（文字或拍照）变成**能动、能量化讲**的动画，再导出成网页或 GIF。

- 给**中学物理老师**用；
- **全程在本机跑**，题目和密钥不上传；
- 一条题 1–3 分钟出结果，画错了会告诉你错在哪。

它不做题库，也不做在线服务——题目由你输入，动画归你使用。

## 二、安装

### 2.1 安装版（推荐）

1. 双击 `小肥鱼物理解题动画-Setup-x.y.z.exe`；
2. 选安装目录（默认在用户目录下，**不需要管理员权限**）；
3. 勾选要不要桌面快捷方式；
4. 装完从开始菜单或桌面打开。

第一次运行如果被 Windows 拦下，点「更多信息 → 仍要运行」。

### 2.2 绿色版

解压 zip 到任意文件夹，双击 `小肥鱼物理解题动画.exe` 即可，不写系统目录。

> 建议放在**不含空格和特殊字符**的路径下，例如 `D:\物理动画\`。
> 绿色版和安装版共用同一份用户数据，别同时开两个。

## 三、第一次打开，做两件事

### 3.1 连上你自己的模型

点右上角 **⚙ 连接设置**，填三项：

| 项 | 填什么 |
|---|---|
| 接口地址 | 兼容 OpenAI 协议的地址，一般以 `/v1` 结尾 |
| 模型名 | 例如你的服务商给的模型 ID |
| 密钥 | 你的 API Key，**只存在你本机** |

填完点「测试连接」。能通就直接用。

### 3.2 不想填？也能先看看

不填密钥也能启动，界面会用**内置的一道真题**跑通全流程，
让你先看看动画长什么样（这种运行会标「未校验」）。

## 四、跑通第一道题（5 分钟）

1. **贴题目**：在「解题」页把题面粘进左侧文本框，或者点「选择图片」传照片；
2. **可选补充**：如果有参考答案或解析，填进「参考答案 / 解析」——填了模型就按你的解析整理，
   不自己另算一套；
3. **点「开始生成动画」**；
4. 等右侧的小肥鱼走完八个阶段；
5. 看**校验报告**；
6. 到「动画」页讲，或直接「导出」。

## 五、解题页：三个地方值得看

| 位置 | 看什么 |
|---|---|
| **阶段大标题** | 现在在干什么（读题 / 解题 / 分析 / 画图 / 检查 / 修复） |
| **校验报告** | 结论 + 每一条检查过没过；没过的那条会指出具体位置 |
| **知识卡依据** | 这次命中了哪几张卡、为什么命中 |

**动画不理想时，先看这两处**：报告说哪条没过，通常是画法问题；卡片依据命中的不对，
改卡片比反复重跑有效。

## 六、动画页：怎么讲

| 操作 | 效果 |
|---|---|
| 点左侧「第 N 步」 | 动画跳到这一步对应的时刻 |
| 拖时间轴 | 自动选中当前步骤 |
| 关掉「动画联动」 | 点步骤只换文字，动画不动 |
| 倍速 | 0.1–20 倍，预设 6 档 |
| 速度 / 加速度 / 受力 | 三个开关，分开控制，图例在画布外 |

时间轴显示的是「第 k / n 步」，不显示秒；但**曲线图的横轴是真实物理秒**。

## 七、改讲法：提示词卡

每道题都会按八个阶段的提示词去调用模型。这八份都能改。

1. 进「设置」→ **提示词卡**；
2. 选一份，直接改文字；
3. 点 **保存到本机**（写之前会自动备份）；
4. 改完对**下一道题**生效，正在跑的题不受影响。

想退回官方版本：点 **恢复本版内置**（只撤销你改过的，不影响你自己新建的内容）。

> ⚠ 提示词里有几个**必须保留的记号**，删了会保存失败并告诉你缺哪个——
> 这是故意的：少一个记号，对应的卡片就永远不触发。

## 八、自建知识卡

知识卡决定“这个元件怎么画、什么场景怎么画”。内置 30 张，你可以自己加。

1. 进「设置」→ **知识卡** → 新建；
2. 选类型：**元件卡**（一个元件）或**场景卡**（一个场景）；
3. 填三部分：
   - **触发**：来自词表，选元件或场景，不是自己写关键词；
   - **画法**：怎么画、有哪些易错点；
   - **生成后自检**：几条能自查的判据 + 一段**能跑通的示例代码**；
4. 保存到本机。

三条规矩：

- **一张卡只讲一个元件或一个场景**，别贪多；
- 必须写「生成后自检」小节，否则卡片质量没法保证；
- 示例代码要能通过静态检查（不能出现 `require`、`eval` 这类调用）。

改坏了能回退：**恢复本版内置**只撤销对内置卡的覆盖，不删你自建的卡。

## 十、出问题了怎么办

**先别急着重装。** 每跑完一道题，软件都会在 软件所在文件夹\`开源日志` 里留一份现场
（成功、报错、取消都留），里面是：出错原因、本次的提示词与模型回答、动画代码、解题过程。

**发给我的步骤：**

1. 打开 `开源日志` 文件夹，找到**时间最新的那一对文件**（`.html` + `.json`）；
2. 把**整个文件夹**打包成 zip；
3. 连同那道题的题面一起发给我。

日志里**不含**密钥和绝对路径，可以放心发。

**联系方式**：〔待填：邮箱 / 微信 / QQ 群〕
在软件「关于」里也能看到。

## 十一、常见问题

| 问题 | 怎么办 |
|---|---|
| 不填密钥能用吗 | 能，用内置题跑通流程，判定标「未校验」 |
| 题目会被上传吗 | 不会。只在你点生成时发给**你自己配置**的接口 |
| 换电脑怎么搬 | 拷整个 `%APPDATA%\xiaofeiyu-physics-animation\data\` |
| 生成很慢 | 正常，含校验与自动修复；超过 5 分钟再看日志 |
| GIF 没有曲线图 | 默认只录画布，要曲线就导出网页 |
| 杀毒软件报毒 | 未签名 exe 的常见误报，加信任即可 |
| 卸载会删我的卡吗 | 不会，卸载默认保留用户数据 |
