# 图层开关、约束对账、接着改

- 日期：2026-10-27
- 这一轮的四件事：图层开关、约束对账、打回接着改、布局调整。

---

## 1. 图层开关（本地控制，不重新生成）

契约从 `render(t)` 变成 `render(t, opts)`：

```js
opts = { vel, acc, force, trail, grid, panel }   // 默认全 true
```

播放器第二排就是对应的六个勾选框（速度 / 加速度 / 受力 / 轨迹 / 网格 / 数据），
关掉就当帧重画，不碰模型、不重新生成。

**自动兜底**：沙盒在同一时刻逐个关掉这六层，比较画面图形数量。
一层都关不动 → 报「图层开关没生效」，让它重做，而不是等老师发现。
静态图（本来就没有箭头）会落到警告而不是错误，不拦交付。

## 2. 约束对账（治"每个数都对、彼此矛盾"）

`finish` 现在要申报两样：

- 2~4 个关键数值（原来的抽查点）
- **至少 2 条物理关系**，等号两边都写成数字

```json
{"name": "vy = g·t", "left": 1.5, "right": 1.5}
{"name": "tan60° = vy/vx", "left": 1.732, "right": 1.732}
```

程序验算等号，不通过就不许交付。

这一条是冲着 2026 铁中第 15 题那次失误加的：它把 `vB=√3`、`t=0.15` 都算对了，
但把"从 A 起算的时间"写成了"离 B 还剩的时间"，于是到 B 点时速度变成水平，
和"沿切线入轨"打架。数值抽查抓不到这种错，关系式能。

## 3. 打回 = 接着改，不重来

- 每轮结束把会话存到 `messages.json`。
- 点「打回」，服务端新建一个任务，但**带着上一版的代码和会话**继续，只追加一句老师的意见。
- 记忆压缩：早前的关键帧图片替换成「［早前的截图已省略］」，只保留最近一组；
  文字记录全留。这样既记得错在哪，又不让上下文无限膨胀。
- 打回次数与自动返修共用 3 轮上限。

## 4. 布局

- 动画页左栏固定 **320px**，右边全给画布；顶部有「收起解析」按钮，讲课时可以收起。
- 输入页左栏 40%。
- 播放器两排：上排播放控制 + 时间轴，下排图层开关。

## 5. 验证

| 项目 | 结果 |
|---|---|
| 沙盒自检 `npm run m0` | 5 帧 + 90 采样，1.81 秒，0 错 |
| 手写样例（支持 opts） | 质检通过，开关检测无警告 |
| 反例（不支持 opts 的动画） | 正确报出「图层开关没生效」 |
| 关掉受力/网格/数据三层的截图 | 箭头、网格、数据卡同时消失 |
