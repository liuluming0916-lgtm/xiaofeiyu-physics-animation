# 测试计划与测试用例 · 小肥鱼物理解题动画软件

| 项 | 内容 |
|---|---|
| 文档版本 | V1.0 |
| 编制日期 | 2026-10-25 |
| 阶段 | 软件测试阶段 |
| 测试对象 | 小肥鱼物理解题动画软件 V1.0 |

## 一、测试目标

1. 生成链在各类题目上都能跑通，失败时有明确报错；
2. 判据能真正拦住错误代码（不是摆设）；
3. 导出的产物在离线机器上可用；
4. 密钥与用户数据不外泄。

## 二、测试范围

| 范围 | 是否覆盖 |
|---|---|
| 生成链（八阶段） | 是 |
| 判据 C1–C9 + C10 | 是 |
| 沙箱隔离 | 是 |
| 导出（网页 / GIF） | 是 |
| 桌面壳（本机服务、安全配置） | 是 |
| 账本与观测 | 是 |
| 打包产物 | 是 |
| 多语言 | 否（仅中文） |

## 三、测试环境

| 项 | 配置 |
|---|---|
| 操作系统 | Windows 10 / 11 x64 |
| 运行时 | Electron 35.7.5（Node 22） |
| 显示 | 1920×1080 与 1366×768 各一轮 |
| 网络 | 联网（模型调用）与断网（离线可用）各一轮 |
| 模型接口 | 兼容 OpenAI 协议的第三方端点 + 本地假端点 |

## 四、测试策略

采用**自动化门禁为主、手工验收为辅**的方式：门禁共 **56 步**，覆盖契约、渲染、导出、安全、编排、
账本、观测、打包配置；每次改动必须全绿才允许打包。

| 层级 | 手段 | 规模 |
|---|---|---|
| 单元 | 各模块自检脚本 | 50+ 个脚本 |
| 集成 | 生成链端到端（假模型） | 15 道合成回归题 |
| 系统 | 真实高考题跑通 | 7 道真题 |
| 负向 | 故意注入错误，验证拦截 | 12 条注入 |
| 兼容 | 打包产物真跑 | NSIS 安装 + 绿色版 |
| 静态 | 编码检查、类型检查、布局体检 | 每轮必跑 |

## 五、测试用例（节选）

### 5.1 生成链

| 编号 | 用例 | 预期 |
|---|---|---|
| TC-01 | 纯文字题，模型正常返回 | 八阶段完成，产出可播放动画 |
| TC-02 | 纯图片题，无题面文字 | 用读题标题兜底，不报空槽 |
| TC-03 | 模型输出缺少槽位标记 | 明确报“缺哪个标记”，不产出半成品 |
| TC-04 | 分步讲解阶段失败 | 物理分析结果保留，错误指向该阶段 |
| TC-05 | 步骤对齐两次都失败 | 按比例回退并带告警，整题仍可交付 |

### 5.2 判据与沙箱

| 编号 | 用例 | 预期 |
|---|---|---|
| TC-06 | 注入 `NaN` 状态量 | C3 拦下并定位到行 |
| TC-07 | 注入 0.4 m 瞬移 | C6/C10 拦下 |
| TC-08 | 注入死循环 `while(true)` | C1 静态拦截 |
| TC-09 | 注入静态判不出的死循环 | C2 超时拦截 |
| TC-10 | 注入 `require("fs")` | C1 拦截 |
| TC-11 | 注入无限膨胀数组 | C2 内存上限拦截 |
| TC-12 | 正常代码 | 全部通过，无误报 |

### 5.3 导出

| 编号 | 用例 | 预期 |
|---|---|---|
| TC-13 | 导出网页 | 自包含、无外链、离线可播 |
| TC-14 | 导出网页含密钥字样 | 产物中不得出现 |
| TC-15 | 导出 GIF | 帧数 = 时长×25 + 1，末帧落在结尾，960×540 |
| TC-16 | 同一秒导出两次 | 文件名不覆盖 |

### 5.4 安全

| 编号 | 用例 | 预期 |
|---|---|---|
| TC-17 | 页面尝试调用 Node | 被禁用，拿不到 |
| TC-18 | 跨源写请求 | 403 拒绝 |
| TC-19 | 打开导出目录外路径 | 拒绝 |
| TC-20 | 账本写入带密钥的记录 | 落库前脱敏，库内搜不到 |
| TC-21 | 日志与复现包 | 无密钥、无绝对路径 |

### 5.5 桌面与打包

| 编号 | 用例 | 预期 |
|---|---|---|
| TC-22 | 首次启动无配置 | 可用内置示例题跑通 |
| TC-23 | 本机服务端口 | 随机分配，不写死 |
| TC-24 | 安装包安装 / 卸载 | 可自选目录，卸载不删用户数据 |
| TC-25 | 绿色版解压运行 | 免安装可启动 |

## 六、缺陷管理

| 等级 | 定义 | 处理 |
|---|---|---|
| P0 | 崩溃、数据损坏、密钥泄露 | 立即修，阻塞发版 |
| P1 | 主链走不通、导出不可用 | 本版必修 |
| P2 | 单题效果不佳（构图、标注） | 记入待办，下版处理 |
| P3 | 文案、样式 | 排期处理 |

缺陷修复后**必须补一条回归**，防止再犯。

## 七、测试结论

| 项 | 结果 |
|---|---|
| 门禁 | 56 步全部通过 |
| 生成链 | 22 道题（15 合成 + 7 真题）全部跑通 |
| 负向注入 | 12 条全部被拦下，且定位到注入点 |
| 导出 | 网页自包含校验通过，GIF 结构校验通过 |
| 安全 | 密钥不入库、不进事件流、不进导出物 |
| 结论 | **满足发布条件** |
