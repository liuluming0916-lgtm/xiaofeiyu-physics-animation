## 一、代码结构

```text
core/              生成链路与运行时（与界面无关）
  orchestrator/    编排器：串阶段、发事件
  analysis/        物理分析 → 运动代码
  prompts/         八个阶段的提示词
  lint/            九项判据
  dryrun/          沙箱试运行与套件
  repair/          修复分类与回灌
  export/          单文件网页 / GIF
  knowledgecard/   知识卡数据与引擎
  observability/   运行记录、复现包、开源日志
contracts/         数据契约与生成器（schema + 校验）
sdk/               动画运行时与绘制 API
electron/          主进程、预加载、本机服务
web/               前端（React + TypeScript）
tools/             构建、打包、体检工具
tests/             56 步门禁与回归题集
template/          导出的成品页模板
```

**分层原则**：`core/` 不依赖 `web/`；`electron/` 只做壳与服务；`web/` 只调 `/api/*`。
这样同一套核心既能被界面调用，也能被门禁脚本直接调用。

## 四、构建流程

```text
① 依赖安装   npm install ；cd web && npm install
② 公式预渲染 node tools/build-tex-svg.mjs
③ 成品页打包 node tools/build-template.mjs
④ 前端构建   node tools/web-build.mjs（tsc 类型检查 + rollup + Tailwind）
⑤ 门禁       node tools/verify-all.mjs（56 步，必须全绿）
⑥ 桌面打包   node tools/electron-build.mjs（NSIS 安装器）
```

**构建闸门：** 第 ⑤ 步未通过时，第 ⑥ 步拒绝打包——保证出包的代码一定过了全部校验。

## 五、关键配置项（package.json）

| 字段 | 值 | 说明 |
|---|---|---|
| `name` | xiaofeiyu-physics-animation | 包名，决定用户数据目录 |
| `version` | 1.x.y | 版本号，构建期注入界面 |
| `main` | electron/main.cjs | 主进程入口 |
| `license` | AGPL-3.0-only | 程序许可 |
| `build.appId` | com.xiaofeiyu.physics-animation | 安装标识 |
| `build.productName` | 小肥鱼物理解题动画 | 安装包与快捷方式名称 |
| `build.files` | core / sdk / contracts / tools / template / web / electron | 打包范围 |
| `build.asar` | true | 源码封入 asar |
| `build.asarUnpack` | better-sqlite3 等原生模块 | 原生模块不能进 asar |
| `build.win.target` | nsis（x64） | 安装器类型 |

## 六、编码规范

| 规范 | 做法 |
|---|---|
| 文本编码 | 全仓库 UTF-8（无 BOM），提交前跑编码检查 |
| 注释 | 写“为什么”，不写“这一行在干什么” |
| 单一事实源 | 版本号、门禁步数等只在文档一处定义 |
| 生成物 | 可重建的产物要么提交、要么一条命令能重建 |
| 契约 | schema 与类型声明由同一份 spec 生成，禁止手改产物 |

## 七、质量保障

| 手段 | 说明 |
|---|---|
| 56 步门禁 | 每次改动必须全绿，覆盖契约、渲染、导出、安全、编排 |
| 15 道回归题 | 合成题固定夹具，防止改 A 坏 B |
| 7 道真题 | 真实高考题端到端跑通 |
| 12 条负向注入 | 故意注入错误，验证判据真的能拦住 |
| 编码检查 | 拦截非法 UTF-8、BOM、疑似乱码 |

## 八、版本管理

- 每个可运行状态一个提交，提交信息写清“改了什么 / 为什么 / 跑了哪条命令验证”；
- 发布包与源码分开，发布物不进版本库；
- 密钥、账本、用户数据不进版本库。
