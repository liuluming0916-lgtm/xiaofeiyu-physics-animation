# 产品需求文档（PRD）· 小肥鱼物理解题动画软件

| 项 | 内容 |
|---|---|
| 文档版本 | V1.0 |
| 编制日期 | 2026-10-25 |
| 阶段 | 产品设计阶段 |
| 软件版本 | V1.0 |

## 一、产品目标

教师输入一道物理题（文字或图片），软件在 3 分钟内产出一段可播放的二维动画，
并附一份校验报告；动画可按讲解步骤暂停、跳转，最终可导出为单文件网页或 GIF。

## 二、用户场景

| 场景 | 触发 | 期望结果 |
|---|---|---|
| 备课时做演示 | 明天要讲传送带 | 一条能投屏播放的动画 |
| 课堂上临时讲 | 学生问“为什么共速后摩擦力反向” | 快速生成，按步骤讲到那一步 |
| 课后发资料 | 学生要复习 | 导出一个双击就能播的网页 |

## 三、信息架构

顶部导航四个入口：**解题 / 动画 / 设置 / 导出（菜单）**。
三者分工：解题页负责“生成”，动画页负责“讲解”，设置页负责“调讲法”，导出负责“带走”。

## 四、核心流程

生成链固定为八个阶段：

```text
读题 → 解题 → 分步讲解 ∥ 物理分析 → 编写绘制代码 → 干跑校验 → 修复 → 步骤对齐
```

| 阶段 | 产出 | 失败时 |
|---|---|---|
| 读题 | 题面转写、元件与场景判定、几何转写 | 停，报错 |
| 解题 | 解题过程文本 | 停，报错 |
| 分步讲解 | 步骤标题与公式（不含时间） | 与物理分析并行，单独失败不影响另一支 |
| 物理分析 | 每段运动方程（生成运动代码的唯一来源） | 停，报错 |
| 编写绘制代码 | 逐帧绘制函数 | 进入修复 |
| 干跑校验 | 九项判据结果 + 试运行帧 | 未通过进入修复 |
| 修复 | 只重画画面（≤3 轮）或重算物理（≤2 轮） | 未收敛则带告警交付 |
| 步骤对齐 | 每个讲解步骤对应的动画时间段 | 失败按比例回退 |

## 五、功能需求

### 5.1 解题页

| 编号 | 需求 | 说明 |
|---|---|---|
| F-01 | 文字题目输入 | 支持粘贴多行文本 |
| F-02 | 图片题目输入 | 支持 PNG/JPG，单张 ≤15 MB |
| F-03 | 图文混合 | 图片转写结果与文字题面合并 |
| F-04 | 连接设置 | 配置接口地址、模型名、密钥；未配置时可用内置示例题 |
| F-05 | 生成过程展示 | 阶段大标题 + 阶段插画 + 进度事件 |
| F-06 | 校验报告 | 结论（通过/告警/未通过）+ 逐条结果 + 定位信息 |
| F-07 | 知识卡依据 | 列出本次命中的卡片与命中原因 |

### 5.2 动画页

| 编号 | 需求 | 说明 |
|---|---|---|
| F-08 | 播放控制 | 播放/暂停、进度拖动、倍速（6 档预设 + 0.1–20 倍自定义） |
| F-09 | 步骤联动 | 点步骤跳时间；拖时间自动选步骤；可关闭联动 |
| F-10 | 曲线图 | 横轴为真实物理时间，与画布联动 |
| F-11 | 矢量开关 | 速度/加速度/受力三组矢量独立开关 |

### 5.3 设置页

| 编号 | 需求 | 说明 |
|---|---|---|
| F-12 | 知识卡管理 | 元件卡/场景卡/规范卡：开关、编辑、新建、导入导出 |
| F-13 | 提示词卡 | 八个阶段的提示词可逐份编辑 |
| F-14 | 本地规则卡 | 清洗规则、渲染规则 |
| F-15 | 保存/恢复/重读 | 保存到本机（写前备份）、恢复本版内置、以磁盘为准刷新 |

### 5.4 导出

| 编号 | 需求 | 说明 |
|---|---|---|
| F-16 | 导出单文件网页 | 自包含、离线可播、无外链 |
| F-17 | 导出 GIF | 960×540、25 帧/秒 |
| F-18 | 打开导出文件夹 | 一键定位产物目录 |

## 六、非功能需求

| 类别 | 要求 |
|---|---|
| 运行形态 | Windows 10/11 x64 桌面应用，绿色版可免安装运行 |
| 数据安全 | 题目、密钥、导出物全部留在本机；仅在生成时访问用户自备的模型接口 |
| 稳定性 | 单题生成失败不得导致软件退出；异常必须给出可操作的提示 |
| 性能 | 单题生成 ≤3 分钟（含最多 3 轮修复） |
| 离线可用 | 除模型调用外，全流程可离线运行；导出的网页离线可播 |
| 可维护 | 判据、门禁、生成链的口径集中定义，改动需通过自动化校验 |

## 七、验收标准

1. 八阶段链路可完整跑通，任一阶段失败都有明确报错；
2. 每次生成都有校验报告，未通过项可定位到具体检查号与位置；
3. 步骤与动画时间双向联动，点步骤必然跳到对应时刻；
4. 导出的网页在断网机器上双击可播；
5. 生成结果在同一道题上重复运行，运动结论一致。

## 八、不在本期范围

- 批量生成、排队；
- 内置题库（避免第三方题目著作权问题）；
- 云端账号与同步；
- 学生端。
