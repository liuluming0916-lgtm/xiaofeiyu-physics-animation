## 二、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，64 位 |
| 处理器 | x64 双核及以上 |
| 内存 | 4 GB（建议 8 GB） |

## 三、安装步骤

### 3.1 安装包方式（推荐）

1. 双击 `小肥鱼物理解题动画-Setup-x.y.z.exe`；
2. 选择安装目录（默认在用户目录下，不需要管理员权限）；
3. 勾选是否创建桌面快捷方式；
4. 完成后从开始菜单或桌面启动。

首次运行如遇 Windows SmartScreen 提示，点「更多信息 → 仍要运行」。

### 3.2 绿色版方式

1. 解压 zip 到任意目录（路径建议不含空格与特殊字符）；
2. 双击 `小肥鱼物理解题动画.exe`。

> 绿色版与安装版共用同一份用户数据目录，两者可以并存，但不建议同时运行。

## 四、首次配置

1. 启动后点右上角 **⚙ 连接设置**；
2. 填写三项：
   - 接口地址（兼容 OpenAI 协议的 `/v1/chat/completions`）；
   - 模型名；
   - 密钥。
3. 点「测试连接」确认可用；
4. **必须先配置才能生成**：软件不自带模型，未配置时跑不了自己的题。

## 五、目录说明

| 目录 | 内容 | 是否可删 |
|---|---|---|
| 安装目录 | 程序本体 | 卸载时清理 |
| `%APPDATA%\xiaofeiyu-physics-animation\data\` | 知识卡、提示词、密钥、账本 | **不可删**（删了会丢配置与历史） |
| `…\data\ai-rules\knowledgecard\` | 用户知识卡 | 可备份 |
| `…\data\ai-rules\keys.json` | 模型密钥 | 可删（需重新配置） |
| `…\data\history.db` | 生成历史与审计 | 可删（丢历史） |
| `文档\小肥鱼物理解题动画\导出\` | 导出的网页与 GIF | 可删 |
| 安装目录\`开源日志\` | 每次运行的日志（已脱敏） | 可删 |

## 六、卸载

1. 控制面板 → 程序和功能 → 卸载「小肥鱼物理解题动画」；
2. **卸载默认不删除用户数据**（保留知识卡与历史）；
3. 需要彻底清理时，手动删除 `%APPDATA%\xiaofeiyu-physics-animation\` 与导出目录。

## 七、迁移到新机器

1. 在新机器完成安装；
2. 把旧机器的整个 `%APPDATA%\xiaofeiyu-physics-animation\data\` 拷贝到新机器同路径；
3. 启动软件，设置页应能看到原有知识卡，历史库有记录。

> 密钥文件随数据目录一起迁移；如担心泄露，可只迁移 `knowledgecard/` 与 `history.db`，
> 到新机器重新填密钥。

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动后空白窗口 | 本机服务未起来 | 查看 `%TEMP%\od-shell.log`，重启软件 |
| 提示“未配置端点” | 未填连接设置 | 右上角齿轮配置 |
| 提示“不支持看图” | 所选模型无视觉能力 | 换模型，或改为文字描述 |
| 生成很慢 | 校验未过进入修复轮次 | 属正常；3 分钟以上再看日志 |
| 导出目录打不开 | 文档目录被重定向 | 用界面「打开导出文件夹」按钮 |
| 杀毒软件报毒 | 未签名 exe 的常见误报 | 加入信任，或使用绿色版解压后运行 |

## 九、版本升级

1. 直接运行新版本安装包覆盖安装，用户数据不受影响；
2. 升级后首次启动会自动迁移旧版数据（知识卡从旧目录复制、账本按结构版本迁移）；
3. 升级前建议备份 `%APPDATA%\xiaofeiyu-physics-animation\data\`。

## 十、回滚

1. 卸载当前版本；
2. 安装上一版本安装包；
3. 若账本结构已升级，旧版本可能无法读取新库——此时用升级前的备份恢复 `history.db`。

## 十一、运维建议

| 项 | 建议 |
|---|---|
| 备份 | 每月备份 `data\` 目录一次 |
| 日志 | 出问题时收集 `开源日志\` 整个文件夹与 `%TEMP%\od-shell.log` |
| 磁盘 | 导出目录定期清理，GIF 单文件约 2–8 MB |
| 安全 | 密钥只存在本机，不要写入任何导出物或截图 |
