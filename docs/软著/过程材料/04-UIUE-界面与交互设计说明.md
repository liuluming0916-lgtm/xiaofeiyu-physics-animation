## 一、设计目标

1. **一眼知道在干什么**：生成过程用一个阶段大标题 + 一张插画表达，不用进度条堆砌；
2. **讲课时不挡视线**：画布占满右栏，控件退到边缘；
3. **错误可读**：不说“失败了”，说“哪一条没过、在哪一行”。

## 二、信息架构

```text
解题页 ─┬─ 左：题目输入 + 生成按钮
        └─ 右：阶段大标题 + 插画 + 折叠面板（解题过程 / 判据·卡片依据·自愈过程）

动画页 ─┬─ 左：导读栏（原题 / 第 N 步 页签，底部曲线图）
        └─ 右：画布 + 播放条 + 矢量开关 + 图例

设置页 ─── 知识卡 / 提示词卡 / 本地规则卡 / AI 帮写（占位）
```

## 三、页面布局规范

| 区域 | 规范 |
|---|---|
| 顶栏 | 高 56px，左为产品名 + 版本号，右为连接设置入口 |
| 主区 | 最大宽 1400px 居中，左右分栏比例 5:7 |
| 动画页 | 左侧导读栏固定 380px，右侧画布自适应（flex 占满剩余高度） |
| 圆角 | 卡片 16px，按钮 8px，输入框 8px |
| 间距 | 8px 栅格，区块间距 16 / 24px |

## 四、视觉规范

| 项 | 取值 | 理由 |
|---|---|---|
| 正文中文 | 宋体（SimSun） | 与教材、试卷一致，投影不失真 |
| 正文英文/数字 | Times New Roman | 与公式排版统一 |
| 控件文字 | 黑体 | 小字号下更清晰（控件不使用宋体） |
| 正文最小字号 | 12px | 宋体在 11px 会发虚 |
| 速度矢量 | #2e7d32（绿） | 与加速度、受力区分 |
| 加速度矢量 | #15529e（深蓝） | 避开图表墨色 |
| 受力矢量 | #b3382f（红） | 惯例色 |
| 画布背景 | #ffffff | 投影环境对比度最高 |
| 强调色 | 天蓝到靛蓝渐变 | 用于阶段大标题 |

> 画布内**不写任何文字**（除 p–V 等图形类题的坐标轴名），文字一律放在画布外，
> 保证投影时字号统一、缩放不失真。

## 五、交互规范

| 交互 | 行为 |
|---|---|
| 生成中切换页面 | 禁止进入动画页（此时程序可能未收敛） |
| 点击步骤 | 时间轴跳到该步起点，页签切到该步 |
| 拖动时间轴 | 自动选中当前步骤（联动开启时） |
| 关闭「动画联动」 | 点步骤只切换文字，不动画 |
| 倍速 | 6 档预设（0.1/0.5/1/2/5/10×）+ 自定义 0.1–20× |
| 矢量开关 | 三组独立，关掉即从画面移除并同步图例 |
| 恢复本版内置 | 只撤销对内置卡的覆盖，不删除用户自建卡 |

## 六、状态与反馈设计

生成过程用一张插画 + 一句大标题表达当前状态，共 9 种：

| 状态 | 画面 | 标题 |
|---|---|---|
| 待机 | 悠闲 | 小肥鱼在等你出题… |
| 读题 | 低头看题 | 小肥鱼正在看题… |
| 解题 | 演算 | 小肥鱼正在解题… |
| 分步/分析/对齐 | 托腮思考 | 小肥鱼正在努力思考… |
| 画图 | 拿笔绘制 | 小肥鱼正在画画… |
| 校验 | 检查 | 小肥鱼正在检查… |
| 修复 | 修修补补 | 小肥鱼正在完善… |
| 完成 | 举双手 | 小肥鱼画好啦！ |
| 出错 | 沮丧 | 小肥鱼卡住了… |

## 七、可访问性

- 阶段标题使用 `role="status"` 与 `aria-live="polite"`，状态变化可被读屏播报；
- 步骤页签使用 `aria-selected` 标注选中态；
- 所有控件可键盘聚焦，焦点环可见；
- 图表与画布提供文字替代说明。
