## 三、主要功能

> 与说明书、与代办平台里填的那段保持同一口径。直接复制：

```text
本软件是一款面向中学物理教师的 Windows 桌面应用，用于把一道物理题自动转换为可播放的讲解动画。主要功能包括：（1）题目录入：支持文字粘贴、图片上传以及图文混合三种方式，图片题可自动识别题面。（2）读题与判定：识别题面、物理元件与场景类型，转写题中给出的数值与几何关系，并给出判定依据供教师复核。（3）解题与分步讲解：生成解题过程与按步骤组织的讲解文本，步骤只含标题与公式，不含时间。（4）物理分析：按小问给出各物体的运动方程，由程序据此生成位移、速度、加速度与曲线数据，模型不参与数值计算，保证同一道题的运动前后一致。（5）动画生成：由模型编写逐帧绘制代码，程序自动合成可播放动画，画面尺寸与取景由程序统一处理。（6）校验与自动修复：对生成结果执行结构检查、数值检查与物理一致性检查共九项判据，并在隔离沙箱中试运行；未通过时按画图错误与物理错误分流定位，画图错误最多重画三轮、物理错误最多重算两轮，仍未收敛则带告警交付并如实报告。（7）交互播放：讲解步骤与动画时间双向联动，点击步骤跳到对应时刻，拖动时间轴自动选中当前步骤；可切换播放速度、受力矢量显示与曲线图。（8）知识卡管理：内置元件卡、场景卡与动画规范卡，教师可按教材章节开关、编辑、新建与导入导出。（9）导出：生成自包含的单文件网页，或导出 960×540、25 帧/秒的 GIF 动图。软件全程本地运行，题目、模型密钥与导出文件均保存在本机，不上传服务器。
```

## 四、技术特点

```text
1. 运动与画面分离：物理分析产出每段运动方程，由程序生成位移、速度、加速度代码，模型只负责逐帧绘制，保证同一道题的运动前后一致。
2. 多层判据把关：生成结果需通过结构、数值、物理一致性共九项静态判据，并在隔离沙箱中试运行；不通过时按“画图错/物理错”分流修复，画图错只重画画面，物理错重算分析。
3. 步骤与画面双向耦合：讲解步骤标注到动画时间轴，点步骤跳时间、拖时间自动选步骤。
4. 知识卡驱动的作图规范：元件与场景以卡片形式描述画法、触发词与自检要求，教师可按教材章节开关或改写。
5. 全本地存储：题目、密钥、历史与导出文件均在本机，不上传服务器。
6. 自包含导出：网页不依赖网络与外部脚本，公式为构建期预渲染，离线可播。
```
