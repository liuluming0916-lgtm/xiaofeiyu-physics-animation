## 一、三步跑通第一道题

1. 解压发布包，双击 **`小肥鱼物理动画.exe`**（绿色版，不用安装）。
   第一次运行被 Windows 拦住，点「更多信息 → 仍要运行」。
2. 想连自己的模型：点右上角 **⚙ 连接设置**，填接口地址、模型名、Key。
   **不填也能用**：界面会用内置的一道真题跑通全流程，先看看效果。
3. 在「解题」页贴题目（或传图片）→ 点「开始生成动画」。

## 二、四个入口

| 入口 | 你在这里做什么 | 产出 |
|---|---|---|
| **解题** | 贴题目 / 传图片 → 开始生成 | 动画程序 + 校验报告 |
| **动画** | 播放；点左侧步骤跳到对应时刻；曲线与画布联动 | 可导出的网页 / GIF |
| **设置** | 改知识卡 / 提示词卡 / 本地规则卡 | 改动存进本机，关掉再开还在 |
| **导出 ▾** | 选「导出网页」或「导出 GIF」 | 落在 `文档\小肥鱼物理动画\导出\` |

**导出在导航栏的「导出 ▾」**，不在动画页顶部。落点固定，界面里有「打开导出文件夹」按钮。

- **单文件网页**：双击就能播，题目、公式、动画都在一个文件里，发给同事不会丢东西。
- **GIF**：25 帧每秒、960×540，默认只抓动画画布，适合贴进课件。

## 三、动画不理想怎么办

1. **先看校验报告**。它不会只说“失败了”，会指出是哪一条（比如箭头没标长度、标注压到图形上）。
2. **再看用了哪几张卡**。“知识卡依据”面板会列出这次命中了哪些卡、为什么命中。
   命中的卡不对，**改卡或调词表开关**比反复重跑有效。

改坏了可以回退：设置页顶部三个按钮——**保存到本机**（写前自动备份）、
**恢复本版内置**（只撤销对内置卡的覆盖，不删你新建的卡）、**重新读取**（以磁盘为准刷新）。

## 四、常见问题

**Q：不填 Key 能用吗？**
能。会用内置的一道真题跑通流程，判定会标「未校验」。要跑自己的题必须填 Key。

**Q：题目和 Key 会被上传吗？**
不会。都在本机。唯一离开本机的是：你点“开始生成”时，题面和图片会发给你自己填的那个模型接口。

**Q：换台电脑怎么带走数据？**
整个 `%APPDATA%\xiaofeiyu-physics-animation\data\` 拷过去即可。

**Q：导出的 GIF 没有曲线图？**
默认不录。需要曲线就导出网页。

**Q：为什么有时候生成很慢？**
链路有干跑和自动修复，校验没过会重画。慢是正常的，卡在“正在检查”超过很久才算异常。

## 六、出问题时，给这三样

1. `%TEMP%\od-shell.log`（软件日志，会记退出原因）；
2. 那道题的**题面文字**（有图片一起给）；
3. 界面上**校验报告的截图**。

有这三样，绝大多数问题能直接定位，不用你描述现象。
