# 小肥鱼物理动画 · 从这里开始

> 这是一款**给物理老师用**的小软件（v1.1.17）：把一道题（文字或拍照）变成**能动起来、能量化讲**的动画，
> 再顺手做成教辅用的单文件网页或 GIF。
>
> 它不卖服务，也不上传你的题目。**所有题目、模型 Key、导出的文件都留在你自己的电脑上。**

---

## 一、装上就能用（Windows 64 位）

1. 解压发布包，双击 **`小肥鱼物理动画.exe`**（绿色版，不用安装）。
2. 第一次运行如果被 Windows 拦住，点「更多信息 → 仍要运行」。
3. 想连自己的模型：点右上角 **⚙ 连接设置**，填接口地址、模型名、Key。
   - 不填也能用：界面会用**内置的一道真题**跑通全流程，让你先看看效果（判定会标「未校验」）。
4. 换台电脑想带走数据：都在 `%APPDATA%\xiaofeiyu-physics-animation\data\` 里。

---

## 二、导航栏：四个入口，一件事一条线

| 入口 | 你在这里做什么 | 产出 |
|---|---|---|
| **解题** | 贴题目 / 传图片 → 点「开始生成动画」 | 动画程序 + 校验报告 |
| **动画** | 直接播放；点左侧步骤会跳到对应时刻；曲线图与画布联动 | 可导出的**单文件网页** / **GIF** |
| **设置** | 改知识卡 / 提示词卡 / 本地规则卡；词表开关、导入导出、恢复内置 | 改动**真的存进本机**，关掉软件再打开还在 |
| **导出 ▾** | 选「导出网页」或「导出 GIF」 | 落在 `文档\小肥鱼物理动画\导出\` |

**导出在导航栏的「导出 ▾」**（不在动画页顶部）。
导出物放在 `文档\小肥鱼物理动画\导出\`，界面里有「打开导出文件夹」按钮，不用记路径。

- **单文件网页**：双击就能播，题目、公式、动画都在一个文件里，发给同事不会丢东西。
- **GIF**：25 帧每秒、960×540，默认不录曲线图（只抓动画画布），适合贴进课件。

## 三、动画不理想？先看这两件事

1. **看校验报告**。它不会只说"失败了"，会指出是哪一条（比如箭头没标长度、标注压到图形上）。
2. **看用了哪几张卡片**。动画生成时会从「知识卡」里取"动画规范卡"、"元件卡"和"场景卡"，
   报告里的「知识卡依据」面板会列出这次命中了哪些、为什么命中。
   如果命中的卡片不对，**改卡片/改词表开关**比反复重跑更有效。

> ⚠ 卡片的写法有讲究：触发只来自词表（元件/场景），不再有 `keys`；
> 一张卡只讲一个元件/一个场景，必须写「生成后自检」小节，并给出能通过检查的代码示例。
> 详见 [改知识卡与导入导出](改词条与导入导出.md)。

## 四、v1.1.17 的变化（老师视角）

### 解题页：小肥鱼大图 + 大标题

- **撤掉阶段进度条**：原来顶部一排「1. 读题 → 2. 解题 → …」的小方块没有了，
  改成**小肥鱼阶段大图 + 一行大标题**（“小肥鱼正在看题…”），跑到哪个阶段就换哪张图、哪句话。
- **过程与判据收进图下**：「解题过程」「判据 · 知识卡依据 · 自愈过程」两个折叠面板
  移到小肥鱼下面，需要看证据时再展开。
- **连接设置**：删掉“（教辅蒸馏要用）”这半句，只保留“这个模型支持看图”。

### 纯图片题也能正常生成

- 只发图片、不写题面也能跑：`PROBLEM` 会用读题得到的标题补上，不再报“PROBLEM 槽是空的”；
- 如果模型输出真的拼不成程序，界面会立刻显示错误并停下，不会一直停在“小肥鱼正在检查…”；
- 模型把标题写成“标题\n…”或“标题：…”也能认出来。

### 生成链换了地基

1. **动画里的运动不再由模型"算"**：模型只负责"怎么画"，位置、速度、加速度、曲线由物理分析统一生成，
   所以同一道题的运动前后一致，不会出现"这段速度莫名下降"。
2. **画面尺寸统一**：相机固定拍一张 10 × 6 的"纸"，物块、小球、滑轮在任何量级的题里都一样大；
   不会再出现 0.4 m 的物块缩成 19 像素。
3. **时长按小问归一**：每个小问固定 **4 秒**（两小问 8 秒），极端题用倍速控件调（0.1–20×）。
4. **步骤和动画联动**：动画页左侧点「第 N 步」会跳到该步的时间；拖时间轴会自动选中当前步。
   时间轴显示「第 k / n 步」，不显示秒；**曲线图横轴仍是真实物理秒**。
5. **题目自动命名**：读题后把模型给的标题用在动画页标题、导出网页标题和导出文件名上。
6. **知识卡库更新**：内置 **30 张**（10 元件 + 18 场景 + 2 规范，其中 3 张封存），旧的 v1 卡正式弃用。

## 五、改坏了怎么回退

设置页顶部有三个按钮：

- **保存到本机**：把改动写进 `%APPDATA%\xiaofeiyu-physics-animation\data\ai-rules\knowledgecard\`（写前自动备份）。
- **恢复本版内置**：只撤销你对**内置卡**的覆盖，**不删你自己新建的卡**。
- **重新读取**：以磁盘为准刷新页面。

> 本地词表开关（按章节关闭某些元件/场景）存在 `ai-rules/vocab.json`，不删词条，随时可再打开。

---

## 六、出问题时，我需要你给这三样

1. `%TEMP%\od-shell.log`（软件日志，里面会记退出原因）；
2. 那道题的**题面文字**（图片也一起给更准）；
3. 界面上的**校验报告截图**。

有这三样，绝大多数问题能直接定位，不用你描述现象。
